# 06-游戏同步与工程对象（Game Sync & Project Objects）

> **来源**: [Audiokinetic 官方文档 - Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_object_reference.html)

## 概述

本章涵盖两大类对象：

1. **游戏同步对象（Game Syncs）** — 用于游戏引擎与 Wwise 之间的参数同步和状态管理
2. **工程组织对象（Project Objects）** — Wwise 工程的元数据结构

---

## 第一部分：游戏同步对象

### GameParameter

游戏参数，是 RTPC 的驱动源，实时控制音频属性的变化。

- **ClassID**: 1507344
- **WAAPI 类型名**: `GameParameter`
- **说明**: GameParameter 是游戏引擎传递给 Wwise 的实时数值参数（如速度、距离、生命值等）。它驱动 RTPC（Real-Time Parameter Control）来动态调整声音属性（音量、音高、滤波等）。位于 \\Game Parameters\\ 文件夹中。
- **所属层级**: Game Parameters（独立层级）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `RangeMin` | number | 参数最小值 |
| `RangeMax` | number | 参数最大值 |
| `DefaultValue` | number | 默认值 |
| `BindToBuiltInParam` | number | 绑定到内置参数（引擎侧） |
| `SimulationValue` | number | Wwise Authoring 中的模拟值 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
|（无常用引用）| — | — |

---

### StateGroup

状态组，管理一组互斥的状态值。

- **ClassID**: 458768
- **WAAPI 类型名**: `StateGroup`
- **说明**: StateGroup 定义了一组互斥的状态值（State）。例如 "Weather" 状态组可能包含 "Rain"、"Snow"、"Clear" 等状态。任一时刻只能有一个状态处于激活状态。位于 \\States\\ 文件夹中。
- **所属层级**: States（独立层级）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `DefaultState` | reference | 默认状态 |
| `Volume` | number | 音量（引擎侧） |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `DefaultState` | State | 默认状态 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | State | 包含的状态列表 |

---

### State

状态，属于某个 StateGroup 的互斥状态值。

- **ClassID**: 393232
- **WAAPI 类型名**: `State`
- **说明**: State 是 StateGroup 的子对象，表示一个具体的状态值。当 StateGroup 切换到某个 State 时，所有关联了该 StateGroup 的声音/容器对象的属性会根据设置进行切换。
- **所属层级**: States（作为 StateGroup 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 状态切换时的音量偏移 |

---

### SwitchGroup

开关组，管理一组 Switch 值。

- **ClassID**: 1245200
- **WAAPI 类型名**: `SwitchGroup`
- **说明**: SwitchGroup 定义了一组 Switch 值（如 "地面类型" 包含 "Concrete"、"Grass"、"Water" 等）。SwitchGroup 被 SwitchContainer 引用，用于在运行时选择播放哪个子对象。位于 \\Switches\\ 文件夹中。
- **所属层级**: Switches（独立层级）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `DefaultSwitch` | reference | 默认开关值 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `DefaultSwitch` | Switch | 默认开关值 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | Switch | 包含的开关值列表 |

---

### Switch

开关值，属于某个 SwitchGroup。

- **ClassID**: 1310736
- **WAAPI 类型名**: `Switch`
- **说明**: Switch 是 SwitchGroup 的子对象，表示一个具体的开关值。SwitchContainer 根据当前激活的 Switch 值来选择对应的子对象播放。
- **所属层级**: Switches（作为 SwitchGroup 的子对象）

---

### Trigger

触发器，用于触发 Stinger 等瞬时音频事件。

- **ClassID**: 2621456
- **WAAPI 类型名**: `Trigger`
- **说明**: Trigger 用于在游戏引擎侧触发瞬时事件，如播放 Stinger（短音乐片段）。不同于 Event，Trigger 是瞬时触发的，不持续占用资源。位于 \\Triggers\\ 文件夹中。
- **所属层级**: Triggers（独立层级）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
|（常用属性较少，官网未提供完整列表）| — | — |

---

### RTPC

实时参数控制（Real-Time Parameter Control），定义 GameParameter 如何影响音频属性。

- **ClassID**: 1441808
- **WAAPI 类型名**: `RTPC`
- **说明**: RTPC 是连接 GameParameter 和音频属性的桥梁。它定义了一个 GameParameter 的值如何映射到目标属性值（如 Volume、Pitch 等），通过曲线来定义映射关系。RTPC 通常作为子对象挂在被控制的对象上。
- **所属层级**: 作为子对象附加在各种对象上

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `RTPCType` | number | RTPC 类型 |
| `X_CoordinateArray` | array | X 坐标数组（输入值） |
| `Y_CoordinateArray` | array | Y 坐标数组（输出值） |
| `Volume` | number (dB) | RTPC 曲线的音量偏移 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `GameParameter` | GameParameter | 驱动此 RTPC 的 GameParameter |
| `Property` | — | 被控制的属性名称引用 |

## 第二部分：工程组织对象

### Project

Wwise 工程对象，是整个工程的根节点。

- **ClassID**: 196624
- **WAAPI 类型名**: `Project`
- **说明**: Project 是 Wwise 工程（.wproj 文件）的根对象，是整个对象层级的起点。通过 WAAPI 查询以 `\\` 或 `{PROJECT_GUID}` 可访问工程的根路径。
- **所属层级**: 工程根

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `ProjectPath` | string | 工程文件路径（只读） |
| `ProjectDirectory` | string | 工程所在目录（只读） |
| `ProjectName` | string | 工程名称 |
| `VolumeThreshold` | number | 音量阈值 |
| `MaxAttenuation` | number | 最大衰减值 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | WorkUnit | 顶层工作单元列表 |

---

### WorkUnit

工作单元，是 Wwise 对象的物理存储容器。

- **ClassID**: 1638416
- **WAAPI 类型名**: `WorkUnit`
- **说明**: WorkUnit 是 Wwise 中对象的物理存储单位，对应磁盘上的 `.wwu` 文件。每个非 WorkUnit 对象都归属于某个 WorkUnit。WorkUnit 通过 `workunitType` 属性区分物理文件夹、根文件和嵌套文件。
- **所属层级**: 各层级的容器

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `workunitIsDefault` | boolean | 是否为默认 WorkUnit |
| `workunitType` | string | 类型：`folder` / `rootFile` / `nestedFile` |
| `workunitIsDirty` | boolean | 是否有未保存的更改 |
| `notes` | string | 注释 |

**WorkUnit 类型说明**:

| workunitType | 说明 |
|-------------|------|
| `folder` | 物理文件夹（在磁盘上有对应目录） |
| `rootFile` | 根文件（工程根级别的 .wwu 文件） |
| `nestedFile` | 嵌套文件（子目录中的 .wwu 文件） |

> **注意**：创建 WorkUnit 前需要清除 undo/redo 历史和剪贴板，且 `onNameConflict` 不能使用 `replace`。

---

### Folder

文件夹，是 Wwise 工程中的逻辑组织容器。

- **ClassID**: 131088
- **WAAPI 类型名**: `Folder`
- **说明**: Folder 是虚拟文件夹（Virtual Folder），仅存在于 Wwise 工程内部作为逻辑组织容器，不占用磁盘空间。与 WorkUnit（Physical Folder）不同，Folder 不生成 .wwu 文件。
- **所属层级**: 各层级中

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `notes` | string | 注释 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | 多种类型 | 子对象列表 |

**虚拟文件夹 vs 物理文件夹**:

| 特性 | Folder（虚拟） | WorkUnit（物理，workunitType=folder） |
|------|----------------|--------------------------------------|
| ClassID | 131088 | 1638416 |
| 磁盘文件 | 不生成 | 对应磁盘目录 |
| 包含 .wwu | 不包含 | 包含 .wwu 文件 |

---

### Platform

平台定义，表示一个目标运行时平台。

- **ClassID**: 4522000
- **WAAPI 类型名**: `Platform`
- **说明**: Platform 定义 Wwise 工程的运行时目标平台（如 Windows、iOS、Android、PS5、Xbox Series X 等）。平台对象影响音频转码设置、平台特定配置等。
- **所属层级**: Platforms

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `BasePlatform` | reference | 基础平台（继承来源） |
| `PlatformReference` | string | 平台引用标识符 |

---

### Language

语言定义，用于多语言工程中的语音本地化。

- **ClassID**: 4915216
- **WAAPI 类型名**: `Language`
- **说明**: Language 定义 Wwise 工程中的语言，用于多语言音频资产管理（如每个 Sound Voice 可以有不同的语言版本）。常见语言包括 English(US)、Chinese(CN)、Japanese 等。
- **所属层级**: Languages

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `LanguageId` | number | 语言 ID |
| `ExternalSourcesDefault` | string | 外部源默认路径 |

---

### SoundBank

声音库，是打包音频数据和元数据的输出单元。

- **ClassID**: 1179664
- **WAAPI 类型名**: `SoundBank`
- **说明**: SoundBank 定义了一组要打包到 .bnk 文件中的 Wwise 对象（事件、声音、总线等）。通过 Inclusion 机制（Inclusions 列表）指定哪些对象包含在此 SoundBank 中。生成 SoundBank 后产生游戏引擎可加载的 .bnk 文件。
- **所属层级**: SoundBanks

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `SoundBankType` | string | SoundBank 类型：User / Bus |
| `SoundBankLanguage` | string | SoundBank 关联的语言 |
| `MaxAttenuation` | reference | 最大衰减引用 |
| `GeneratedSoundBanksPath` | string | 生成的 SoundBank 输出路径 |
| `IsZeroLatency` | boolean | 是否零延迟 |
| `Notes` | string | 注释 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `Inclusions` | Inclusion | 包含关系列表（定义哪些对象被此 SoundBank 包含） |

---

### ExternalSource / ExternalSourceFile

外部源和外部源文件，用于管理运行时动态加载的音频文件。

- **ExternalSource ClassID**: 3735568
- **ExternalSourceFile ClassID**: 3670032
- **WAAPI 类型名**: `ExternalSource` / `ExternalSourceFile`
- **说明**: ExternalSource 和 ExternalSourceFile 用于管理运行时动态替换的音频。例如，游戏运行时下载或生成的音频文件可以通过 ExternalSource 机制替换预置的音频。
- **所属层级**: Actor-Mixer Hierarchy

---

### Conversion

转换设置，定义音频文件的转码参数。

- **ClassID**: 3604496
- **WAAPI 类型名**: `Conversion`
- **说明**: Conversion 定义了音频转码的平台特定设置（如采样率、比特率、编码格式等）。多个 Sound 对象可以共享同一个 Conversion 设置（通过 `Conversion` 引用）。
- **所属层级**: Conversion Settings

---

## 其他辅助对象

### AcousticTexture（声学材质）

- **ClassID**: 4718608
- **说明**: 声学材质定义表面的声学特性（吸收、反射、散射等），用于 Wwise Spatial Audio / Reflect。

### Curve（曲线）

- **ClassID**: 917520
- **说明**: 曲线对象，定义 RTPC 或 Attenuation 中的插值曲线点。

### Panner（声像器）

- **ClassID**: 2752528
- **说明**: 声像器，控制声音在空间中的定位（2D / 3D）。

### Position（位置）

- **ClassID**: 786448
- **说明**: 定位设置，定义声音的 2D/3D 位置行为（包括 Positioning 选项卡下的所有设置）。

### Path2D（2D 路径）

- **ClassID**: 720912
- **说明**: 2D 路径，定义声音在 2D 空间中的移动路径。

### ModulatorEnvelope（包络调制器）

- **ClassID**: 4259856
- **说明**: 包络调制器，使用 ADSR 包络来调制声音属性。

### ModulatorLfo（LFO 调制器）

- **ClassID**: 4194320
- **说明**: LFO（低频振荡器）调制器，以周期性波形调制声音属性。

### ModulatorTime（时间调制器）

- **ClassID**: 5111824
- **说明**: 时间调制器，基于时间偏移来调制声音属性。

### Modifier（修饰器）

- **ClassID**: 983056
- **说明**: 修饰器，对声音属性进行数学变换（如随机化）。

### CustomState（自定义状态）

- **ClassID**: 5177360
- **说明**: 自定义状态，允许用户定义自定义的状态类型。

### MultiSwitchEntry（多开关条目）

- **ClassID**: 5439504
- **说明**: 多开关条目，用于定义多个开关值的组合条件。

## WAAPI 操作示例

### 创建 GameParameter

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Game Parameters\\Default Work Unit\\",
        "type": "GameParameter",
        "name": "PlayerSpeed",
        "@RangeMin": 0.0,
        "@RangeMax": 100.0,
        "@DefaultValue": 0.0
    }
}
```

### 创建 StateGroup 和 States

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\States\\Default Work Unit\\",
        "type": "StateGroup",
        "name": "Weather",
        "children": [
            {
                "type": "State",
                "name": "Clear"
            },
            {
                "type": "State",
                "name": "Rain"
            },
            {
                "type": "State",
                "name": "Snow"
            }
        ]
    }
}
```

### 在 Sound 对象上创建 RTPC

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{SOUND_GUID}",
        "type": "RTPC",
        "name": "SpeedToVolume",
        "@RTPCType": 0
    }
}
```

### 创建 SwitchGroup 和 Switches

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Switches\\Default Work Unit\\",
        "type": "SwitchGroup",
        "name": "GroundMaterial",
        "children": [
            { "type": "Switch", "name": "Concrete" },
            { "type": "Switch", "name": "Grass" },
            { "type": "Switch", "name": "Water" }
        ]
    }
}
```

### 创建 SoundBank 并添加 Inclusions

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\SoundBanks\\Default Work Unit\\",
        "type": "SoundBank",
        "name": "Main",
        "@SoundBankType": "User"
    }
}
```

### 通过 Sound Engine API 设置状态

```json
{
    "method": "ak.soundengine.setState",
    "params": {
        "stateGroup": "Weather",
        "state": "Rain"
    }
}
```

### 通过 Sound Engine API 设置 Switch

```json
{
    "method": "ak.soundengine.setSwitch",
    "params": {
        "switchGroup": "GroundMaterial",
        "switchState": "Concrete",
        "gameObject": 1
    }
}
```

### 通过 Sound Engine API 设置 RTPC

```json
{
    "method": "ak.soundengine.setRTPCValue",
    "params": {
        "rtpc": "PlayerSpeed",
        "value": 50.0,
        "gameObject": 1
    }
}
```

### 查询所有 GameParameter

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"search": ["\\Game Parameters"]},
        "transform": [
            {"select": ["descendants"]},
            {"where": ["type:isIn", ["GameParameter"]]}
        ],
        "options": [{"return": ["id", "name", "RangeMin", "RangeMax", "DefaultValue"]}]
    }
}
```

### 查询 SoundBank 的 Inclusions

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"id": ["{SOUNDBANK_GUID}"]},
        "options": [{"return": ["id", "name", "Inclusions.@object", "Inclusions.@filter"]}]
    }
}
```
