# 03-关键字详解

本文详细介绍 WAQL 中的核心关键字和访问器（Accessor），内容来源于官方 WAQL Reference。

---

## 对象表达式（Object Expressions）

对象表达式返回零到多个 Wwise 对象。多个表达式可以用点号 `.` 链式组合。

---

### this — 当前对象

返回**当前对象**本身。

```
$ from object "\Master-Mixer Hierarchy\Default Work Unit\Master Audio Bus" select this, descendants
```

通常与 `descendants` 或 `ancestors` 组合使用，因为这两个关键字默认不包含当前对象。

---

### parent — 父对象

返回对象的**直接父对象**。如果对象没有父对象，则不返回任何对象。

**select 中使用：**
```
$ from type Sound select parent
```

**where 中使用：**
```
$ from type Sound where parent.name : "*engine"
```

**链式使用：**
```
$ from object "Event:Play_Hello" select parent.parent
```

---

### children — 直接子对象

返回对象的**直接子对象**。

```
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select children
```

---

### descendants — 所有后代

返回对象的所有**后代**（递归包含所有层级的子对象）。

```
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants
```

> **注意：** `descendants` **不包含**当前对象。如需包含当前对象，请使用：
> ```
> $ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants, this
> ```

---

### ancestors — 所有祖先

返回对象的所有**祖先**（递归包含所有层级的父对象）。

```
$ from object "Event:Play_Hello" select ancestors
```

> **注意：** `ancestors` **不包含**当前对象。如需包含当前对象，请使用：
> ```
> $ from object "Event:Play_Hello" select ancestors, this
> ```

---

### referencesTo — 反向引用

返回**所有引用了当前对象**的对象。类似于 Reference View 中的"查找所有引用"功能。

```
$ from type Effect select referencesTo
$ "Event:Play_Hello" select referencesTo
```

**实际应用：** 从 Sound 查找引用它的所有 Event：
```
$ from type sound select this, ancestors select referencesTo where type = "action" select parent
```

---

### owner — 所有者

返回对象的**所有者**。`owner` 仅对定义在其他对象内部的"Custom"对象生效。

注意区分：
- **owner**：Custom 对象的拥有者（如包含 Effect 作为 Insert 的对象）
- **parent**：Shareset 对象的父级
- **referencesTo**：引用当前对象的其他对象

```
$ from type Effect select owner
$ from type Effect where owner.name : "*env"
```

---

### REFERENCE_NAME — 引用访问器

返回当前对象特定引用名所引用的**另一个对象**。

三种使用方式：

| 语法 | 说明 |
|------|------|
| `REFERENCE_NAME` | 返回 UI 中定义的值，**考虑**覆盖（override）设置 |
| `@REFERENCE_NAME` | 返回 WWU 文件中**直接定义**的值，**不考虑**覆盖设置 |
| `@@REFERENCE_NAME` | 等同于不带 `@` 的形式，用于解决与内置访问器名称冲突的情况 |

```
$ from type Sound select OutputBus
$ from type Sound select effects
$ from type Sound select @@Effects
$ from type Sound where outputBus = "Bus:Master Audio Bus"
```

> **注意：** 引用访问器**不区分大小写**。可以链式连接多个引用访问器。
> 完整引用列表参考 Wwise Objects Reference。

---

### 其他对象表达式

| 表达式 | 说明 | 示例 |
|--------|------|------|
| `randomizer("PROPERTY_NAME")` | 返回与指定属性关联的随机化器对象。可访问 `.min`、`.max`、`.enabled` 属性 | `where randomizer("pitch") != null`<br>`where randomizer("highpass").min < 0`<br>`where randomizer("volume").enabled = true` |
| `workunit` | 返回用于持久化当前对象的 Work Unit 对象 | `$ from type Effect select workunit` |
| `maxDurationSource` | 返回一个 JSON 对象，包含所有后代中最大播放时长的 Audio Source 的 ID 和时长值。仅适用于 Actor-Mixer Hierarchy、Interactive-Music Hierarchy 和 Event 对象 | `$ from object "\Actor-Mixer Hierarchy" select maxDurationSource` |
| `maxDurationSourceObject` | 返回所有后代中具有最大播放时长的 Audio Source 对象 | `$ from object "\Actor-Mixer Hierarchy" select maxDurationSource` |
| `maxRadiusAttenuation` | 返回一个 JSON 对象，包含所有后代中最大半径衰减对象的 ID 和半径值 | `$ from type Sound select maxRadiusAttenuation` |
| `maxRadiusAttenuationObject` | 返回所有后代中具有最大半径的衰减对象 | `$ from type Sound select maxRadiusAttenuation` |
| `audioSourceLanguage` | 返回当前 Audio Source 使用的语言对象。仅适用于 Audio Source 对象 | `$ from type AudioFileSource select audioSourceLanguage` |
| `switchContainerChildContext` | 返回 Switch Container 上下文对象。仅适用于 SwitchContainer | `$ from project select switchContainerChildContext` |
| `musicTransitionRoot` | **(已弃用)** 返回 Music Transition 根对象。应使用 TransitionRoot 引用代替 | — |
| `musicPlaylistRoot` | **(已弃用)** 返回 Music Playlist 根对象。应使用 PlaylistRoot 引用代替 | — |
| `activeSource` | 返回与 Sound 对象关联的活动源 | `$ from type Sound select activeSource` |

## 值表达式（Value Expressions）

值表达式返回数字、字符串或布尔值。

### PROPERTY_NAME — 属性访问器

返回特定对象属性的值。

三种使用方式：

| 语法 | 说明 |
|------|------|
| `PROPERTY_NAME` | 返回**有效值**（考虑覆盖设置），即播放时实际使用的值 |
| `@PROPERTY_NAME` | 返回对象上**直接定义**的值，即使未被覆盖 |
| `@@PROPERTY_NAME` | 等同于不带 `@` 的形式，用于解决与内置访问器名称冲突的情况 |

```
$ from type Sound where volume < 0
$ from type Sound where @UserAuxSendVolume0 < 0
$ from type Sound where IsLoopingEnabled = true
$ from type sound where isloopingenabled = true
```

> **注意：** 属性访问器**不区分大小写**。

### 内置访问器（Built-in Accessors）

在所有 Wwise 对象上可用的内置访问器：

| 访问器 | 返回值类型 | 说明 | 示例 |
|--------|-----------|------|------|
| `id` | 字符串（GUID） | 128 位 GUID，格式 `"{0CB93450-E995-40E5-98A5-239F15B1F1D4}"`，项目中的唯一标识符 | `$ where id = "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"` |
| `shortId` | 数值（32 位） | Sound Engine 中使用的短 ID。唯一性范围取决于对象类型 | `$ where shortId = 1588715066` |
| `name` | 字符串 | 对象名称 | `$ where name = "Play_Hello"` |
| `notes` | 字符串 | 对象备注（也称为注释） | `$ where notes : "audiokinetic"` |
| `type` | 字符串 | 对象类型（不区分大小写） | `$ where type = "Sound"` |
| `nodeType` | 字符串 | 节点类型 | `$ where nodeType = "Sound SFX"` |
| `classId` | 数值 | 对象类 ID，表示对象类型及 Effect/Source/Conversion 插件类型 | `$ where classId = 8847363` |
| `category` | 字符串 | 对象所属的顶层文件夹名 | `$ where category = "Actor-Mixer Hierarchy"` |
| `filePath` | 字符串 | Work Unit 或 Project 的 wwu/wproj 文件绝对路径 | `$ where type = "WorkUnit" and filePath : "*wwu"` |
| `path` | 字符串 | 对象在项目中的路径，包含顶层文件夹名 | `$ where path : "microphone"` |
| `isPlayable` | 布尔值 | 对象是否可在 Transport 中播放或在 Event 中使用 | `$ where isPlayable`<br>`$ where !isPlayable` |
| `childrenCount` | 数值 | 当前对象的直接子对象数量 | `$ where childrenCount > 10` |

### 插件相关访问器

| 访问器 | 说明 | 示例 |
|--------|------|------|
| `pluginName` | 插件厂商提供的插件名称（Effects/Source/Audio Devices/Metadata） | `$ where pluginName = ""` |

### 文件相关访问器（原始文件）

适用于 Sound、AudioSource、Music Clip、Music Clip MIDI 对象：

| 访问器 | 说明 | 示例 |
|--------|------|------|
| `originalFilePath` | 原始文件的绝对路径 | `$ from type Sound where originalFilePath : "hello"` |
| `originalRelativeFilePath` | 相对于项目 Originals 文件夹的路径 | `$ from type Sound where originalFilePath : "hello"` |
| `originalTotalChannelCount` | 总声道数 | `$ from type Sound where originalTotalChannelCount > 3` |
| `originalNormalChannelCount` | 默认平面声道数 | `$ from type Sound where originalNormalChannelCount > 3` |
| `originalHeightChannelCount` | 高度平面声道数 | `$ from type Sound where originalHeightChannelCount > 0` |
| `originalLFEChannelCount` | 低频声道数 | `$ from type Sound where originalLFEChannelCount > 0` |
| `originalAnonymousChannelCount` | 匿名声道数 | `$ from type Sound where originalAnonymousChannelCount > 0` |
| `originalChannelConfig` | 声道配置字符串 | `$ from type Sound where originalChannelConfig = "7.1.4"` |
| `originalChannelMask` | 声道配置掩码 | `$ from type Sound where originalChannelMask = 185919` |
| `originalSampleRate` | 采样率 | `$ from type Sound where originalSampleRate = 48000` |
| `originalBitDepth` | 位深度 | `$ from type Sound where originalSampleRate = 16` |
| `originalFileSize` | 文件大小（字节） | `$ from type Sound where originalFileSize != 0` |
| `originalDataSize` | 数据大小（字节） | `$ from type Sound where originalDataSize != 0` |
| `originalSampleCount` | 采样数 | `$ from type Sound where originalSampleCount != 0` |
| `originalDuration` | 时长（秒），不含 trim | `$ from type Sound where originalDuration > 1` |
| `originalCodec` | 编解码器 | `$ from type Sound where originalCodec = "PCM"` |

### 文件相关访问器（转换后文件）

适用对象同上，返回转换后文件的属性：

| 访问器 | 说明 | 示例 |
|--------|------|------|
| `convertedFilePath` | 转换后文件的绝对路径 | `$ from type Sound where convertedFilePath : "hello"` |
| `convertedTotalChannelCount` | 总声道数 | `$ from type Sound where convertedTotalChannelCount > 3` |
| `convertedSampleRate` | 采样率 | `$ from type Sound where convertedSampleRate = 48000` |
| `convertedCodec` | 编解码器 | `$ from type Sound where convertedCodec = "Vorbis"` |
| `convertedDuration` | 时长（秒），不含 trim | `$ from type Sound where convertedDuration > 1` |

> 完整的 converted 系列访问器（ChannelConfig、ChannelMask、BitDepth、FileSize、DataSize 等）与 original 系列一一对应，此处不一一列举。

## 值表达式与对象表达式的链式组合

```
OBJECT_EXPRESSION.VALUE_EXPRESSION
OBJECT_EXPRESSION.OBJECT_EXPRESSION.VALUE_EXPRESSION
```

通过点号链式组合对象表达式，最后跟一个值表达式来获取链式对象的属性值：

```
$ where OutputBus.id = "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"
```

## count() 函数

`count()` 是列表函数，返回列表中**匹配指定条件的项数**。条件语句为可选。

```
$ where children.count() > 3
$ where effects.count(effect.pluginname:"eq") > 0
```

无参数时返回列表中的总项数。带条件时只计算匹配的项数。
