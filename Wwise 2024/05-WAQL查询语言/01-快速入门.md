# 01-快速入门

## WAQL 是什么

WAQL（Wwise Authoring Query Language）是 Wwise 专有的查询语言，用于查询 Wwise 项目及其对象。它**不是 SQL**，而是一门为 Wwise 对象模型设计的领域特定语言。

查询可以：
- 枚举 Wwise 对象（Sound、Container、Bus、Event、SoundBank 等）
- 按属性筛选（名称、备注、ID、音量、音高、输出总线等）
- 追踪对象引用（如 Event 的 Target、OutputBus 等）

## 在哪使用 WAQL

WAQL 可以在 Wwise 的四个位置使用（来源：官方文档）：

1. **Wwise 工具栏搜索（Toolbar Search）**
2. **列表视图搜索（List View Search）** — 官方推荐用于学习 WAQL
3. **原理图视图搜索（Schematic View Search）**
4. **WAAPI** — 通过 `ak.wwise.core.object.get` 函数

## 查询基本结构

### $ 前缀

所有 WAQL 查询都以 `$` 开头，这是 Wwise 区分**标准文本搜索**和**WAQL 查询**的方式。`$` 之后的内容定义了查询本身。

### 查询的组成

一个查询可以分解为多个部分（section），由 `from`、`where` 和 `select` 语句定义。每个部分将其输出传递给下一个部分。

```
$ SOURCE
$ SOURCE TRANSFORM
$ SOURCE TRANSFORM, TRANSFORM, ...
$ TRANSFORM
```

- **SOURCE**：对象生成器，输出一个对象序列
- **TRANSFORM**：序列变换，接收一个输入序列并输出另一个序列
- 当省略 `from` 时，隐式以项目中所有对象作为源

## 第一个查询：简单筛选

在 List View 搜索框中输入：

```
$ where volume < 0
```

**解释：**
- `$` — 告诉 Wwise 这是一个 WAQL 查询
- `where` — 过滤关键字，对每个对象执行条件判断
- `volume < 0` — 条件表达式，比较 volume 属性的数值

当以 `where` 开头时，WAQL 会自动将项目中的**每个对象**作为源，然后过滤出符合条件的对象。

**通用形式：**
```
$ where CONDITION
```

CONDITION 是一个返回 `true` 或 `false` 的布尔表达式。

### 练习

- 尝试不同运算符：`<=`、`>`、`>=`、`=`
- 将 `volume` 替换为 `pitch` 或 `lowpass`
- 使用 `and` 和 `or` 组合更复杂的表达式

> **提示：** 要了解 WAQL 属性名称，请参考 Wwise Objects Reference（官网提供）。

## 字符串条件

```
$ where name = "hello"
```

字符串条件使用等号进行**不区分大小写**的比较。当文本完全相同时返回 true。

### 单词搜索

```
$ where name : "hello"
```

使用冒号 `:` 替代等号，定义**单词搜索**运算符。当指定单词在字段中找到时返回 true。

### 通配符

可以在搜索文本中使用 `*` 通配符：
```
$ where name : "*lo"
```

## 使用 from 指定源

```
$ from type sound
```

`from` 关键字定义了查询的**起始源**（source），可以大幅缩小搜索范围，提高查询效率。

### 指定多个类型

```
$ from type randomsequencecontainer, switchcontainer, blendcontainer
```

> **注意：** 上例比等价的 `where` 写法 `where type = "randomsequencecontainer" or type = "switchcontainer" or type = "blendcontainer"` 更高效，因为后者需要遍历项目中所有对象（包括 Event、Bus、Sound 等），执行时间更长。

## 组合 from 和 where

```
$ from type sound where volume < 0
```

`from` 只能出现在查询开头，`where` 可以追加在 `from` 之后。

## 从特定对象查询

### 按路径

```
$ from object "\Actor-Mixer Hierarchy"
```

### 简化形式（省略 from object）

```
$ "\Actor-Mixer Hierarchy"
```

### 多个对象

```
$ "\Master-Mixer Hierarchy", "\Actor-Mixer Hierarchy"
```

### 按 GUID

```
$ "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"
```

### 按类型和名称

对于 Event 和 Bus 等有唯一名称的对象类型：
```
$ "Bus:Master Audio Bus"
$ "Event:Play_Hello"
```

### 快捷操作

- **Shift + 右键** → 选择 **Copy Path(s) to clipboard** 复制对象路径
- **Shift + 右键多个对象** → 选择 **Copy WAQL query to clipboard** 复制 WAQL 查询
- **Shift + 右键** → 选择 **Copy GUID(s) to clipboard** 复制 GUID

## select 选择对象

```
$ "\Actor-Mixer Hierarchy\Default Work Unit" select children
```

返回 Default Work Unit 的所有**直接子对象**。

```
$ "\Actor-Mixer Hierarchy\Default Work Unit" select descendants
```

返回所有**后代对象**（递归包含所有层级的子对象）。

## 属性链式访问（点运算符）

Wwise 对象有两种属性：

1. **返回值属性**（Value Properties）：Volume、Pitch、Lowpass 等（数值），name、notes、id、path（字符串）
2. **返回引用属性**（References）：OutputBus、Target、UserAuxSend0 等（指向另一个对象），Parent（指向父对象）

使用点号 `.` 组合属性：
```
$ where parent.name = "Music"
$ where parent.volume < 0
$ where outputbus.parent.name = "Master Audio Bus"
```

> **注意：** 返回值属性只能出现在最后一个点号之后；返回引用属性可以在链条中的任何位置。

## Event 相关查询示例

### 查找 Event 引用的所有 Sound

```
$ from type event select children select target select this, descendants where type = "sound"
```

步骤分解：
1. `from type event` — 获取所有 Event
2. `select children` — 获取 Event 的 Action（Event 的直接子对象）
3. `select target` — 获取每个 Action 的 Target
4. `select this, descendants` — 获取 Target 本身及其所有后代
5. `where type = "sound"` — 仅保留 Sound 类型的对象

### 反向查询：从 Sound 查找引用它的 Event

```
$ from type sound select this, ancestors select referencesTo where type = "action" select parent
```

## 小结

| 概念 | 说明 |
|------|------|
| `$` 前缀 | 标识 WAQL 查询 |
| `from` | 定义查询源，省略时使用整个项目 |
| `where` | 过滤对象，保留匹配条件的 |
| `select` | 从当前序列中获取新对象 |
| 查询结构 | 每个部分将其输出传递给下一个部分 |
| 点运算符 | 链式访问属性，返回值属性只能在最后一个点号之后 |
