# 05-平台与语言概念

## Wwise 平台概念

### 什么是平台

Wwise 支持为不同目标平台管理音频资产。每个平台在 Wwise 中都是一个 **Platform** 对象，具有独立的：
- 音频转换设置和编码格式
- 属性值（可为每个平台设置不同的属性值）
- 音频源文件关联

常见平台包括：**Windows、iOS、Android、PS5、Xbox Series X、Mac、Linux** 等。

### 获取平台 GUID

平台也是 Wwise 对象，可以通过 WAQL 查询：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "$ from type Platform",
        "return": ["id", "name"]
    }
}
```

**响应示例：**
```json
{
    "return": [
        {"id": "{66666666-7777-8888-9999-AAAAAAAAAAAA}", "name": "Windows"},
        {"id": "{77777777-8888-9999-AAAA-BBBBBBBBBBBB}", "name": "iOS"},
        {"id": "{88888888-9999-AAAA-BBBB-CCCCCCCCCCCC}", "name": "Android"}
    ]
}
```

### 在查询中指定平台

使用 `platform` 选项指定查询所需的平台：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "\"{24979032-B170-43E3-A2E4-469E0193E2C3}\"",
        "return": ["id", "name", "Volume", "@Volume", "isIncluded"],
        "platform": "{66666666-7777-8888-9999-AAAAAAAAAAAA}"
    }
}
```

## 属性 Link/Unlink

### 什么是 Link（属性链接）

**Link（链接）** 表示属性在所有平台上**共享同一个值**。

- 当属性被 Link 时，在所有平台上获取该属性都返回相同的值
- 修改 Link 属性的值会影响所有平台

### 什么是 Unlink（属性取消链接）

**Unlink（取消链接）** 表示属性在每个平台上具有**独立的值**。

- 每个平台可以有独立的属性值
- 不同平台之间的值互不影响
- 需要分别设置每个平台的值

### ak.wwise.core.object.setLinked

将属性、引用或对象列表**链接**或**取消链接**到特定平台。

**函数 URI：** `ak.wwise.core.object.setLinked`

**参数：**

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `object` | string (GUID/Name/Path) | ✅ 必需 | 目标对象 ID |
| `property` | string | ✅ 必需 | 属性名称，参考 Wwise Objects Reference |
| `platform` | string (GUID/Name) | ✅ 必需 | 平台 ID 或唯一名称 |
| `linked` | boolean | ✅ 必需 | `true` = 链接（共享值），`false` = 取消链接（平台独立） |

**示例 — 将 Volume 属性在 Windows 平台上取消链接：**

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.setLinked",
    "params": {
        "object": "{24979032-B170-43E3-A2E4-469E0193E2C3}",
        "property": "Volume",
        "platform": "{66666666-7777-8888-9999-AAAAAAAAAAAA}",
        "linked": false
    }
}
```

### ak.wwise.core.object.isLinked

查询属性、引用或对象列表是否已链接到特定平台。

**函数 URI：** `ak.wwise.core.object.isLinked`

**参数：**

| 参数 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `object` | string (GUID/Name/Path) | ✅ 必需 | 目标对象 ID |
| `property` | string | ✅ 必需 | 属性名称 |
| `platform` | string (GUID/Name) | ✅ 必需 | 平台 ID 或唯一名称 |

**结果：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `linked` | boolean | 该属性在指定平台上是否链接 |

**示例 — 检查 Volume 属性是否在 Windows 平台上链接：**

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.isLinked",
    "params": {
        "object": "{24979032-B170-43E3-A2E4-469E0193E2C3}",
        "property": "Volume",
        "platform": "{66666666-7777-8888-9999-AAAAAAAAAAAA}"
    }
}
```

**响应：**
```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "result": {
        "linked": true
    }
}
```

### Use @@ prefix for Override system

For references like `OutputBus`, the override system determines which value is actually used:

- `@@OutputBus` (or no prefix): Returns the value resolved by the override system — the value used for playback.
- `@OutputBus`: Returns the value directly set on the object. This is the value persisted in the Work Unit file. This value may not be in use if the object doesn't have the Override Parent option checked.

When querying platform-specific property values:
- **Single `@`** returns the value set on the object for the specified platform (may return unused/hidden values).
- **Double `@@`** (or no prefix, recommended) returns the value as resolved by the override system for the specified platform.

```json
{
    "waql": "\"{24979032-B170-43E3-A2E4-469E0193E2C3}\"",
    "return": ["@Volume", "@@Volume", "OutputBus", "@OutputBus"],
    "platform": "{66666666-7777-8888-9999-AAAAAAAAAAAA}"
}
```

## 语言概念

### SFX vs Voice 语言

Wwise 将语言分为两大类：

- **SFX（音效）语言**：音效通常与语言无关，所有本地化版本共享相同的音效资产。默认不区分语言。
- **Voice（语音）语言**：语音内容需要本地化，每种语言可以有独立的音频文件。

### 多语言音频管理

Wwise 支持通过语言（Language）对象管理多语言音频：

1. 在工程中定义语言（如 English(US)、French、Japanese 等）
2. 为 Sound Voice 类型的对象关联特定语言的音频文件
3. 生成 SoundBank 时指定目标语言

### 获取可用语言列表

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "$ from type Language",
        "return": ["id", "name"]
    }
}
```

### 在查询中指定语言

使用 `language` 选项获取特定语言的数据：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "\"{24979032-B170-43E3-A2E4-469E0193E2C3}\"",
        "return": ["id", "name", "audioSourceLanguage.name", "convertedFilePath"],
        "language": "English(US)"
    }
}
```

### 语言相关访问器

| 访问器 | 说明 |
|--------|------|
| `audioSourceLanguage` | 音频源关联的语言对象 |
| `audioSourceLanguage.id` | 语言的 GUID |
| `audioSourceLanguage.name` | 语言的名称 |

### 导入时指定语言

使用 `ak.wwise.core.audio.import` 导入音频时指定语言：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.audio.import",
    "params": {
        "importOperation": "createNew",
        "default": {
            "importLanguage": "English(US)"
        },
        "imports": [
            {
                "audioFile": "C:\\audio\\vo_line01_en.wav",
                "objectPath": "\\Actor-Mixer Hierarchy\\Default Work Unit\\VO_Line01"
            }
        ]
    }
}
```

> **注意**：语言名称区分大小写，必须与工程中定义的语言名称完全匹配。

### SoundBank 生成时的语言指定

生成 SoundBank 时，可以指定包含哪些语言：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.soundbank.generate",
    "params": {
        "soundbanks": [
            {
                "soundbank": "{AABBCC00-1122-3344-5566-77889900AABB}",
                "platforms": ["{66666666-7777-8888-9999-AAAAAAAAAAAA}"],
                "languages": ["English(US)", "French"]
            }
        ]
    }
}
```

## 平台特定属性操作示例

### 为特定平台设置属性值

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.setProperty",
    "params": {
        "object": "{24979032-B170-43E3-A2E4-469E0193E2C3}",
        "property": "Volume",
        "value": -6.0,
        "platform": "{66666666-7777-8888-9999-AAAAAAAAAAAA}"
    }
}
```

### 获取某个平台上的属性值

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "\"{24979032-B170-43E3-A2E4-469E0193E2C3}\"",
        "return": ["id", "name", "@Volume"],
        "platform": "{66666666-7777-8888-9999-AAAAAAAAAAAA}"
    }
}
```

### 批量获取多个平台的属性值

```python
from waapi import WaapiClient

client = WaapiClient()

object_id = "{24979032-B170-43E3-A2E4-469E0193E2C3}"
platforms = [
    ("Windows", "{66666666-7777-8888-9999-AAAAAAAAAAAA}"),
    ("iOS", "{77777777-8888-9999-AAAA-BBBBBBBBBBBB}"),
]

for platform_name, platform_id in platforms:
    result = client.call("ak.wwise.core.object.get", {
        "waql": f'"{object_id}"',
        "return": ["id", "name", "Volume"],
        "platform": platform_id
    })
    print(f"{platform_name}: Volume = {result['return'][0].get('Volume', 'N/A')}")

client.disconnect()
```

### Link/Unlink 典型流程

1. **检查当前链接状态**
2. **取消链接**（如果需要对特定平台设置独立值）
3. **设置平台特定值**
4. **（可选）恢复链接**以同步其他平台

```python
# Step 1: 检查状态
status = client.call("ak.wwise.core.object.isLinked", {
    "object": sound_id,
    "property": "Volume",
    "platform": windows_id
})
print(f"Linked: {status['linked']}")

# Step 2: 取消链接
if status['linked']:
    client.call("ak.wwise.core.object.setLinked", {
        "object": sound_id,
        "property": "Volume",
        "platform": windows_id,
        "linked": False
    })

# Step 3: 设置平台特定值
client.call("ak.wwise.core.object.setProperty", {
    "object": sound_id,
    "property": "Volume",
    "value": -3.0,
    "platform": windows_id
})

# Step 4: 恢复链接（可选）
client.call("ak.wwise.core.object.setLinked", {
    "object": sound_id,
    "property": "Volume",
    "platform": windows_id,
    "linked": True
})
```
