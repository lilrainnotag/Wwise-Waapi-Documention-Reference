# 02 - 批量操作模式

> **数据来源**: Audiokinetic 官方文档 — [ak.wwise.core.object.set](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=ak_wwise_core_object_set.html) 和 [Importing Audio Files and Creating Structures](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_import.html)

## 场景描述

`ak.wwise.core.object.set` 是 WAAPI 中最强大的批量操作 API，它集成了以下功能：

- ✅ 在层级中批量创建子对象（支持任意深度嵌套）
- ✅ 在列表中创建对象（RTPC、States、Effects 等）
- ✅ 设置对象的名称、注释、属性和引用
- ✅ 导入音频文件（集成 import 功能）
- ✅ 一次调用中完成上述所有操作的组合

> **官方建议**: "ak.wwise.core.object.set offers a superset of the functionalities offered in ak.wwise.core.object.create. We recommend using ak.wwise.core.object.set."

---

## 核心 API 调用链

```
1. 连接 WAAPI → WaapiClient()
2. 构造 objects 数组（定义目标对象、要创建的层级、要设置的属性）
3. 调用 ak.wwise.core.object.set(args, options=options)
4. 处理返回结果
5. 断开连接 → client.disconnect()
```

**参数结构**（来源：官方参数 Schema）：

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `objects` | array | ✅ | 要操作的对象数组 |
| `objects[].object` | string | ✅ | 目标对象的 GUID、名称或路径 |
| `objects[].children` | array | — | 要创建的子对象数组（递归） |
| `objects[].name` | string | — | 设置对象的新名称 |
| `objects[].notes` | string | — | 设置对象的注释 |
| `objects[].@PropertyName` | any | — | 设置属性值（如 `@Volume`） |
| `objects[].onNameConflict` | string | — | 命名冲突模式 |
| `objects[].listMode` | string | — | 列表操作模式 |
| `objects[].import` | object | — | 导入音频文件配置 |
| `objects[].platform` | string | — | 平台限定 |

---

## 名称冲突模式

当目标位置已存在同名对象时，通过 `onNameConflict` 控制行为：

| 模式 | 行为 |
|------|------|
| `fail` | 返回错误（默认） |
| `replace` | 删除目标对象（包括其子对象），创建新对象 |
| `rename` | 自动分配唯一名称（追加数字后缀） |
| `merge` | 复用目标对象，将指定的属性、引用和子对象合并，其余部分不变 |

> ⚠️ Work Unit 创建时不支持 `replace` 模式，只能使用 `fail`、`merge` 或 `rename`。

---

## 列表模式

当向列表（如 RTPC、States、Effects）添加对象时，通过 `listMode` 控制行为：

| 模式 | 行为 |
|------|------|
| `append` | 在现有列表尾部添加新对象（默认） |
| `replaceAll` | 移除所有现有对象后添加新对象 |

> 注意：某些列表不允许重复的等效对象（如 RTPC 列表中不能有两个相同属性的 RTPC）。

## 完整 Python 示例

### 示例 1：批量创建层级结构并导入音频

> 来源：官方 Import 页面 — "Using ak.wwise.core.object.set to import audio files and create a hierarchy of objects"

```python
from waapi import WaapiClient
import json

client = WaapiClient()

# 在 Default Work Unit 下创建一个完整的层级结构
# ActorMixer → RandomSequenceContainer → Sound(sfx) + 导入音频
args = {
    "objects": [
        {
            "object": "\\Actor-Mixer Hierarchy\\Default Work Unit",
            "children": [
                {
                    "type": "ActorMixer",
                    "name": "FootSteps",
                    "@Volume": "-2",
                    "children": [
                        {
                            "type": "RandomSequenceContainer",
                            "name": "FootStep_Concrete",
                            "@RandomOrSequence": "1",
                            "children": [
                                {
                                    "type": "Sound",
                                    "name": "FootStep_Concrete_01",
                                    "import": {
                                        "files": [
                                            {
                                                "audioFile": "C:\\wave\\cues\\FootStep_Concrete_01.wav"
                                            }
                                        ]
                                    }
                                },
                                {
                                    "type": "Sound",
                                    "name": "FootStep_Concrete_02",
                                    "import": {
                                        "files": [
                                            {
                                                "audioFile": "C:\\wave\\cues\\FootStep_Concrete_02.wav"
                                            }
                                        ]
                                    }
                                }
                            ]
                        }
                    ]
                }
            ]
        }
    ]
}

result = client.call("ak.wwise.core.object.set", args)
print("创建结果:", json.dumps(result, indent=2))

client.disconnect()
```

**说明**：这个示例展示了 `ak.wwise.core.object.set` 的全部能力：
1. 在 Actor-Mixer Hierarchy 的 Default Work Unit 下创建 ActorMixer "FootSteps"
2. 设置 Volume 属性为 -2
3. 创建子容器 RandomSequenceContainer "FootStep_Concrete"
4. 设置 RandomOrSequence 属性为 1（Sequence 模式）
5. 创建两个 Sound 对象并同时导入 WAV 音频文件

> **官方提示**: `object` 字段支持对象 ID (GUID) 和对象路径两种方式。可以通过 Shift+右键点击 Wwise 中的对象，选择 "Copy GUID(s) to clipboard" 获取 GUID，或通过 `ak.wwise.core.object.get` 按路径查询获取 ID。

### 示例 2：批量设置对象属性

```python
from waapi import WaapiClient

client = WaapiClient()

# 同时修改多个对象的属性
args = {
    "objects": [
        {
            "object": "\\Actor-Mixer Hierarchy\\Default Work Unit\\FootSteps\\FootStep_Concrete\\FootStep_Concrete_01",
            "@Volume": "-6",
            "@OutputBus": "\\Master-Mixer Hierarchy\\Default Work Unit\\Master Audio Bus",
            "notes": "Updated via WAAPI batch operation"
        },
        {
            "object": "\\Actor-Mixer Hierarchy\\Default Work Unit\\FootSteps\\FootStep_Concrete\\FootStep_Concrete_02",
            "@Volume": "-6",
            "@OutputBus": "\\Master-Mixer Hierarchy\\Default Work Unit\\Master Audio Bus",
            "notes": "Updated via WAAPI batch operation"
        }
    ]
}

result = client.call("ak.wwise.core.object.set", args)
print("批量更新完成")

client.disconnect()
```

### 示例 4：使用 merge 模式安全更新

```python
from waapi import WaapiClient

client = WaapiClient()

# 使用 merge 模式：如果对象已存在则合并更新，否则创建
args = {
    "objects": [
        {
            "object": "\\Actor-Mixer Hierarchy\\Default Work Unit\\FootSteps",
            "onNameConflict": "merge",
            "children": [
                {
                    "type": "ActorMixer",
                    "name": "FootStep_Wood",
                    "@Volume": "-4"
                }
            ]
        }
    ]
}

result = client.call("ak.wwise.core.object.set", args)
print("Merge 操作完成")

client.disconnect()
```

## 常见陷阱和注意事项

1. **对象定位**：`object` 字段支持 GUID、名称（type:name 格式）和路径三种方式。推荐使用路径或 GUID 以确保精确性。

2. **路径分隔符**：Wwise 内部路径使用 `\` 分隔。在 WAQL 字符串中需要转义为 `\\`，在参数 JSON 中通常自动处理。

3. **属性前缀**：通过 `@PropertyName` 前缀设置属性值。不支持的属性会被静默忽略。

4. **Work Unit 创建限制**：
   - 创建 Work Unit 会清除 undo/redo 历史和剪贴板
   - Work Unit 创建后会自动保存为 .wwu 文件
   - 不支持 `replace` 模式

5. **不可通过 object.set 创建的对象**：
   - **Metadata 列表**：Metadata 是插件，无法通过 WAAPI 创建
   - **Clips 列表**：Clips 需要 AudioSourceRef，无法指定
   - **Stingers 列表**（不推荐）：无法通过 WAAPI 分配 Segment
   - **Sequences 列表**（不推荐）：无法通过 WAAPI 创建 MusicClip
   - **Source/Effect/Metadata 插件**：应通过专门的插件相关 API 创建

6. **Sound 对象限制**：通过 `ak.wwise.core.object.create` 创建 Sound 对象时无法关联 WAV/MIDI 文件和语言。应使用 `ak.wwise.core.object.set`（带 import）或 `ak.wwise.core.audio.import`。

---

## 性能考量

- **批量操作**：一次 `object.set` 调用可处理多个对象的创建和修改，远优于逐个调用 `object.create`
- **深度嵌套**：虽然支持任意深度的嵌套 `children`，但极深的层级可能导致单次调用执行时间较长
- **大量音频导入**：如果需要导入大量音频文件，考虑使用 `ak.wwise.core.audio.importTabDelimited` 配合 Tab Delimited 格式文件，效率更高
- **merge 模式**：比 `replace` 模式更快，因为不需要删除和重建现有对象
