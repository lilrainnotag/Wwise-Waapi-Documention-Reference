# 01 - 通用返回属性（Built-in Accessors）

## 概述

内置访问器（Built-in Accessors）是 `ak.wwise.core.object.get` 的 `return` 选项中不需要 `@` 前缀即可使用的属性。它们返回每个 Wwise 对象的基本元数据信息。

所有内置访问器名称均为英文字符串，在 `return` 数组中直接使用，例如 `"name"`、`"id"`、`"type"`。

## @ 与 @@ 前缀的含义和区别

当访问对象属性（而非内置访问器）时，需要使用 `@` 或 `@@` 前缀：

| 前缀 | 含义 | 使用场景 |
|------|------|----------|
| `@` | 获取**该对象自身**的属性值 | 获取对象的音量：`@Volume` |
| `@@` | 获取属性的 **override 源**的值 | 当属性通过继承/共享获得时，获取源头对象的值：`@@Volume` |

### 语法规则

- 单 `@`：`@PropertyName` — 返回该对象属性的当前值
- 双 `@@`：`@@PropertyName` — 返回该对象属性的 override 来源值
- 链式访问：通过 `.` 连接，如 `@OutputBus.name`、`parent.parent.type`

## 引用链式访问语法

Wwise 支持通过点号 `.` 进行链式访问，可以访问引用对象的嵌套属性：

```
@OutputBus.name              — 获取输出总线的名称
@OutputBus.id                — 获取输出总线的 ID
parent.name                  — 获取父对象的名称
parent.parent.type           — 获取祖父对象的类型
parent.parent.parent.name    — 获取曾祖父对象的名称
Effects.first.id             — 获取第一个效果器的 ID
Effects.first.name           — 获取第一个效果器的名称
Effects.first.effect.id      — 获取第一个效果器的效果插件 ID
```

引用链可以访问 `id`、`name` 等内置访问器，也可以继续以 `@` 前缀访问属性。

## 完整内置访问器列表

以下列表从 Wwise 2024.1.14 官方文档提取，共 90+ 个访问器。

### 1. 基础标识类

| 访问器 | 类型 | 说明 |
|--------|------|------|
| `id` | string (GUID) | 对象的 GUID，格式：`{aabbcc00-1122-3344-5566-77889900aabb}` |
| `name` | string | 对象的名称 |
| `type` | string | 对象的类型，如 `Sound`、`Bus`、`Event` 等。参见 Wwise Objects Reference |
| `shortId` | integer (uint32) | 对象的 Short ID，范围 [0, 4294967295] |
| `classId` | integer (uint32) | 对象的 Class ID，范围 [0, 4294967295] |
| `pluginName` | string | 插件的名称（适用于 Source、Effect、Mixer、Device 和 Metadata 插件） |
| `category` | string | 对象所属的分类，如 `Actor-Mixer Hierarchy` |
| `path` | string | 对象从项目根目录开始的路径，如 `\Actor-Mixer Hierarchy\Default Work Unit\Sound1` |

### 2. 层级关系类

| 访问器 | 类型 | 说明 |
|--------|------|------|
| `parent` | object | 父对象。返回包含 `id` 和 `name` 字段的对象 |
| `parent.id` | string (GUID) | 父对象的 GUID |
| `parent.name` | string | 父对象的名称 |
| `owner` | object | 对象的所有者。适用于被其他对象本地拥有的对象，如自定义效果器、自定义衰减等。返回包含 `id` 和 `name` 字段的对象 |
| `owner.id` | string (GUID) | 所有者的 GUID |
| `owner.name` | string | 所有者的名称 |
| `childrenCount` | number | **（已弃用）** 对象的子对象数量。建议使用 `children.count()` 替代 |
| `workunit` | object | 包含该对象的父 Work Unit。返回 `id` 和 `name` |
| `workunit.id` | string (GUID) | Work Unit 的 GUID |
| `workunit.name` | string | Work Unit 的名称 |
| `isPlayable` | boolean | 对象是否可以在 Transport 中播放 |

### 3. 文件路径类

| 访问器 | 类型 | 说明 |
|--------|------|------|
| `filePath` | string | 包含该对象的文件路径。可以是 Work Unit 文件或项目文件。Mac 上使用 WAAPI 时请参考相关文档 |
| `sound:originalWavFilePath` | string | 原始 WAV 文件的绝对路径。仅对 Sound 和 Audio Source 对象有效 |
| `sound:convertedWemFilePath` | string | 转换后 WEM 文件的绝对路径。需在 options 中指定 platform。仅对 Sound 和 Audio Source 对象有效 |
| `soundbank:bnkFilePath` | string | 生成的 SoundBank 文件（.bnk）的绝对路径。仅对 SoundBank 对象有效 |
| `originalFilePath` | string | 原始文件的绝对路径。仅对 Sound 和 Audio Source 对象有效 |
| `originalRelativeFilePath` | string | 原始文件相对于项目 Originals 文件夹的相对路径。仅对 Sound 和 Audio Source 对象有效 |
| `convertedFilePath` | string | 转换后文件的绝对路径。需在 options 中指定 platform。仅对 Sound 和 Audio Source 对象有效 |

### 4. 已弃用的文件路径类（向后兼容）

以下访问器已被弃用，建议使用带 `:` 前缀的新版本：

| 访问器 | 类型 | 说明 |
|--------|------|------|
| `originalWavFilePath` | string | **（已弃用）** 原始 WAV 文件绝对路径。建议使用 `sound:originalWavFilePath` |
| `convertedWemFilePath` | string | **（已弃用）** 转换后 WEM 文件绝对路径。建议使用 `sound:convertedWemFilePath` |
| `soundbankBnkFilePath` | string | **（已弃用）** 生成的 SoundBank 文件路径。建议使用 `soundbank:bnkFilePath` |

| `music:playlistRoot` | object | Music Playlist Root，包含所有其他 Music Playlist Item（递归）。仅适用于 Music Playlist Container。返回 `id` 字段 |
| `musicTransitionRoot` | object | **（已弃用）** 建议使用 `music:transitionRoot` |
| `musicPlaylistRoot` | object | **（已弃用）** 建议使用 `music:playlistRoot` |

| `originalLFEChannelCount` | number | 低频声道数 |

| `originalChannelMask` | number | 声道配置对应的掩码 |
| `originalSampleRate` | number | 采样率 |
| `originalBitDepth` | number | 位深，16 或 24 |

| `originalCodec` | string | 音频编解码器。原始文件始终为 `PCM` |

### 11. Mute / Solo / Inclusion 状态类

| 访问器 | 类型 | 说明 |
|--------|------|------|
| `isExplicitMute` | boolean | 对象是否被显式静音。显式静音会隐式地静音其所有后代对象 |
| `isExplicitSolo` | boolean | 对象是否被显式独奏。独奏会使项目中除该对象外的所有其他对象静音 |
| `isImplicitMute` | boolean | 对象是否被隐式静音（因祖先被显式静音导致） |
| `isImplicitSolo` | boolean | 对象是否被隐式独奏 |
| `isIncluded` | boolean | 对象是否被包含（Included）。需在 options 中指定 platform。会考虑对象祖先的 Inclusion 状态 |

| `structureSize` | integer | 该对象及其所有子对象的元数据在 SoundBank 中占用的空间（字节）。不包含媒体文件 |

## 使用示例

### 获取基本标识信息

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["id", "name", "type", "shortId", "classId", "category", "path"]
}
```

### 获取层级关系

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["parent", "parent.name", "parent.type", "workunit", "owner"]
}
```

### 获取文件路径信息

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["sound:originalWavFilePath", "sound:convertedWemFilePath", "filePath"],
  "platform": "Windows"
}
```

### 链式引用访问

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "parent.name",
    "parent.parent.name",
    "parent.parent.type"
  ]
}
```

> **数据来源**：以上所有访问器名称、类型和说明均从 Audiokinetic 官方文档 (Wwise 2024.1.14) `ak.wwise.core.object.get` 的 Options Schema 和 Result Schema 中提取。
