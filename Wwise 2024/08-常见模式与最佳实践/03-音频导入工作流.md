# 03 - 音频导入工作流

> **数据来源**: Audiokinetic 官方文档 — [Importing Audio Files and Creating Structures](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_import.html)

## 场景描述

在游戏开发流程中，音频设计师经常需要批量导入大量音频文件并自动创建对应的 Wwise 对象结构。手动操作不仅耗时，而且容易出错。WAAPI 提供了三种编程化音频导入方式：

| 方法 | API | 适用场景 |
|------|-----|---------|
| **object.set + import** | `ak.wwise.core.object.set` | 创建层级结构的同时导入音频 |
| **audio.import** | `ak.wwise.core.audio.import` | 使用 JSON 数据批量导入 |
| **audio.importTabDelimited** | `ak.wwise.core.audio.importTabDelimited` | 使用 Tab Delimited TXT 文件导入 |

> **官方建议**: "ak.wwise.core.audio.importTabDelimited and ak.wwise.core.audio.import are the preferred ways to create Sound objects and import audio files at the same time."

音频导入支持以下功能：
- 音频文件的导入和本地化（多语言）
- 自动创建 Actor-Mixer 层级结构
- 自动创建关联的 Event
- 属性值赋值（如 Volume）
- 引用赋值（如 Output Bus）

---

## 核心 API 调用链

### 方式一：object.set + import

```
1. 连接 WAAPI → WaapiClient()
2. 构造 objects 数组，在 children 中使用 import 字段
3. 调用 ak.wwise.core.object.set(args)
4. 处理返回结果
5. 断开连接 → client.disconnect()
```

### 方式二：audio.import

```
1. 连接 WAAPI → WaapiClient()
2. 构造 import 参数（importOperation, default, imports 等）
3. 调用 ak.wwise.core.audio.import(args, options=options)
4. 处理返回结果
5. 断开连接 → client.disconnect()
```

### 方式三：audio.importTabDelimited

```
1. 连接 WAAPI → WaapiClient()
2. 准备 Tab Delimited TXT 文件（定义导入规则）
3. 调用 ak.wwise.core.audio.importTabDelimited(args)
4. 处理返回结果
5. 断开连接 → client.disconnect()
```

---

## import 字段参数（来源：官方 Schema）

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| `import.files` | array | ✅ | 要导入的音频文件数组 |
| `import.files[].audioFile` | string | — | 音频文件的绝对路径（Wwise 必须能访问） |
| `import.files[].audioFileBase64` | string | — | Base64 编码的 WAV 数据，格式: `文件名\|Base64数据` |
| `import.files[].language` | string | — | 语言的 GUID 或名称（从 WPROJ 的 LanguageList 获取） |
| `import.files[].originalsSubFolder` | string | — | Originals 文件夹下的子目录 |
| `import.files[].objectType` | string | — | 创建的对象类型（如 Sound SFX、Sound Voice） |
| `import.autoAddToSourceControl` | boolean | — | 是否自动 Add 到版本控制，默认 true |

> ⚠️ 重要：确保语言名称在工程中存在，且大小写匹配。

## 完整 Python 示例

### 示例 1：通过 object.set 导入音频并创建层级（含语言）

> 基于官方 Import 页面示例改写

```python
from waapi import WaapiClient
import json

client = WaapiClient()

# 创建一个 Sound Voice 并导入英文音频
args = {
    "objects": [
        {
            "object": "\\Actor-Mixer Hierarchy\\Default Work Unit",
            "children": [
                {
                    "type": "Sound",
                    "name": "VO_Hello",
                    "import": {
                        "autoAddToSourceControl": True,
                        "files": [
                            {
                                "audioFile": "C:\\audio\\vo\\hello_en.wav",
                                "language": "English(US)"
                            }
                        ]
                    },
                    "children": [
                        {
                            "type": "AudioFileSource",
                            "name": "Hello_EN"
                        }
                    ]
                }
            ]
        }
    ]
}

result = client.call("ak.wwise.core.object.set", args)
print("导入结果:", json.dumps(result, indent=2))

client.disconnect()
```

### 示例 2：通过 audio.import 导入多个 Sound SFX

> 基于官方 Import 页面 "Importing audio files and creating multiple Sound SFX" 示例改写

```python
from waapi import WaapiClient

client = WaapiClient()

# 使用 ak.wwise.core.audio.import 批量导入
args = {
    "importOperation": "createNew",     # createNew, useExisting, replaceExisting
    "default": {
        "importLanguage": "SFX"         # 使用 SFX 语言导入（非本地化音频）
    },
    "imports": [
        {
            "objectPath": "\\Actor-Mixer Hierarchy\\Default Work Unit\\<Sound SFX>GunShot_01",
            "audioFile": "C:\\audio\\sfx\\gunshot_01.wav"
        },
        {
            "objectPath": "\\Actor-Mixer Hierarchy\\Default Work Unit\\<Sound SFX>GunShot_02",
            "audioFile": "C:\\audio\\sfx\\gunshot_02.wav"
        },
        {
            "objectPath": "\\Actor-Mixer Hierarchy\\Default Work Unit\\<Sound SFX>Explosion_01",
            "audioFile": "C:\\audio\\sfx\\explosion_01.wav"
        }
    ]
}

options = {
    "autoAddToSourceControl": True
}

result = client.call("ak.wwise.core.audio.import", args, options=options)
print("批量导入完成")

client.disconnect()
```

**说明**：
- `importOperation`: `createNew` 创建新对象，`useExisting` 使用现有对象，`replaceExisting` 替换现有对象
- `objectPath`: 使用 `<type>name` 格式指定对象类型和名称
- `SFX` 语言：对于非本地化音频（Sound SFX），使用 `SFX` 作为语言标识

## 完整导入工作流最佳实践

### 推荐流程

```
音频源文件
    │
    ▼
┌──────────────────────────────────┐
│ 1. 扫描音频文件目录              │
│    (os.walk / glob)              │
├──────────────────────────────────┤
│ 2. 按命名规范解析元数据          │
│    (文件名→对象名/类型/语言)     │
├──────────────────────────────────┤
│ 3. 构造 import 参数              │
│    构建层级结构 + import 字段    │
├──────────────────────────────────┤
│ 4. 调用 ak.wwise.core.object.set │
│    或 ak.wwise.core.audio.import │
├──────────────────────────────────┤
│ 5. 验证导入结果                  │
│    通过 object.get 查询确认      │
├──────────────────────────────────┤
│ 6. 创建关联 Event / SoundBank    │
└──────────────────────────────────┘
```

### 目录扫描与自动导入脚本

```python
from waapi import WaapiClient
import os
import glob

def import_audio_folder(waapi_client, audio_dir, wwise_parent_path):
    """
    扫描音频目录，自动构造层级结构并导入

    约定：
    - 目录层级映射到 Wwise 对象层级
    - 顶级目录名 → ActorMixer
    - 子目录名 → RandomSequenceContainer
    - .wav 文件 → Sound SFX
    """
    objects = []

    for root, dirs, files in os.walk(audio_dir):
        # 计算在 Wwise 中的相对位置
        rel_path = os.path.relpath(root, audio_dir)
        if rel_path == ".":
            continue

        path_parts = rel_path.split(os.sep)

        # 查找 .wav 文件
        wav_files = glob.glob(os.path.join(root, "*.wav"))
        if not wav_files:
            continue

        # 构造 Sound 对象
        sounds = []
        for wav_file in wav_files:
            sound_name = os.path.splitext(os.path.basename(wav_file))[0]
            sounds.append({
                "type": "Sound",
                "name": sound_name,
                "import": {
                    "files": [{"audioFile": wav_file.replace("\\", "\\\\")}]
                }
            })

        objects.append({
            "object": wwise_parent_path,
            "children": sounds
        })

    if objects:
        args = {"objects": objects}
        result = waapi_client.call("ak.wwise.core.object.set", args)
        return result

    return None


# 使用示例
client = WaapiClient()
result = import_audio_folder(
    client,
    audio_dir="C:\\GameAssets\\Audio\\Footsteps",
    wwise_parent_path="\\Actor-Mixer Hierarchy\\Default Work Unit"
)
print(f"导入了 {len(result.get('objects', [])) if result else 0} 个对象")
client.disconnect()
```

## 常见陷阱和注意事项

1. **文件路径**：`audioFile` 路径必须是 Wwise 可以访问的绝对路径。在 Mac 上使用 WAAPI 时，路径格式需参考 [Using WAAPI on Mac](https://www.audiokinetic.com/library/edge/?source=SDK&id=waapi_mac.html)。

2. **语言大小写**：语言名称大小写必须与 WPROJ 文件中 `LanguageList` 定义完全一致。例如 `"English(US)"` 不能写成 `"english(us)"`。

3. **SFX 语言**：对于 Sound SFX（非本地化）类型，导入时使用的语言应为 `"SFX"`。

4. **Base64 导入**：支持通过 `audioFileBase64` 字段使用 Base64 编码的 WAV 数据，格式为 `"filename.wav|Base64Data"`。

5. **自动 Source Control**：`import.autoAddToSourceControl` 默认为 `true`，会自动将受影响的 Work Unit 添加到版本控制。

6. **Originals 子目录**：可通过 `originalsSubFolder` 指定音频文件在 Originals 目录中的子路径。例如对于 SFX 导入，文件将放在 `Originals\SFX\<originalsSubFolder>`。

7. **Tab Delimited 导入**：对于超大批量导入，推荐使用 `ak.wwise.core.audio.importTabDelimited`，它复用了 Wwise 内置的 Tab Delimited 导入处理器，更高效。

---

## 性能考量

- **小批量（< 100 个文件）**：使用 `ak.wwise.core.object.set`（带 import）最为灵活
- **中批量（100-1000 个文件）**：使用 `ak.wwise.core.audio.import`，构造 JSON 导入数组
- **大批量（> 1000 个文件）**：使用 `ak.wwise.core.audio.importTabDelimited`，先生成 TXT 文件再导入
- 每次导入操作都会触发 Wwise 的音频文件处理流程（转码、峰值分析等），大量文件导入会占用较长时间
- 建议导入后保存工程：调用 `ak.wwise.core.project.save`
