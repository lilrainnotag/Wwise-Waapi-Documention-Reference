# 06 - 事件订阅模式

> **数据来源**: Audiokinetic 官方文档 — [Subscribing to Topics in the Wwise Authoring API](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_subscribe.html)

## 场景描述

Wwise WAAPI 不仅支持远程过程调用（RPC），还支持**发布/订阅（Pub/Sub）模式**。通过订阅 Topic，客户端可以实时接收 Wwise 工程中的变更通知，例如：
- 对象被创建、删除、重命名
- 属性值发生变化
- 选择集发生变化
- SoundBank 生成状态通知

这使你能够在 WAAPI 客户端和 Wwise 进程之间同步数据，或实时响应 Wwise 中的操作。

---

## 核心概念

### 什么是 Topic

Topic 是 Wwise 中特定事件的**发布通道**。当 Wwise 中发生某个事件时（如对象重命名），相应的 Topic 会被发布，所有订阅者都会收到通知。

### 订阅机制

- 订阅基于 **WAMP（Web Application Messaging Protocol）** 协议
- 不同语言的 WAAPI 客户端有不同的订阅实现方式
- 当订阅一个 Topic 时，指定的**回调函数**会在 Topic 被发布时执行
- 部分 Topic 支持 **return options**，可以控制回调中传递的数据内容

### 订阅生命周期

> ⚠️ **重要**：订阅在项目关闭时会自动撤销。但以下 Topic 支持跨项目加载的订阅：
> - `ak.wwise.core.project.loaded`
> - `ak.wwise.core.project.preClosed`
> - `ak.wwise.core.project.postClosed`

---

## 核心 API 调用链

```
1. 连接 WAAPI → WaapiClient()
2. 定义回调函数
3. 调用 client.subscribe(topic, callback, options)
4. 保持连接，等待事件
5. （可选）调用 client.unsubscribe(topic, callback)
6. 断开连接 → client.disconnect()
```

## Return Options 在订阅中的使用

部分 Topic 支持 `return` 选项，可以在回调中直接获取对象数据，避免额外的查询：

```json
{
    "return": ["id", "name", "path"]
}
```

这样，每次对象名称变更时，通知会直接包含 `id`、`name` 和 `path` 信息。

---

## 示例代码

### 示例 1：订阅对象名称变更

```python
from waapi import WaapiClient

client = WaapiClient()

def on_name_changed(*args, **kwargs):
    """对象名称变更回调"""
    print(f"对象名称已变更: {kwargs}")
    # kwargs 中包含 return 选项指定的字段

# 订阅对象名称变更 Topic，附带 return options
options = {
    "return": ["id", "name", "path", "type"]
}
client.subscribe(
    "ak.wwise.core.object.nameChanged",
    on_name_changed,
    options=options
)

print("已订阅名称变更事件。在 Wwise 中修改对象名称进行测试...")
print("按 Ctrl+C 退出")

try:
    import time
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    print("退出")
    client.disconnect()
```

### 示例 2：订阅对象创建和删除

```python
client = WaapiClient()

def on_created(*args, **kwargs):
    """对象创建回调"""
    print(f"新对象已创建: {kwargs.get('name', 'unknown')} "
          f"({kwargs.get('type', 'unknown')})")

def on_deleted(*args, **kwargs):
    """对象删除回调"""
    print(f"对象已删除: {kwargs}")

# 订阅对象创建 Topic
client.subscribe(
    "ak.wwise.core.object.created",
    on_created,
    options={"return": ["id", "name", "type", "path"]}

# 订阅对象删除 Topic

    "ak.wwise.core.object.postDeleted",
    on_deleted,
    options={"return": ["id", "name", "type"]}
)

print("已订阅创建/删除事件。在 Wwise 中操作对象进行测试...")

try:
    while True:
        time.sleep(1)
except KeyboardInterrupt:
    client.disconnect()
```

### 示例 6：订阅 SoundBank 生成事件

```python
client = WaapiClient()

def on_generated(*args, **kwargs):
    """单个 SoundBank 生成完成回调"""
    bank_name = kwargs.get("soundbank", {}).get("name", "unknown")
    print(f"SoundBank '{bank_name}' 已生成")

def on_generation_done(*args, **kwargs):
    """所有 SoundBank 生成完成回调"""
    print("所有 SoundBank 生成完毕！")

client.subscribe(
    "ak.wwise.core.soundbank.generated",
    on_generated
)
client.subscribe(
    "ak.wwise.core.soundbank.generationDone",
    on_generation_done
)

# 触发 SoundBank 生成
client.call("ak.wwise.core.soundbank.generate", {
    "soundbanks": [],
    "writeToDisk": True
})

print("等待 SoundBank 生成...")

import time
time.sleep(30)  # 等待生成完成

client.disconnect()
```

## 取消订阅

```python
# 取消特定回调函数的订阅
client.unsubscribe(
    "ak.wwise.core.object.nameChanged",
    on_name_changed  # 之前注册的回调函数
)
```

## 最佳实践

1. **使用 return options**：在订阅时指定 `return` 选项避免在回调中进行额外的查询
2. **合理管理订阅生命周期**：在不需要时取消订阅，避免内存泄漏
3. **处理项目关闭**：注意项目关闭时订阅会被撤销，使用项目级别的 Topic 进行跨项目订阅
4. **错误处理**：在回调函数中添加 try-except 防止异常导致订阅链断裂
5. **避免重入**：在回调中修改工程时要小心，避免触发循环通知

## 语言差异

不同语言的 WAAPI 客户端实现订阅方式不同：

- **Python (Waapi-Client)**：使用 `client.subscribe()` 方法
- **C# WaapiClient**：通过 WAMP 接口实现
- **JavaScript/WebSocket**：直接使用 WAMP 协议

详见各语言的 WAAPI 客户端文档。
