# 05-高级查询模式

本文整理 WAQL 的高级查询模式、实际应用技巧和性能优化建议，所有示例均来自官方文档。

---

## 多条件组合查询

### AND 组合

```
$ from type sound where name = "Hello" and volume = 0
$ from type sound where volume > -3 and volume < 0
$ from type RandomSequenceContainer where childrenCount > 2 and childrenCount <= 4
```

### OR 组合

```
$ where name = "Hello" or name = "Hi"
$ from type sound where volume = -3 or volume = 0
```

### 括号分组

```
$ from type sound where (volume = -3 or volume = 0) and (name = "Hello" or name = "Hi")
```

### 逻辑非

```
$ where !(name = "Hello")
$ from type sound where !(volume < -3)
$ where !isPlayable
```

## 正则表达式搜索

WAQL 使用 **ECMAScript 正则表达式**，语法为 `= /REGEX/`：

```
$ where name = /Hello/
$ where name = /llo$/
$ where name = /[a-z][0-9]/
```

### 与通配符搜索的区别

| 方式 | 语法 | 说明 |
|------|------|------|
| 单词搜索（通配符） | `where name : "*ello"` | 使用 `*` 通配符，匹配单词的部分 |
| 正则表达式 | `where name = /llo$/` | 完整正则表达式，更强大 |

### 正则示例

```
$ from type Sound where outputbus = "Bus:Master Audio Bus" and name = /_[0-9]+$/
```

匹配以 `_` 后跟一个或多个数字结尾的 Sound 名称。

## 跨引用查询（点运算符链式）

### 查询父对象的属性

```
$ where parent.name = "Music"
$ where parent.volume < 0
$ from type Sound where parent.name : "*engine"
```

### 查询 OutputBus 链

```
$ where outputbus.parent.name = "Master Audio Bus"
$ from type Sound where @OutputBus = "Bus:Master Audio Bus"
$ where OutputBus.id = "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"
```

### 查询 Action 的 Target 属性

```
$ from type Event select children where @Target.path : "hello"
$ from type Action orderby @Target.name
```

### 查询效果器插件名

```
$ where pluginName = ""
$ from type Effect where owner.name : "*env"
```

### 查询衰减对象

```
$ from object "{CBCD492C-982D-4EE4-AE75-0019CA6577EF}" select parent.@Attenuation
```

## Event 相关高级查询

### 查找 Event 中引用的所有 Sound

这是官方的完整示例链条：

```
$ from type event select children select target select this, descendants where type = "sound"
```

**步骤分解：**
1. `from type event` → 所有 Event
2. `select children` → 每个 Event 的 Action（Event 的直接子对象）
3. `select target` → 每个 Action 的 Target 对象
4. `select this, descendants` → Target 本身 + 所有后代
5. `where type = "sound"` → 仅保留 Sound 类型

**变体：**
- 从特定 Event 开始：`$ "Event:Play_Hello" select children select target select this, descendants where type = "sound"`
- 仅筛选 Play Action：需要判断 ActionType 属性（参考 Wwise Objects Reference 中的 Action）

### 从 Sound 反向查找 Event

```
$ from type sound select this, ancestors select referencesTo where type = "action" select parent
```

**步骤分解：**
1. `from type sound` → 所有 Sound（或特定 Sound）
2. `select this, ancestors` → Sound 本身 + 所有祖先（因为父级 Random Container 也可能被 Event 引用）
3. `select referencesTo` → 查找所有引用这些对象的对象
4. `where type = "action"` → 仅保留 Action（过滤 SoundBank、SoundCaster 等引用）
5. `select parent` → 获取 Action 的父对象，即 Event

**变体：**
- 从特定 Sound 开始：`$ "Sound:MySound" select this, ancestors select referencesTo where type = "action" select parent`
- 从特定 Work Unit 下的所有对象开始

## 列表函数高级用法

### count() — 计数

```
$ where children.count() > 3
$ where effects.count(effect.pluginname:"eq") > 0
```

查找子对象超过 3 个的对象，或者有 EQ 效果器的对象。

### any() — 任意匹配

```
$ where rtpc.any()
$ where children.any(type = "Sound")
```

查找有 RTPC 的对象，或子对象中包含 Sound 的对象。

### all() — 全部匹配

```
$ where children.all(type = "Sound")
```

查找所有子对象都是 Sound 类型的对象。

### first() / last() — 首尾取项

```
$ where effects.first(effect.pluginname:"EQ") != null
$ where children.first().type = "Sound"
$ where effects.last(effect.pluginname:"EQ") != null
$ where children.last().type = "Sound"
```

### 在 select 中使用列表函数

```
$ select children.take(2)
$ select effects.skip(1)
$ select effects.at(0)
$ select effects.where(effect.pluginname:"EQ")
```

## 实际工程场景示例

### 场景 1：查找低音量 Sound

```
$ from type sound where volume < 0
```

### 场景 2：查找特定 OutputBus 的 Sound

```
$ from type Sound where @OutputBus = "Bus:Master Audio Bus"
```

### 场景 3：查找带 Aux Send 的 Sound

```
$ from type Sound where @UserAuxSend0 = "AuxBus:Hangar_Env"
$ from type Sound where @UserAuxSend0 != null
```

### 场景 4：查找 Vorbis 格式的音频

```
$ from query "\Queries\Factory Queries\Audio Source\Audio Source - Format = Vorbis"
$ from type Sound where convertedCodec = "Vorbis"
```

### 场景 5：查找音量被随机的 Sound

```
$ from type sound where randomizer("volume") != null
$ from type sound where randomizer("volume").enabled = true
```

### 场景 6：查找有 EQ 效果器的对象

```
$ where effects.count(effect.pluginname:"eq") > 0
$ where effects.first(effect.pluginname:"EQ") != null
```

### 场景 7：查找包含特定文字备注的对象

```
$ where notes : "All"
$ where notes : "*audiokinetic*"
```

### 场景 8：查找未保存更改的 Work Unit

```
$ where workunitIsDirty
```

### 场景 9：查找具有特定声道配置的文件

```
$ from type Sound where originalChannelConfig = "7.1.4"
$ from type Sound where originalTotalChannelCount > 3
```

### 场景 10：查找时长超过 1 秒的 Sound

```
$ from type Sound where originalDuration > 1
$ from type Sound where duration.max = 5
```

## 性能优化建议

### 1. 优先使用 from type 而非 where type

**低效：**
```
$ where type = "randomsequencecontainer" or type = "switchcontainer" or type = "blendcontainer"
```
这会遍历项目中所有对象。

**高效：**
```
$ from type randomsequencecontainer, switchcontainer, blendcontainer
```
只遍历指定类型的对象。

### 2. 尽早过滤

在 Transform 链中，将 `where` 放在尽可能早的位置，减少后续 Transform 处理的对象数量。

**推荐：**
```
$ from type sound where volume < 0 select parent
```
先过滤再 select，而非 `select parent` 后再 `where volume < 0`。

### 3. 限制返回数量

在不需要完整结果集时使用 `take`/`skip`：

```
$ from type Sound take 10
$ from type Sound skip 10 take 5
```

### 4. 注意 orderby 和 distinct 的内存消耗

`orderby` 和 `distinct` 都需要分配等于输入序列大小的内存。在大型项目中，先使用 `where` 缩小序列再排序/去重：

```
$ from type sound where volume < 0 orderby name
```

而非：
```
$ from type sound orderby name
```

### 5. 使用 from object 精确定位

当知道目标对象的确切路径时，直接从该对象开始查询，而不是从整个项目开始：

```
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants where @Volume < 0
```

### 6. distinct 和 orderby 的正确顺序

```
$ ... distinct orderby name
```

`distinct` 会改变顺序，应将 `orderby` 放在 `distinct` 之后。
