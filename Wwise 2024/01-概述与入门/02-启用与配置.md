# 02-启用与配置

## 启用 WAAPI

WAAPI 默认情况下是启用的。在开始使用之前，建议检查其偏好设置，确认 WAAPI 已启用并了解安全配置。

### 启用步骤

1. 在 Wwise 中，选择 **Project > User Preferences**（默认快捷键：**Shift + U**）
2. 在 **Wwise Authoring API** 分组框中，勾选 **Enable Wwise Authoring API**
3. 点击 **OK**

完成以上步骤后，WAAPI 即可使用。

## WAMP 端口配置

WAAPI 的 WAMP 协议默认使用 **8080** 端口。WAMP 使用 WebSocket 作为传输层，提供有序、可靠、双向、面向消息的通信。

### 默认连接地址

```
ws://127.0.0.1:8080/waapi
```

## HTTP 端口配置

WAAPI 的 HTTP POST 协议默认使用 **8090** 端口。HTTP POST 允许调用方发送 JSON 文档体（对应函数参数）并通过 HTTP 响应接收 JSON 结果。

### 默认连接地址

```
http://127.0.0.1:8090/waapi
```

## 网络安全性

由于 WAAPI 允许远程控制 Wwise，必须在安全环境中使用，以防止他人获取对计算机的控制权。如果配置不当，可能存在安全风险。

### 阻止对 WAAPI 端口的访问

WAAPI 提供两个端口供 WAMP 和 HTTP 使用（默认：8080 和 8090）。为了更高的安全性，建议使用**防火墙**阻止远程计算机访问这些端口。如果需要允许远程计算机访问 WAAPI，建议将其加入**白名单**，而不是开放所有远程连接。

### 限制 IP 地址访问

默认情况下，WAAPI **仅接受来自 localhost（127.0.0.1 或 ::1）的连接**。

从远程计算机访问 WAAPI 将会失败，除非在 User Preferences 中添加该 IP 地址：

1. 从 Wwise 主菜单选择 **Project > User Preferences**
2. 在 **Allow connections from** 字段中添加 IP 地址。例如：
   - IPv4 地址：`203.0.113.255`
   - IPv6 地址：`2001:db8::`
3. 点击 **OK**

> ⚠️ **警告：** 可以添加 `*` 来允许任意 IP 地址的连接，但这是不安全的，不推荐。

### 防止跨站脚本攻击（Cross-Site Scripting）

WAAPI 提供了针对跨站脚本攻击的安全层。否则，当访问包含 JavaScript 代码的网页时，该代码理论上可以通过加载的网页获取对 Wwise 的访问权限。在这种情况下，防火墙是不够的。

WAAPI 的安全层依赖于**浏览器安全设置**。默认情况下，WAAPI 仅接受来自本地软件或从本地文件系统打开 HTML 文件的浏览器连接。

从其他主机加载的网页中使用 WAAPI 将会失败，除非在 User Preferences 中添加该主机为有效来源（origin）：

1. 从 Wwise 主菜单选择 **Project > User Preferences**
2. 在 **Allow browser connections from origins** 字段中添加主机 URI。例如：
   - `http://www.myhost.com`（假设端口 80）
   - `http://www.myhost.com:1234`（假设端口为 1234）
3. 点击 **OK**

> ⚠️ **警告：** 可以添加 `*` 来允许任意来源的网页连接，但这是不安全的，不推荐。

> ℹ️ **注意：** 如果通过浏览器连接到 WAAPI，必须同时添加 Web 服务器的 IP 地址和 origin（来源），连接才能被允许。

## 多客户端支持

WAAPI 支持同时多个连接：
- **WAMP**：最大 20 个活动连接
- **HTTP POST**：最大 20 个活动连接

## Mac 平台注意事项

WAAPI 在 Mac 上使用 **Windows 风格的路径**访问文件：

- 根目录 `/` 映射为驱动器 **Z**
- 主目录（home）映射为驱动器 **Y**

例如，加载项目 `/Volumes/path/to/MyProject.wproj` 时，必须使用路径：

```
Z:\Volumes\path\to\MyProject.wproj
```

> 💡 如果不确定，可以参考 Wwise 中"最近项目"（Recent Projects）列表里显示的项目路径。
