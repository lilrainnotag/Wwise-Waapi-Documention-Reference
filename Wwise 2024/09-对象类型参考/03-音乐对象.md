# 03-音乐对象（Music Objects）

> **来源**: [Audiokinetic 官方文档 - Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_object_reference.html)

## 概述

音乐对象位于 **Interactive Music Hierarchy** 中，专门用于创建交互式音乐系统。Wwise 提供了丰富的音乐对象层次结构，支持动态音乐播放、切换、过渡、Stinger 插入等高级功能。

## 音乐对象层级关系

```
MusicPlaylistContainer / MusicSwitchContainer
│
├── MusicPlaylistItem（仅 MusicPlaylistContainer）
│   └── MusicSegment
│       ├── MusicTrack
│       │   ├── MusicClip（音频片段）
│       │   └── MusicClipMidi（MIDI 片段）
│       └── MusicTrack
│           └── MusicTrackSequence
│               └── MusicClip / MusicClipMidi
│
├── MusicCue → MusicSegment（提示点跳转）
├── MusicFade（淡入淡出设置）
├── MusicStinger（短音乐片段插入）
└── MusicTransition（段落间过渡规则）
```

## 类型列表

### MusicSegment

音乐段落，是交互音乐系统中承载实际音频内容的核心对象。

- **ClassID**: 1769488
- **WAAPI 类型名**: `MusicSegment`
- **说明**: 音乐段落是交互音乐中最基本的播放单元，包含多条 MusicTrack。每个 MusicTrack 可以包含多个 MusicClip（音频）或 MusicClipMidi（MIDI）。MusicSegment 可以设置入口（Entry Cue）、出口（Exit Cue）和其他提示点。
- **所属层级**: Interactive Music Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `Duration` | number | 时长（秒，只读） |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | MusicTrack | 包含的音乐轨道列表 |
| `Cues` | MusicCue | 提示点列表 |
| `Stingers` | MusicStinger | Stinger 列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |

---

### MusicPlaylistContainer

音乐播放列表容器，按播放列表的方式组织 MusicSegment 的播放。

- **ClassID**: 2228240
- **WAAPI 类型名**: `MusicPlaylistContainer`
- **说明**: 音乐播放列表容器通过 MusicPlaylistItem 来组织多个 MusicSegment，支持随机和序列两种播放组模式。每个 MusicPlaylistItem 指向一个 MusicSegment 并有权重设置。
- **所属层级**: Interactive Music Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `RandomOrSequence` | number | 播放模式：0 = 随机, 1 = 序列 |
| `Loop` | boolean | 是否循环 |
| `TransitionTime` | number | 过渡时间 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | MusicPlaylistItem | 播放列表项列表 |
| `Transitions` | MusicTransition | 过渡规则列表 |
| `Stingers` | MusicStinger | Stinger 列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |

---

### MusicPlaylistItem

音乐播放列表项，是 MusicPlaylistContainer 的子对象，指向一个 MusicSegment。

- **ClassID**: 2359312
- **WAAPI 类型名**: `MusicPlaylistItem`
- **说明**: 播放列表项属于 MusicPlaylistContainer，每个项引用一个 MusicSegment。支持权重的随机播放和循环设置。
- **所属层级**: Interactive Music Hierarchy（作为 MusicPlaylistContainer 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Weight` | number | 播放权重（随机模式下） |
| `LoopCount` | number | 循环次数 |
| `PlayAt` | number | 播放起始时间 |

---

### MusicSwitchContainer

音乐开关容器，根据 Switch 的状态选择播放哪个音乐段落。

- **ClassID**: 2293776
- **WAAPI 类型名**: `MusicSwitchContainer`
- **说明**: 音乐开关容器与普通 SwitchContainer 类似，但专门用于交互音乐。它根据关联的 Switch Group 的 Switch 值切换播放不同的 MusicSegment 或子 MusicPlaylistContainer。
- **所属层级**: Interactive Music Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |
| `ContinuePlayback` | boolean | 是否继续播放（切换时） |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |
| `SwitchGroupDefault` | SwitchGroup | 关联的默认开关组 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | MusicSegment / MusicPlaylistContainer | 子音乐对象列表 |
| `Transitions` | MusicTransition | 过渡规则列表 |
| `Stingers` | MusicStinger | Stinger 列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |

---

### MusicTrack

音乐轨道，是 MusicSegment 的子对象，承载实际的音频或 MIDI 片段。

- **ClassID**: 1835024
- **WAAPI 类型名**: `MusicTrack`
- **说明**: 音乐轨道承载 MusicClip 或 MusicClipMidi。多条 MusicTrack 可以同时在 MusicSegment 中播放，实现多轨混合。每条轨道可以通过 Sub-Track 进一步组织。
- **所属层级**: Interactive Music Hierarchy（作为 MusicSegment 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | MusicClip / MusicClipMidi / MusicTrackSequence | 子对象列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |

---

### MusicTrackSequence

音乐轨道序列，用于在单个轨道上组织多个 MusicClip 的序列播放。

- **ClassID**: 3801104
- **WAAPI 类型名**: `MusicTrackSequence`
- **说明**: 音乐轨道序列是 MusicTrack 的子对象，用于在单个轨道上按时间顺序组织多个 MusicClip 或 MusicClipMidi 的播放序列。
- **所属层级**: Interactive Music Hierarchy（作为 MusicTrack 的子对象）

---

### MusicClip

音乐片段，引用磁盘上的音频文件。

- **ClassID**: 3932176
- **WAAPI 类型名**: `MusicClip`
- **说明**: 音乐片段是交互音乐中最底层的音频载体，关联到实际的 WAV 音频文件。MusicClip 位于 MusicTrack 或 MusicTrackSequence 下。
- **所属层级**: Interactive Music Hierarchy（作为 MusicTrack 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量偏移 |
| `OriginalWavFilePath` | string | 原始音频文件路径（只读） |
| `PlaybackDuration` | number | 播放时长（只读） |

---

### MusicClipMidi

MIDI 音乐片段，引用磁盘上的 MIDI 文件。

- **ClassID**: 4063248
- **WAAPI 类型名**: `MusicClipMidi`
- **说明**: MIDI 音乐片段关联到 MIDI 文件，用于驱动合成器插件生成音乐。
- **所属层级**: Interactive Music Hierarchy（作为 MusicTrack 的子对象）

---

### MusicCue

音乐提示点，标记在 MusicSegment 中的时间位置，用于跳转和同步。

- **ClassID**: 3866640
- **WAAPI 类型名**: `MusicCue`
- **说明**: 音乐提示点是 MusicSegment 中定义的时间标记。包括 Entry Cue（入口）、Exit Cue（出口）和 Custom Cue（自定义提示点）。用于音乐过渡时指定跳转位置。
- **所属层级**: Interactive Music Hierarchy（作为 MusicSegment 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Time` | number | 提示点所在的时间位置（秒） |
| `Type` | string | 提示点类型：Entry / Exit / Custom |

---

### MusicEventCue

音乐事件提示点，在 MusicSegment 的特定时间触发游戏事件。

- **ClassID**: 5046288
- **WAAPI 类型名**: `MusicEventCue`
- **说明**: 音乐事件提示点在音乐播放到特定时间时发送通知，可用于同步游戏画面与音乐。
- **所属层级**: Interactive Music Hierarchy

---

### MusicFade

音乐淡入淡出设置，定义音乐过渡时的音量变化。

- **ClassID**: 2555920
- **WAAPI 类型名**: `MusicFade`
- **说明**: 音乐淡入淡出定义了音乐过渡（Transition）中的音量变化曲线，包括淡出时间和淡入时间等参数。
- **所属层级**: Interactive Music Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `FadeOutTime` | number | 淡出时间（秒） |
| `FadeInTime` | number | 淡入时间（秒） |
| `FadeOffsetTime` | number | 淡入淡出偏移时间（秒） |
| `FadeCurve` | number | 淡入淡出曲线类型 |

---

### MusicStinger

音乐 Stinger，在音乐播放过程中插入的短音乐片段（如胜利音效、提示音等）。

- **ClassID**: 2490384
- **WAAPI 类型名**: `MusicStinger`
- **说明**: 音乐 Stinger 是在现有音乐播放中插入的短音乐片段，通过与 Trigger 关联来触发。常用于游戏中的"胜利"、"失败"等短音乐提示。
- **所属层级**: Interactive Music Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `TriggerAt` | number | 触发位置（秒） |

---

### MusicTransition

音乐过渡，定义两个 MusicSegment 之间的过渡规则。

- **ClassID**: 2424848
- **WAAPI 类型名**: `MusicTransition`
- **说明**: 音乐过渡定义了从源 MusicSegment 到目标 MusicSegment 的过渡方式，包括淡入淡出、提示点跳转等规则。
- **所属层级**: Interactive Music Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `SourceCue` | reference | 源提示点 |
| `DestinationCue` | reference | 目标提示点 |
| `TransitionType` | number | 过渡类型 |

## WAAPI 操作示例

### 创建 MusicPlaylistContainer 和 MusicSegment

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Interactive Music Hierarchy\\Default Work Unit\\",
        "type": "MusicPlaylistContainer",
        "name": "CombatMusic",
        "@RandomOrSequence": 0,
        "@Loop": true,
        "children": [
            {
                "type": "MusicSegment",
                "name": "Combat_Intro"
            },
            {
                "type": "MusicSegment",
                "name": "Combat_Loop"
            }
        ]
    }
}
```

### 创建 MusicSegment 及其下的 MusicTrack 和 MusicClip

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{MUSIC_PLAYLIST_GUID}",
        "type": "MusicSegment",
        "name": "Combat_Loop",
        "children": [
            {
                "type": "MusicTrack",
                "name": "Drums",
                "children": [
                    {
                        "type": "MusicClip",
                        "name": "Drums_Loop"
                    }
                ]
            },
            {
                "type": "MusicTrack",
                "name": "Bass",
                "children": [
                    {
                        "type": "MusicClip",
                        "name": "Bass_Loop"
                    }
                ]
            }
        ]
    }
}
```

### 查询音乐层级结构

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"search": ["\\Interactive Music Hierarchy"]},
        "transform": [
            {"select": ["descendants"]},
            {"where": ["type:isIn", ["MusicSegment", "MusicPlaylistContainer", "MusicSwitchContainer"]]}
        ],
        "options": [{"return": ["id", "name", "type", "Duration"]}]
    }
}
```
