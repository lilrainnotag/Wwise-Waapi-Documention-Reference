# 03-快速入门

## 前提条件

1. 确保 WAAPI 已在 Wwise 中启用（参见 [02-启用与配置.md](./02-启用与配置.md)）
2. Wwise Authoring 应用程序正在运行
3. 已打开一个 Wwise 项目
4. 确认 WAMP 端口（默认 8080）或 HTTP 端口（默认 8090）未被防火墙阻止
5. 选择一种编程语言和相应的 WAAPI 客户端库

> ℹ️ **推荐使用 Python + waapi-client**，官方认为这是最容易上手的方式。

## 通信协议选择

WAAPI 提供两种协议：

| 协议 | URL 格式 | 特点 |
|------|----------|------|
| WAMP | `ws://127.0.0.1:8080/waapi` | 双向通信，支持 Pub/Sub，性能最佳 |
| HTTP POST | `http://127.0.0.1:8090/waapi` | 仅支持 RPC，简单直接 |

以下示例以 **Python (waapi-client)** 为主，同时提供 WAMP 和 HTTP 的 JSON-RPC 格式参考。

## 步骤 1：测试连接（ak.wwise.core.ping）

### 功能说明
验证 WAAPI 当前是否可用。注意：当 Wwise 显示模态对话框时，WAAPI 不可用。

### Python (waapi-client) 示例

```python
from waapi import WaapiClient

# 连接（默认 URL: ws://127.0.0.1:8080/waapi）
client = WaapiClient()

# 调用 ping
result = client.call("ak.wwise.core.ping")
print(result)  # 输出: {'isAvailable': True}

# 断开连接
client.disconnect()
```

### WAMP 格式（JSON-RPC 风格请求）

```json
// 请求 (CALL 消息类型码 2)
[2, "1", "ak.wwise.core.ping", {}]
```

```json
// 响应 (RESULT 消息类型码 3)
[3, "1", {"isAvailable": true}]
```

### HTTP POST 格式

```http
POST /waapi HTTP/1.1
Host: 127.0.0.1:8090
Content-Type: application/json

{
    "method": "ak.wwise.core.ping",
    "params": {},
    "id": 1
}
```

```json
// 响应
{
    "result": {
        "isAvailable": true
    },
    "id": 1
}
```

### 返回值

| 名称 | 类型 | 描述 |
|------|------|------|
| isAvailable *(必填)* | boolean | 指示 WAAPI 是否可用。模态对话框显示时不可用 |

## 步骤 2：获取工程信息（ak.wwise.core.getProjectInfo）

### 功能说明
获取当前打开的 Wwise 项目的信息。

### Python (waapi-client) 示例

```python
from waapi import WaapiClient

client = WaapiClient()

# 获取项目信息
result = client.call("ak.wwise.core.getProjectInfo")
print(result)
# 输出包含项目名称、路径、GUID 等信息

client.disconnect()
```

### WAMP 格式

```json
// 请求
[2, "2", "ak.wwise.core.getProjectInfo", {}]
```

### HTTP POST 格式

```json
{
    "method": "ak.wwise.core.getProjectInfo",
    "params": {},
    "id": 2
}
```

## 步骤 3：查询对象（ak.wwise.core.object.get）

### 功能说明
使用 WAQL（Wwise Authoring Query Language）或 JSON 格式查询 Wwise 项目中的对象。

> ℹ️ **官方推荐使用 WAQL**，因为 WAQL 提供更强大的功能和覆盖范围、更好的错误处理，且更易于使用。

> 💡 WAQL 查询可以直接在 Wwise Authoring 的工具栏或 List View 搜索字段中测试。例如输入 `$ from type Event` 即可验证查询语法。

### WAQL 查询：返回指定对象的 ID、名称和音量

```python
from waapi import WaapiClient
import pprint

client = WaapiClient()

# 使用 WAQL 查询指定路径和 GUID 的对象
args = {
    "waql": "$ \"\\Audio Devices\\Default Work Unit\\System\", \"{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}\""
}

options = {
    "return": ["id", "name", "Volume"]
}

result = client.call("ak.wwise.core.object.get", args, options=options)
pprint.pprint(result)

client.disconnect()
```

### WAQL 查询：返回 Actor-Mixer Hierarchy 中所有以 "My" 开头的对象

```python
from waapi import WaapiClient
import pprint

client = WaapiClient()

# 返回以 "My" 开头的对象
args = {
    "waql": "$ \"\\Actor-Mixer Hierarchy\" select descendants where name = /^My/"
}

options = {
    "return": ["name", "id"]
}

result = client.call("ak.wwise.core.object.get", args, options=options)
pprint.pprint(result)

client.disconnect()
```

### WAQL 查询：所有 Event 类型对象

```
$ from type Event
```

### JSON 查询格式（不推荐，官方建议使用 WAQL）

JSON 查询分为两部分：

- **from**：指定查询起点（id / name / search / path / ofType）
- **transform**：指定一系列变换操作（select parent / select children / select descendants / select ancestors / select referencesTo / where / distinct）

### Return 选项说明

`return` 表达式可以指定返回的参数类型：

- `@PROPERTYNAME`：返回直接设置在对象上的值（忽略 override 系统）
- `@@PROPERTYNAME`：返回经由 override 系统解析后的值（可能继承自父对象）
- 无前缀：等价于 `@@` 前缀，返回 override 系统解析后的值（推荐）

示例：
- `volume` / `Volume` / `@Volume` / `@@Volume`：均返回对象的音量（音量不可 override，故等价）
- `OutputBus` / `@@OutputBus`：返回解析后的 Output Bus（实际用于播放的值）
- `@OutputBus`：返回直接设置在对象上的 Output Bus（可能未生效）

引用链式查询示例：
- `OutputBus.name`：返回输出总线的名称
- `parent.name`：返回父对象的名称
- `parent.parent.type`：返回祖父对象的类型
- `OutputBus.Volume`：返回输出总线的音量
- `Effects.first.effect.id`：返回第一个 Effect 的 ID

### WAMP 格式

```json
// 请求 - WAQL 查询
[2, "3", "ak.wwise.core.object.get", {
    "waql": "$ from type Event"
}, {
    "return": ["id", "name", "path"]
}]
```

### HTTP POST 格式

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "$ from type Event"
    },
    "options": {
        "return": ["id", "name", "path"]
    },
    "id": 3
}
```

## 步骤 4：创建对象（ak.wwise.core.object.create）

### 功能说明
在指定父对象下创建一个指定类型的新对象。也可用于批量创建子对象。

### Python (waapi-client) 示例

```python
from waapi import WaapiClient

client = WaapiClient()

# 在 Actor-Mixer Hierarchy 的 Default Work Unit 下创建一个 Sound SFX
args = {
    "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit",
    "type": "Sound",
    "name": "MyNewSound",
    "onNameConflict": "fail",  # fail / rename / replace / merge
    "notes": "通过 WAAPI 创建的声音对象"
}

result = client.call("ak.wwise.core.object.create", args)
print(result)
# 返回新创建对象的 GUID

client.disconnect()
```

### 参数说明

| 参数 | 类型 | 必填 | 描述 |
|------|------|------|------|
| parent * | string/list | ✅ | 父对象的 ID (GUID)、名称(path) 或路径；如果设置 list 参数，则插入到父对象的列表中 |
| type * | string | ✅ | 新对象的类型。参见 Wwise Objects Reference |
| name * | string | ✅ | 新对象的名称 |
| onNameConflict | string | ❌ | 名称冲突处理方式。可选：`rename`、`replace`、`fail`（默认）、`merge` |
| platform | string/GUID | ❌ | 设置属性时使用的平台。不指定则为所有链接的平台设置值 |
| autoAddToSourceControl | boolean | ❌ | 是否自动对受影响的 Work Unit 执行源代码管理 Add 操作。默认 true |
| id | string (GUID) | ❌ | 用于内部用途，为新对象分配指定的 GUID |
| notes | string | ❌ | 新对象的注释 |
| children | array | ❌ | 要递归创建的子对象数组 |
| @propertyName | any | ❌ | 直接设置属性值（如 `@Volume`） |

### 递归创建子对象

```python
args = {
    "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit",
    "type": "RandomSequenceContainer",
    "name": "MyContainer",
    "children": [
        {
            "type": "Sound",
            "name": "Child1",
            "@Volume": 3.0
        },
        {
            "type": "Sound",
            "name": "Child2"
        }
    ]
}
```

### WAMP 格式

```json
// 请求
[2, "4", "ak.wwise.core.object.create", {
    "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit",
    "type": "Sound",
    "name": "MyNewSound"
}]
```

```json
// 响应 - 返回新创建对象的 GUID
[3, "4", {
    "id": "{aabbcc00-1122-3344-5566-77889900aabb}",
    "name": "MyNewSound",
    "type": "Sound",
    "path": "\\Actor-Mixer Hierarchy\\Default Work Unit\\MyNewSound"
}]
```

### HTTP POST 格式

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit",
        "type": "Sound",
        "name": "MyNewSound"
    },
    "id": 4
}
```

## 步骤 5：设置属性（ak.wwise.core.object.setProperty）

### 功能说明
设置指定对象的属性值。可以指定平台来设置平台特定的属性值。

### Python (waapi-client) 示例

```python
from waapi import WaapiClient

client = WaapiClient()

# 设置 Sound 对象的音量
args = {
    "object": "{aabbcc00-1122-3344-5566-77889900aabb}",
    "property": "Volume",
    "value": -6.0
}

client.call("ak.wwise.core.object.setProperty", args)

# 为特定平台设置属性值
args_with_platform = {
    "object": "{aabbcc00-1122-3344-5566-77889900aabb}",
    "property": "Volume",
    "value": -3.0,
    "platform": "{77777777-8888-9999-AAAA-BBBBCCCCDDDD}"
}

client.call("ak.wwise.core.object.setProperty", args_with_platform)

client.disconnect()
```

### WAMP 格式

```json
// 请求
[2, "5", "ak.wwise.core.object.setProperty", {
    "object": "{aabbcc00-1122-3344-5566-77889900aabb}",
    "property": "Volume",
    "value": -6.0
}]
```

### HTTP POST 格式

```json
{
    "method": "ak.wwise.core.object.setProperty",
    "params": {
        "object": "{aabbcc00-1122-3344-5566-77889900aabb}",
        "property": "Volume",
        "value": -6.0
    },
    "id": 5
}
```

## 完整示例：从连接到创建对象的完整流程

```python
from waapi import WaapiClient

def main():
    # 连接 WAAPI
    client = WaapiClient()
    
    # 1. 测试连接
    ping = client.call("ak.wwise.core.ping")
    if not ping.get("isAvailable"):
        print("WAAPI 不可用")
        return
    print("✅ WAAPI 连接成功")
    
    # 2. 获取项目信息
    project = client.call("ak.wwise.core.getProjectInfo")
    print(f"📁 项目: {project.get('name', 'Unknown')}")
    
    # 3. 查询现有对象
    events = client.call("ak.wwise.core.object.get", {
        "waql": "$ from type Event"
    }, options={
        "return": ["id", "name", "path"]
    })
    print(f"📋 找到 {len(events.get('return', []))} 个 Event")
    
    # 4. 创建新 Sound 对象
    new_sound = client.call("ak.wwise.core.object.create", {
        "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit",
        "type": "Sound",
        "name": "WAAPI_Created_Sound"
    })
    sound_id = new_sound.get("id")
    print(f"🎵 创建 Sound 对象: {sound_id}")
    
    # 5. 设置属性
    client.call("ak.wwise.core.object.setProperty", {
        "object": sound_id,
        "property": "Volume",
        "value": -12.0
    })
    print(f"🔊 已设置音量为 -12 dB")
    
    # 断开连接
    client.disconnect()
    print("👋 已断开连接")

if __name__ == "__main__":
    main()
```
