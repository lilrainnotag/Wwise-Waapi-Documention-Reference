# 04-标识符体系

## 四种标识方式对比

WAAPI 支持四种标识 Wwise 对象的方式，各有不同的适用场景和稳定性特征。

| 方式 | 格式 | 示例 | 适用场景 | 稳定性 |
|------|------|------|---------|--------|
| **GUID** | `{XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX}` | `{24979032-B170-43E3-A2E4-469E0193E2C3}` | API 操作、持久化存储、跨工程引用 | ✅ 稳定（永不变化） |
| **Short ID** | 整数 (uint32) | `245489792` | 声音引擎运行时、Game Sync | ⚠️ 可能因工程修改而变化 |
| **Path** | `\Category\...\Name` | `\Actor-Mixer Hierarchy\Default Work Unit\MySound` | 人类可读、脚本调试 | ⚠️ 重命名/移动后变化 |
| **Name** | `Type:Name` 或 `Global:ShortId` | `Event:Play_Sound_01`, `Global:245489792` | 搜索定位、常用对象引用 | ⚠️ 不唯一，可能重复 |

### 各方式详解

### 1. GUID

**格式：** `{aabbcc00-1122-3344-5566-77889900aabb}`

GUID（全局唯一标识符）是 Wwise 为每个对象自动分配的唯一标识符，具有以下特性：
- **全局唯一**：不同工程中的对象 GUID 也不相同
- **永恒不变**：对象重命名、移动都不改变 GUID
- **API 首选**：大多数 WAAPI 函数使用 GUID 标识对象

在 Wwise 创作工具中获取 GUID：
- 按住 **Shift** 键右键点击对象，选择 **Copy GUID(s) to clipboard**

### 2. Short ID

**格式：** 32 位无符号整数 (uint32)，范围 `[0, 4294967295]`

Short ID 是 Wwise 为某些对象类型生成的数值标识符，主要用于：
- **声音引擎运行时**：性能敏感场景中，整数比较比字符串比较更高效
- **Game Sync 对象**：Event、SwitchGroup、StateGroup、GameParameter、Trigger 等

**Short ID 可能变化的原因：**
- 工程文件的物理位置变化
- 对象被删除后重新创建
- 某些工程级别的重新计算操作

**在使用 Short ID 时需要同时提供 type：**
```json
{
    "shortId": 245489792,
    "type": 10
}
```

type 取值为对象类型的枚举值：

| type 值 | 对象类型 |
|---------|---------|
| 10 | Event |
| 12 | SwitchGroup |
| 14 | StateGroup |
| 17 | EffectPlugin |
| 18 | SoundBank |
| 19 | Bus |
| 20 | AuxBus |
| 22 | GameParameter |
| 41 | Trigger |
| 68 | AudioDevicePlugin |

> **注意**：Short ID + type 的语法已被标记为 deprecated，推荐使用 WAQL 代替。

### 3. Path

**格式：** `\Category\WorkUnit\...\ObjectName`

项目路径从工程根开始，包含类别（Category）和工作单元（Work Unit）：

```
\Actor-Mixer Hierarchy\Default Work Unit\New Sound SFX
\Interactive Music Hierarchy\Default Work Unit\MyMusicSegment
\Master-Mixer Hierarchy\Default Work Unit\Master Audio Bus
\Events\Default Work Unit\Play_MySound
\SoundBanks\Default Work Unit\MySoundBank
```

**路径的特点：**
- 人类可读，便于调试和脚本编写
- 当对象被**重命名或移动**时，路径会变化
- 适合一次性脚本，不适合持久化存储

### 4. Name（类型限定名）

**格式：**
- 类型限定名：`Type:Name`（如 `Event:Play_Sound_01`）
- 全局短 ID：`Global:245489792`

**重要限制：** 只有具有全局唯一名称的对象类型才支持此格式，包括：
- Event
- SwitchGroup
- StateGroup
- GameParameter
- Trigger
- SoundBank 等

**注意：** 普通 Sound 对象的名称不是全局唯一的，不能使用 Name 方式直接标识。

## 如何获取对象的 GUID

### 方法 1：从 Wwise UI 获取

在 Wwise 创作工具中：
1. 按住 **Shift** 键
2. 右键点击目标对象
3. 选择 **Copy GUID(s) to clipboard**

### 方法 2：通过 ak.wwise.core.object.get 查询

使用已知的名称或路径查询 GUID：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "$ from type Sound where name = \"MySound\"",
        "return": ["id", "name", "path"]
    }
}
```

### 方法 3：使用 ak.wwise.ui.getSelectedObjects

获取当前在 Wwise UI 中选中的对象：

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.ui.getSelectedObjects",
    "params": {}
}
```

### 方法 4：获取所有平台 GUID

```json
{
    "id": 1,
    "jsonrpc": "2.0",
    "method": "ak.wwise.core.object.get",
    "params": {
        "waql": "$ from type Platform",
        "return": ["id", "name"]
    }
}
```

## 如何在不同标识方式之间转换

`ak.wwise.core.object.get` 是标识符转换的核心工具。通过指定不同的查询输入和返回字段，可以在各种标识方式之间互相转换。

### GUID → Path / Name / Short ID

```json
{
    "waql": "\"{24979032-B170-43E3-A2E4-469E0193E2C3}\"",
    "return": ["name", "path", "shortId", "type"]
}
```

### Path → GUID

```json
{
    "waql": "$ from path \"\\\\Actor-Mixer Hierarchy\\\\Default Work Unit\\\\MySound\"",
    "return": ["id"]
}
```

### Name → 完整信息

```json
{
    "waql": "$ from name \"Event:Play_Sound_01\"",
    "return": ["id", "name", "path", "type"]
}
```

### Short ID → GUID

```json
{
    "from": {
        "id": [
            {
                "shortId": 245489792,
                "type": 10
            }
        ]
    },
    "return": ["id", "name"]
}
```

### Name Search（模糊搜索）→ GUID 列表

```json
{
    "waql": "$ from search \"MySound\"",
    "return": ["id", "name", "path"]
}
```

## 可用的内置访问器 (Built-in Accessors)

在 `ak.wwise.core.object.get` 的 `return` 选项中，可以使用以下内置访问器：

| 访问器 | 类型 | 说明 |
|--------|------|------|
| `id` | string | 对象的 GUID |
| `name` | string | 对象名称 |
| `notes` | string | 对象备注 |
| `type` | string | 对象类型名称 |
| `pluginName` | string | 插件名称（Source/Effect/Mixer 插件） |
| `shortId` | integer | Short ID |
| `classId` | integer | Class ID |
| `category` | string | 对象所属类别（如 "Actor-Mixer Hierarchy"） |
| `filePath` | string | 包含对象的文件路径（Work Unit 或工程文件） |
| `workunit` | object | 父 Work Unit 的 id 和 name |
| `parent` | object | 父对象的 id 和 name |
| `owner` | object | 所有者的 id 和 name（自定义效果器、衰减等） |
| `path` | string | 从工程根开始的对象路径 |
| `isPlayable` | boolean | 是否可在 Transport 中播放 |
| `childrenCount` | number | 子对象数量（已弃用，推荐 children.count()） |
| `totalSize` | integer | 对象及所有子对象在 SoundBank 中的总大小（字节） |
| `mediaSize` | integer | 对象及所有子对象媒体文件的总转换大小（字节） |
| `objectSize` | integer | 对象元数据在 SoundBank 中的大小（字节） |
| `structureSize` | integer | 对象及所有子对象元数据的总大小（字节） |
| `isExplicitMute` | boolean | 是否被显式静音 |
| `isExplicitSolo` | boolean | 是否被显式独奏 |
| `isImplicitMute` | boolean | 是否被隐式静音 |
| `isImplicitSolo` | boolean | 是否被隐式独奏 |
| `isIncluded` | boolean | 对象是否被包含（考虑祖先的 Inclusion 状态） |
| `points` | array | 曲线对象的点数组 |
| `stateProperties` | array | 状态属性 |
| `stateGroups` | array | 关联的 State Group 对象 |
| `blendTracks` | array | 混合轨道 |

## 最佳实践选择建议

### 选择 GUID 的场景（推荐）

- ✅ **持久化存储**：保存对象引用到数据库或配置文件
- ✅ **跨会话操作**：脚本在多次运行间需要引用同一对象
- ✅ **跨工程引用**：不同 Wwise 工程间的对象引用
- ✅ **API 调用参数**：所有 WAAPI 函数的 `object` 参数

### 选择 Path 的场景

- ✅ **调试和开发**：快速理解脚本在操作哪个对象
- ✅ **一次性脚本**：临时脚本不需要持久化引用
- ✅ **对象创建**：指定新对象的创建位置

### 选择 Name 的场景

- ✅ **Event/Switch/State 操作**：这些全局对象类型名称唯一
- ✅ **人类友好的配置**：比 GUID 更易读

### 避免的场景

- ❌ 不要用 Short ID 做持久化存储
- ❌ 不要用 Name 标识非全局唯一的对象类型（如 Sound）
- ❌ 不要在路径中硬编码 Work Unit 名称（用户可能重命名）
