# 05-事件与动作（Event & Action Objects）

> **来源**: [Audiokinetic 官方文档 - Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_object_reference.html)

## 概述

事件系统是 Wwise 与游戏引擎交互的核心机制。游戏代码通过触发 **Event** 来控制音频播放，Event 包含若干 **Action**（动作），每个 Action 对指定的目标对象执行操作（播放、停止、设置状态等）。

## Event Action Target 关系

```
Event
├── Action（Play）—— Target：Sound / Container
├── Action（Stop）—— Target：Sound / Container
├── Action（Pause）—— Target：Sound / Container
├── Action（Resume）—— Target：Sound / Container
├── Action（Set State）—— Target：StateGroup + State
├── Action（Set Switch）—— Target：SwitchGroup + Switch
├── Action（Set Game Parameter）—— Target：GameParameter + Value
├── Action（Set RTPC）—— Target：RTPC
├── Action（Mute）—— Target：Sound / Container / Bus
├── Action（Unmute）—— Target：Sound / Container / Bus
├── Action（Bypass Effect）—— Target：Bus Effect Slot
├── Action（Reset Bypass Effect）—— Target：Bus Effect Slot
├── Action（Seek）—— Target：Sound / Container
├── Action（Release）—— Target：Sound / Container
├── Action（Use State）—— Target：StateGroup
├── Action（Break）—— Target：N/A
└── ActionException（动作异常）—— 定义特定 Platform/Language 的替代行为
```

## 类型列表

### Event

事件是触发音频行为的入口，游戏代码通过 Post Event 来激活。

- **ClassID**: 262160
- **WAAPI 类型名**: `Event`
- **说明**: 事件是 Wwise 中最核心的交互入口。每个 Event 包含一组 Action，定义了当事件被触发时要执行的操作序列。游戏引擎通过事件名称或 GUID 来触发（Post）事件。事件位于 \\Events\\ 文件夹中。
- **所属层级**: Events（独立层级）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `name` | string | 事件名称（在 \\Events\\ 下的完整路径） |
| `notes` | string | 注释/备注 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
|（无常用引用）| — | Event 主要通过列表组织 Action |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | Action | 包含的动作列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |

---

### Action

动作，定义 Event 触发时执行的具体操作。

- **ClassID**: 327696
- **WAAPI 类型名**: `Action`
- **说明**: Action 是 Event 的子对象，每个 Action 定义一个具体操作。Action 类型由 `ActionType` 属性决定。每个 Action 通常有一个 Target 引用指向要操作的目标对象。
- **所属层级**: Events（作为 Event 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `ActionType` | number | 动作类型（见下表） |
| `FadeTime` | number | 淡入淡出时间（秒） |
| `FadeInCurve` | number | 淡入曲线 |
| `FadeOutCurve` | number | 淡出曲线 |
| `Delay` | number | 动作延迟（秒） |
| `Probability` | number | 触发概率（0-100） |
| `Inclusion` | boolean | 是否包含在 SoundBank 中 |

**Action 类型枚举（ActionType）**:

| ActionType 值 | 动作名称 | 说明 |
|---------------|----------|------|
| 1 | Play | 播放目标对象 |
| 2 | Stop | 停止目标对象的播放 |
| 3 | Pause | 暂停目标对象的播放 |
| 4 | Resume | 恢复目标对象的播放 |
| 5 | Break | 中断（不常用） |
| 6 | Mute | 静音目标对象 |
| 7 | Unmute | 取消静音 |
| 8 | Set Volume | 设置音量（不常用，建议用 RTPC） |
| 9 | Reset Volume | 重置音量 |
| 10 | Set Pitch | 设置音高 |
| 11 | Reset Pitch | 重置音高 |
| 12 | Set LPF | 设置低通滤波 |
| 15 | Set HPF | 设置高通滤波 |
| 18 | Set Game Parameter | 设置游戏参数值 |
| 19 | Set Switch | 设置开关值 |
| 25 | Set State | 设置状态 |
| 27 | Bypass Effect | 旁通效果器 |
| 28 | Reset Bypass Effect | 取消旁通效果器 |
| 30 | Seek | 寻址播放位置 |
| 31 | Release | 释放（用于 Envelope） |
| 33 | Use State | 使用状态 |
| 39 | Reset State | 重置状态 |
| 40 | Set RTPC | 设置 RTPC 值 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `Target` | 多种（Sound / Container / Bus / StateGroup 等） | 动作的目标对象，根据 ActionType 不同而变化 |

---

### ActionException

动作异常规则，定义在特定平台或语言下的替代 Action。

- **ClassID**: 4980752
- **WAAPI 类型名**: `ActionException`
- **说明**: ActionException 允许为不同的 Platform 或 Language 定义替代的 Action 行为。例如在移动平台上用较短的音效替代主机平台的长音效，或为不同语言替换语音。
- **所属层级**: Events（作为 Action 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Platform` | reference | 适用的平台 |
| `Language` | reference | 适用的语言 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `Target` | 多种（Sound / Container 等） | 替代的目标对象 |

---

### DialogueEvent

对话事件，管理角色对话的播放逻辑。

- **ClassID**: 3014672
- **WAAPI 类型名**: `DialogueEvent`
- **说明**: 对话事件是专门为管理角色对话（VO）设计的对象类型。它使用 Dialogue Path（对话路径）规则根据 Game Parameter / State / Switch 动态选择要播放的音频。
- **所属层级**: Actor-Mixer Hierarchy（通常在 \\Actor-Mixer Hierarchy\\Default Work Unit\\ 下）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Probability` | number | 触发概率 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |

---

## WAAPI 操作示例

### 创建 Event 和 Play Action

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Events\\Default Work Unit\\",
        "type": "Event",
        "name": "Play_Explosion",
        "children": [
            {
                "type": "Action",
                "name": "Play",
                "@ActionType": 1
            }
        ]
    }
}
```

### 设置 Action 的 Target

```json
{
    "method": "ak.wwise.core.object.setReference",
    "params": {
        "object": "{ACTION_GUID}",
        "reference": "Target",
        "value": "{SOUND_GUID}"
    }
}
```

### 创建 Stop Action

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{EVENT_GUID}",
        "type": "Action",
        "name": "Stop",
        "@ActionType": 2
    }
}
```

### 创建 Set State Action

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{EVENT_GUID}",
        "type": "Action",
        "name": "SetState",
        "@ActionType": 25
    }
}
```

### 查询所有 Event 及其 Actions

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"search": ["\\Events"]},
        "transform": [
            {"select": ["descendants"]},
            {"where": ["type:isIn", ["Event"]]}
        ],
        "options": [{"return": ["id", "name", "children.name", "children.type", "children.ActionType"]}]
    }
}
```

### 通过 WAAPI 执行 Event（Sound Engine 侧）

```json
{
    "method": "ak.soundengine.postEvent",
    "params": {
        "event": "Play_Explosion",
        "gameObject": 1
    }
}
```

### 为 Action 创建 ActionException（平台替代）

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{ACTION_GUID}",
        "type": "ActionException",
        "name": "MobileOverride"
    }
}
```
