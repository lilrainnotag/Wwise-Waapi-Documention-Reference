# 工程事件

## 订阅机制

`ak.wwise.core.project.*` 系列 Topic 用于监听 Wwise 工程的加载、关闭和保存等生命周期事件。

**重要特性**：`project.loaded`、`project.preClosed`、`project.postClosed` 这三个 Topic 支持**跨工程加载的持久订阅**。普通订阅在工程关闭时会自动失效，但这三个 Topic 的订阅在工程关闭后依然保持，可以在下一个工程加载时继续接收事件。

---

## 事件列表

### ak.wwise.core.project.loaded

- **触发时机**：当工程成功加载后发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| （无特殊返回数据） | — | 此 Topic 为纯通知，不携带额外数据 |

- **WAMP 订阅示例**：

```python
from waapi import WaapiClient

client = WaapiClient()

def on_project_loaded(channel, **kwargs):
    print("工程已加载！")

# 此订阅在工程关闭后仍然保持，下次加载时仍会触发
sub_id = client.subscribe(
    "ak.wwise.core.project.loaded",
    callback=on_project_loaded
)
```

- **注意事项**：
  - 此 Topic 是三个**豁免 Topic** 之一，订阅不会因工程关闭而自动取消
  - 无 Options 和 Publish Schema，纯通知事件
  - 可用于在工程加载后自动执行初始化操作
  - 相关 API：`ak.wwise.ui.project.open`

---

### ak.wwise.core.project.preClosed

- **触发时机**：当工程开始关闭时发送（关闭流程的起始阶段）
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| （无特殊返回数据） | — | 此 Topic 为纯通知，不携带额外数据 |

- **WAMP 订阅示例**：

```python
def on_project_pre_closed(channel, **kwargs):
    print("工程即将关闭，执行清理操作...")
    # 可在此保存状态、关闭相关资源等

sub_id = client.subscribe(
    "ak.wwise.core.project.preClosed",
    callback=on_project_pre_closed
)
```

- **注意事项**：
  - 此 Topic 是三个**豁免 Topic** 之一，订阅不会因工程关闭而自动取消
  - 在工程实际关闭之前触发，可在此时执行清理操作
  - 与 `postClosed` 配对使用，形成关闭前/后的完整生命周期钩子

---

### ak.wwise.core.project.postClosed

- **触发时机**：当工程完全关闭后发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| （无特殊返回数据） | — | 此 Topic 为纯通知，不携带额外数据 |

- **WAMP 订阅示例**：

```python
def on_project_post_closed(channel, **kwargs):
    print("工程已完全关闭")

sub_id = client.subscribe(
    "ak.wwise.core.project.postClosed",
    callback=on_project_post_closed
)
```

- **注意事项**：
  - 此 Topic 是三个**豁免 Topic** 之一，订阅不会因工程关闭而自动取消
  - 通知发送时，工程已完全关闭，此时大部分其他订阅已自动失效

---

### ak.wwise.core.project.saved

- **触发时机**：当工程被保存时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| （无特殊返回数据） | — | 此 Topic 为纯通知，不携带额外数据（官网未提供详细 Publish Schema） |

- **WAMP 订阅示例**：

```python
def on_project_saved(channel, **kwargs):
    print("工程已保存")

sub_id = client.subscribe(
    "ak.wwise.core.project.saved",
    callback=on_project_saved
)
```

- **注意事项**：
  - 此 Topic **不是**豁免 Topic，工程关闭时订阅自动取消
  - 可用于实现自动备份等自定义保存后处理
  - 注意：频繁保存会频繁触发此事件

---

## 工程生命周期与订阅关系

```
project.loaded  →  [普通订阅全部有效]  →  project.saved（可多次）
                                            ↓
                                      project.preClosed
                                            ↓
                                    [普通订阅自动取消]
                                            ↓
                                      project.postClosed
```

- `loaded`、`preClosed`、`postClosed` 的订阅跨越整个生命周期，且支持跨工程持久化
- `saved` 和其他所有 Topic 的订阅在 `postClosed` 之前自动取消
