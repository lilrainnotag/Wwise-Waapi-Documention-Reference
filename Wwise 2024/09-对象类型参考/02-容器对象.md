# 02-容器对象（Container Objects）

> **来源**: [Audiokinetic 官方文档 - Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_object_reference.html)

## 概述

容器对象用于组织和控制一组子声音对象的播放行为。不同类型的容器提供不同的播放逻辑：随机/序列播放、基于开关选择、基于游戏参数混合等。容器对象位于 **Actor-Mixer Hierarchy** 中。

## 类型列表

### ActorMixer

Actor 混合器是最基本的容器类型，用于将一组声音逻辑分组。不提供特殊的播放逻辑，主要用于组织和为子对象设置统一的属性（如音量、总线等）。

- **ClassID**: 524304
- **WAAPI 类型名**: `ActorMixer`
- **说明**: Actor 混合器是 Wwise 中最基础的容器对象，用于将声音对象逻辑分组。它可以将音量、总线路由、效果器等设置统一应用到所有子对象上。常用于按类别分组音效（如"武器"、"脚步"等）。
- **所属层级**: Actor-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |
| `OverridePositioning` | boolean | 是否覆盖定位设置 |
| `OverrideVirtualVoice` | boolean | 是否覆盖虚拟语音设置 |
| `OverrideConversion` | boolean | 是否覆盖转换设置 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |
| `Conversion` | Conversion | 转换设置 |
| `Attenuation` | Attenuation | 衰减设置 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | 多种（Sound / Container 等） | 子对象列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |

### RandomSequenceContainer

随机/序列容器，控制子对象按随机或序列方式播放。

- **ClassID**: 589840
- **WAAPI 类型名**: `RandomSequenceContainer`
- **说明**: 随机/序列容器根据 `RandomOrSequence` 属性决定子对象的播放模式：随机模式（0）下随机挑选子对象播放，序列模式（1）下按顺序依次播放。支持 `AvoidRepeating`（避免重复）和 `PlayMode`（播放模式：连续/步进）等高级设置。
- **所属层级**: Actor-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `RandomOrSequence` | number | 播放模式：0 = 随机（Random）, 1 = 序列（Sequence） |
| `RandomAvoidRepeating` | boolean | 是否避免重复（仅随机模式） |
| `PlayMechanismStepOrContinuous` | number | 播放模式：0 = 连续（Continuous）, 1 = 步进（Step） |
| `PlayMechanismLoop` | boolean | 是否循环 |
| `PlayMechanismSpecialTransitionsValue` | number | 过渡时间 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |
| `Conversion` | Conversion | 转换设置 |
| `Attenuation` | Attenuation | 衰减设置 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | 多种（Sound / Container 等） | 子对象列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |

### SwitchContainer

开关容器，根据 Switch（开关）的状态选择播放哪个子对象或子容器。

- **ClassID**: 655376
- **WAAPI 类型名**: `SwitchContainer`
- **说明**: 开关容器根据当前选中的 Switch Group 的 Switch 值来决定播放哪个关联的子对象。每个 Switch 对应一个或多个子对象（Assignment）。常用于脚步声（根据地面材质切换音效）、武器音效（根据武器类型切换）等场景。
- **所属层级**: Actor-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `IgnoreParentMaxSoundInstance` | boolean | 是否忽略父对象的播放限制 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |
| `SwitchBehavior` | number | 播放模式：0 = Step（步进）, 1 = Continuous（连续） |
| `DefaultSwitchOrState` | reference | 默认 Switch/State |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |
| `Conversion` | Conversion | 转换设置 |
| `Attenuation` | Attenuation | 衰减设置 |
| `SwitchGroupDefault` | SwitchGroup | 关联的默认开关组 |
| `SwitchGroup` | SwitchGroup | 关联的开关组 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | 多种（Sound / Container 等） | 子对象列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |
| `SwitchAssignments` | Switch Assignment | 开关与子对象的关联列表 |

### BlendContainer

混合容器，根据 Game Parameter 的值在多个子对象之间进行交叉淡入淡出混合。

- **ClassID**: 1900560
- **WAAPI 类型名**: `BlendContainer`
- **说明**: 混合容器根据一个或多个 Game Parameter 的值在子对象（BlendTrack）之间进行实时混合。每条 BlendTrack 对应一个 Game Parameter 范围，当参数值变化时自动交叉淡入淡出。常用于按速度混合动画音效、按距离混合环境音等场景。
- **所属层级**: Actor-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |
| `Conversion` | Conversion | 转换设置 |
| `Attenuation` | Attenuation | 衰减设置 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `BlendTracks` | BlendTrack | 混合轨道列表（每条关联一个 Game Parameter 范围） |
| `children` | Sound / Container | 子对象列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |

---

### BlendTrack

混合轨道，属于 BlendContainer 的子对象，每条轨道关联一个 Game Parameter 范围。

- **ClassID**: 1966096
- **WAAPI 类型名**: `BlendTrack`
- **说明**: 混合轨道是 BlendContainer 的子对象，每一条 BlendTrack 定义一个 Game Parameter 值区间，在对应区间内播放关联的声音对象。当 Game Parameter 值在多个 BlendTrack 的交界处时，自动交叉淡入淡出。
- **所属层级**: Actor-Mixer Hierarchy（作为 BlendContainer 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `EnableCrossFading` | boolean | 是否启用交叉淡入淡出 |
| `LayerCrossFadeControlInput` | reference | 交叉淡入淡出控制的 GameParameter 引用 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | Sound / Container | 该混合轨道上的子对象列表 |

## 容器对象对比

| 容器类型 | 播放逻辑 | Game Parameter 驱动 | Switch 驱动 | 典型场景 |
|----------|----------|---------------------|-------------|----------|
| ActorMixer | 同时/混合播放子对象 | 可选（通过 RTPC） | 否 | 逻辑分组、统一控制 |
| RandomSequenceContainer | 随机或序列选择子对象 | 可选（通过 RTPC） | 否 | 音效变体、随机播放 |
| SwitchContainer | 根据 Switch 选择子对象 | 否 | 是 | 脚步声、武器音效切换 |
| BlendContainer | 按参数值混合子对象 | 是 | 否 | 速度混合、距离过渡 |

## WAAPI 操作示例

### 创建 RandomSequenceContainer

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit\\",
        "type": "RandomSequenceContainer",
        "name": "Footsteps",
        "@RandomOrSequence": 0
    }
}
```

### 创建 SwitchContainer 并关联 SwitchGroup

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit\\",
        "type": "SwitchContainer",
        "name": "FootstepSwitch",
        "children": [
            {
                "type": "Sound",
                "name": "Footstep_Concrete"
            },
            {
                "type": "Sound",
                "name": "Footstep_Grass"
            }
        ]
    }
}
```

然后设置 SwitchGroup 引用：

```json
{
    "method": "ak.wwise.core.object.setReference",
    "params": {
        "object": "{SWITCH_CONTAINER_GUID}",
        "reference": "SwitchGroupDefault",
        "value": "{SWITCH_GROUP_GUID}"
    }
}
```

### 创建 BlendContainer

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit\\",
        "type": "BlendContainer",
        "name": "SpeedBlend",
        "children": [
            {
                "type": "BlendTrack",
                "name": "Slow"
            },
            {
                "type": "BlendTrack",
                "name": "Fast"
            }
        ]
    }
}
```

### 查询容器中的子对象

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"id": ["{CONTAINER_GUID}"]},
        "transform": [
            {"select": ["children"]}
        ],
        "options": [{"return": ["id", "name", "type", "Volume"]}]
    }
}
```
