## WAAPI 端口配置

### WAMP 端口 (WaapiWampPort)

- **默认值**: `8080`
- **说明**: WebSocket/WAMP 协议使用的端口
- **配置位置**: Wwise → Project → User Preferences → Wwise Authoring API

连接示例：
```
ws://127.0.0.1:8080/waapi
```

### HTTP 端口 (WaapiHttpPort)

- **默认值**: `8090`
- **说明**: HTTP POST 协议使用的端口
- **配置位置**: Wwise → Project → User Preferences → Wwise Authoring API

连接示例：
```
http://127.0.0.1:8090/waapi
```

> WAAPI provides access to two ports for WAMP and HTTP (by default: 8080 and 8090).

> **来源**: [Preparing to use the Wwise Authoring API](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_prepare.html)

## User Preferences 配置

WAAPI 的配置位于 Wwise 的 User Preferences 中：

### 启用 WAAPI

1. 在 Wwise 中选择 **Project > User Preferences**（默认快捷键：`Shift + U`）
2. 在 **Wwise Authoring API** 组框中，勾选 **Enable Wwise Authoring API**
3. 点击 **OK**

> To enable Wwise Authoring API: In Wwise, select Project > User Preferences. (Default shortcut: Shift + U). In the Wwise Authoring API group box, select Enable Wwise Authoring API. Click OK.

> **来源**: [Preparing to use the Wwise Authoring API](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_prepare.html)

### IP 地址白名单

- 配置项: **Allow connections from**
- 默认值: 仅允许本地连接 (`127.0.0.1` 和 `::1`)
- 格式:
  - IPv4 地址: `203.0.113.255`
  - IPv6 地址: `2001:db8::`
  - 多个地址: 用逗号分隔
  - ⚠️ 通配符 `*`: 允许所有 IP（不推荐，不安全）

### Origin 白名单（浏览器）

- 配置项: **Allow browser connections from origins**
- 默认值: 仅允许本地文件系统
- 格式:
  - `http://www.myhost.com`（端口 80）
  - `http://www.myhost.com:1234`（指定端口 1234）
  - ⚠️ 通配符 `*`: 允许所有源（不推荐，不安全）

## 网络安全

### 防火墙配置

> For greater security, we recommend you block remote computers from accessing those ports, by using a Firewall. If you wish to allow remote computers to access WAAPI, we recommend adding them in a white list, instead of allowing any remote connection.

建议通过防火墙阻止远程计算机访问 WAAPI 端口，仅允许白名单中的 IP 地址。

### 跨站脚本防护

> WAAPI provides a security layer against cross-site scripting. This WAAPI security layer relies on your browser security settings.

WAAPI 提供了跨站脚本安全层，依赖浏览器的安全设置。

## Mac 路径注意事项

在 Mac 上使用 WAAPI 时，WAAPI 使用 Windows 风格路径：

- 根目录 `/` → 驱动器 `Z:`
- 用户主目录 `/Users/<name>` → 驱动器 `Y:`

例如：加载工程 `/Volumes/path/to/MyProject.wproj` 时，路径应写为：
```
Z:\Volumes\path\to\MyProject.wproj
```

> WAAPI uses Windows-style paths to access files, with the root folder "/" represented by drive Z and the home folder drive Y.

> **来源**: [Preparing to use the Wwise Authoring API](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_prepare.html)
