# UI 与其他事件

## 订阅机制



`ak.wwise.ui.*`、`ak.wwise.core.audio.*`、`ak.wwise.core.log.*`、`ak.wwise.core.switchContainer.*` 和 `ak.wwise.debug.*` 这些 Topic 涵盖 UI 操作、音频导入、日志、Switch Container 分配以及调试相关的事件通知。

---

## 事件列表

### ak.wwise.ui.selectionChanged

- **触发时机**：当 Wwise 工程中的选择（Selection）发生变化时发送
- **Options**：

| 名称 | 类型 | 说明 |
|------|------|------|
| return | array | 指定每个对象返回的数据字段 |
| platform | string 或 GUID | 平台 ID 或名称（可选，默认使用当前平台） |
| language | string 或 GUID | 语言 ID 或名称（可选） |

- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| objects * | array | 当前选中的对象列表。未选中任何对象时为空数组 |
| objects[...] | object | 选中对象。默认返回 id 和 name，可通过 options 指定更多字段 |
| objects[...].id | string | 对象的 GUID |
| objects[...].name | string | 对象的名称 |
| objects[...].type | string | 对象的类型 |
| objects[...].path | string | 对象的工程路径 |

- **WAMP 订阅示例**：

```python
from waapi import WaapiClient

client = WaapiClient()

def on_selection_changed(channel, **kwargs):
    objects = kwargs.get("objects", [])
    if objects:
        for obj in objects:
            print(f"已选中: {obj.get('name')} ({obj.get('type')})")
    else:
        print("未选中任何对象")

sub_id = client.subscribe(
    "ak.wwise.ui.selectionChanged",
    options={"return": ["id", "name", "type", "path"]},
    callback=on_selection_changed
)
```

- **WAMP 原始示例**：

```json
// 发布内容
{
    "objects": [
        {
            "id": "{object-guid-1}",
            "name": "Sound SFX",
            "type": "Sound",
            "path": "\\Actor-Mixer Hierarchy\\Default Work Unit\\Sound SFX"
        }
    ]
}
```

- **注意事项**：
  - 多选时 `objects` 数组包含所有选中的对象
  - 取消选择（点击空白区域）时 `objects` 为空数组 `[]`
  - 这是非常常用的 Topic，常用于实现"属性面板"等跟随选择的工具

### ak.wwise.ui.commands.executed

- **触发时机**：当 Wwise 命令被执行时发送。被发布的对象通常是当前选中的对象
- **Options**：

| 名称 | 类型 | 说明 |
|------|------|------|
| return | array | 指定每个对象返回的数据字段 |
| platform | string 或 GUID | 平台 ID 或名称（可选） |
| language | string 或 GUID | 语言 ID 或名称（可选） |

- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| command * | string | 被执行的命令 ID。参考 Wwise Authoring Command Identifiers 获取命令列表 |
| objects * | array | 命令执行所针对的对象列表。通常是选中的对象。若无对象则为空数组 |
| objects[...] | object | 对象信息。默认返回 id 和 name |
| objects[...].id | string | 对象的 GUID |
| objects[...].name | string | 对象的名称 |
| objects[...].type | string | 对象的类型 |

- **WAMP 订阅示例**：

```python
def on_command_executed(channel, **kwargs):
    command = kwargs.get("command", "")
    objects = kwargs.get("objects", [])
    obj_names = [o.get("name", "") for o in objects]
    print(f"命令已执行: {command} → 对象: {obj_names}")

sub_id = client.subscribe(
    "ak.wwise.ui.commands.executed",
    options={"return": ["id", "name", "type"]},
    callback=on_command_executed
)
```

- **WAMP 原始示例**：

```json
// 发布内容
{
    "command": "Play",
    "objects": [
        {
            "id": "{object-guid}",
            "name": "Sound SFX",
            "type": "Sound"
        }
    ]
}
```

- **注意事项**：
  - 可用于监听 Wwise 中的用户操作（如播放、删除、属性编辑等）
  - 命令 ID 列表参见 [Wwise Authoring Command Identifiers](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_authoring_command_identifiers.html)
  - 某些命令不涉及特定对象，此时 `objects` 为空数组

### ak.wwise.core.audio.imported

- **触发时机**：在导入操作完成时发送
- **Options**：

| 名称 | 类型 | 说明 |
|------|------|------|
| return | array | 要返回的数据字段列表 |

- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| operation * | string | 导入操作的类型。可能的值：`"CreateNewObject"`（创建新对象）、`"ReplaceFile"`（替换文件）、`"Localize"`（本地化）、`"ReplaceObject"`（替换对象） |
| objects * | array | 本次导入操作创建的对象列表 |
| objects[...] | object | 导入创建的对象。默认返回 id 和 name |
| objects[...].id | string | 对象的 GUID |
| objects[...].name | string | 对象的名称 |
| objects[...].type | string | 对象的类型 |

- **WAMP 订阅示例**：

```python
def on_audio_imported(channel, **kwargs):
    operation = kwargs.get("operation", "")
    objects = kwargs.get("objects", [])
    print(f"导入完成 [{operation}]: 创建了 {len(objects)} 个对象")
    for obj in objects:
        print(f"  - {obj.get('name')} ({obj.get('type')})")

sub_id = client.subscribe(
    "ak.wwise.core.audio.imported",
    options={"return": ["id", "name", "type", "path"]},
    callback=on_audio_imported
)
```

- **WAMP 原始示例**：

```json
// 发布内容
{
    "operation": "CreateNewObject",
    "objects": [
        {
            "id": "{object-guid}",
            "name": "ImportedSound",
            "type": "Sound",
            "path": "\\Actor-Mixer Hierarchy\\Default Work Unit\\ImportedSound"
        }
    ]
}
```

- **注意事项**：
  - 一次导入操作可能创建**多个**对象（如多声道文件拆分）
  - `operation` 字段标识了导入的具体方式
  - 与 `ak.wwise.core.object.created` 不同，此 Topic 专门针对**音频导入**操作，提供了操作类型的上下文

### ak.wwise.core.log.itemAdded

- **触发时机**：当日志中添加新条目时发送。可用于获取 SoundBank 生成日志中的条目。如需获取完整日志，使用 `ak.wwise.core.log.get`
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| item * | object | 日志中新增的条目 |
| item.message | string | 日志消息内容 |
| item.severity | string | 日志级别（如 "Message", "Warning", "Error"） |
| item.time | integer | 日志条目的时间戳 |

- **WAMP 订阅示例**：

```python
def on_log_item_added(channel, **kwargs):
    item = kwargs.get("item", {})
    print(f"[{item.get('severity')}] {item.get('time')}: {item.get('message')}")

sub_id = client.subscribe(
    "ak.wwise.core.log.itemAdded",
    callback=on_log_item_added
)
```

- **注意事项**：
  - 常用于监控 SoundBank 生成过程的日志输出
  - 获取完整历史日志请使用 RPC：`ak.wwise.core.log.get`
  - 日志级别可用于过滤（Message / Warning / Error）

### ak.wwise.core.switchContainer.assignmentAdded

- **触发时机**：当 Switch Container 中添加了一个分配（Assignment）时发送
- **Options**：

| 名称 | 类型 | 说明 |
|------|------|------|
| return | array | 要返回的数据字段列表 |

- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| switchContainer * | object | 添加了分配的 Switch Container |
| switchContainer.id | string | Switch Container 的 GUID |
| switchContainer.name | string | Switch Container 的名称 |
| switchContainer.type | string | 对象类型（通常为 "SwitchContainer"） |
| switch * | object | 分配对应的 Switch/State 对象 |
| switch.id | string | Switch/State 的 GUID |
| switch.name | string | Switch/State 的名称 |
| child * | object | 被分配的子对象 |
| child.id | string | 子对象的 GUID |
| child.name | string | 子对象的名称 |
| child.type | string | 子对象的类型 |

- **WAMP 订阅示例**：

```python
def on_assignment_added(channel, **kwargs):
    container = kwargs.get("switchContainer", {})
    switch = kwargs.get("switch", {})
    child = kwargs.get("child", {})
    print(f"Switch Container 分配: {container.get('name')} → {switch.get('name')} = {child.get('name')}")

sub_id = client.subscribe(
    "ak.wwise.core.switchContainer.assignmentAdded",
    options={"return": ["id", "name", "type"]},
    callback=on_assignment_added
)
```

- **注意事项**：
  - 返回三个关键对象：Switch Container、Switch/State 和分配的子对象
  - 与 `assignmentRemoved` 配对使用，可追踪 Switch Container 的全部分配变化

---

### ak.wwise.core.switchContainer.assignmentRemoved

- **触发时机**：当 Switch Container 中移除了一个分配（Assignment）时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| switchContainer * | object | 移除了分配的 Switch Container |
| switchContainer.id | string | Switch Container 的 GUID |
| switchContainer.name | string | Switch Container 的名称 |
| switch * | object | 被移除分配的 Switch/State 对象 |
| switch.id | string | Switch/State 的 GUID |
| switch.name | string | Switch/State 的名称 |
| child * | object | 被移除分配的子对象 |
| child.id | string | 子对象的 GUID |
| child.name | string | 子对象的名称 |

- **WAMP 订阅示例**：

```python
def on_assignment_removed(channel, **kwargs):
    container = kwargs.get("switchContainer", {})
    switch = kwargs.get("switch", {})
    child = kwargs.get("child", {})
    print(f"Switch Container 移除分配: {container.get('name')} → {switch.get('name')} = {child.get('name')}")

sub_id = client.subscribe(
    "ak.wwise.core.switchContainer.assignmentRemoved",
    options={"return": ["id", "name", "type"]},
    callback=on_assignment_removed
)
```

- **注意事项**：
  - 发布结构与 `assignmentAdded` 对称
  - 移除的分配在 Wwise 中不再有效

### ak.wwise.debug.assertFailed

- **触发时机**：当断言（Assert）失败时发送。**仅在 Debug 构建**中可用
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| message | string | 断言失败的消息内容（官网未提供详细 Publish Schema） |
| file | string | 断言失败的源文件路径（官网未提供） |
| line | integer | 断言失败的代码行号（官网未提供） |

- **WAMP 订阅示例**：

```python
def on_assert_failed(channel, **kwargs):
    print(f"断言失败: {kwargs}")

# ⚠️ 仅在 Wwise Debug 构建中可用
sub_id = client.subscribe(
    "ak.wwise.debug.assertFailed",
    callback=on_assert_failed
)
```

- **注意事项**：
  - ⚠️ **仅限 Debug 构建**：Release 构建中此 Topic 不可用
  - 用于调试和开发阶段的问题排查
  - 断言失败通常表示内部逻辑错误或意外状态
