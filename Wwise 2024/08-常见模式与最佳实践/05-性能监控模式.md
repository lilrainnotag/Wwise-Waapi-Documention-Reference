# 05 - 性能监控模式

> **数据来源**: Audiokinetic 官方文档 — [ak.wwise.core.profiler.startCapture](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=ak_wwise_core_profiler_startcapture.html)

## 场景描述

Wwise 的 Profiler（性能分析器）是调试和优化音频性能的核心工具。通过 WAAPI 可以编程化地控制 Profiler 捕获会话，实时获取性能数据，适合以下场景：

- 🔍 **自动化性能回归测试**：在 CI/CD 中自动捕获性能数据并对比基线
- 📊 **自定义性能面板**：构建定制化的性能监控仪表盘
- 🤖 **自动化测试集成**：在游戏自动化测试中嵌入音频性能验证
- 📝 **批量数据分析**：异地/异步分析大量 Profiler 捕获数据

## Profiler API 全景（来源：官方 API 列表）

### 捕获控制

| API | 说明 |
|-----|------|
| `ak.wwise.core.profiler.startCapture` | 开始性能捕获，返回捕获起始时间（毫秒） |

| `ak.wwise.core.profiler.saveCapture` | 保存捕获数据到文件 |
| `ak.wwise.core.profiler.enableProfilerData` | 启用/禁用特定类型的 Profiler 数据 |

## 核心 API 调用链

```
1. 连接 WAAPI (WAMP 推荐) → WaapiClient()
2. 启动 Profiler 捕获 → ak.wwise.core.profiler.startCapture
   └─ 返回: 捕获起始时间（毫秒）
3. 循环查询性能数据 → ak.wwise.core.profiler.getCpuUsage/getVoices/...
4. 停止捕获 → ak.wwise.core.profiler.stopCapture
5. 保存捕获文件（可选） → ak.wwise.core.profiler.saveCapture
6. 断开连接 → client.disconnect()
```

## startCapture 详解（来源：官方 Schema）

> 官方描述: "Starts the profiler capture and returns the time at the beginning of the capture, in milliseconds."

| 参数 | 说明 |
|------|------|
| （无参数） | 直接调用即可开始捕获 |

| 返回值 | 类型 | 说明 |
|--------|------|------|
| `return` | integer | 捕获时间游标值（毫秒） |

### 关联 API

- `ak.wwise.core.profiler.stopCapture` — 停止捕获
- `ak.wwise.core.profiler.getCursorTime` — 获取当前捕获游标时间
- `ak.wwise.core.profiler.getVoices` — 获取活跃 Voice 数据

## 完整 Python 示例

### 示例 1：基础 Profiler 捕获流程

> 基于官方 startCapture 描述改写

```python
from waapi import WaapiClient
import time
import json

client = WaapiClient()

# 1. 开始捕获（无参数，直接调用）
result = client.call("ak.wwise.core.profiler.startCapture")
capture_start_time = result.get("return", 0)
print(f"捕获开始，时间游标: {capture_start_time} ms")

# 2. 启动 Wwise Transport 播放（触发音频处理）
client.call("ak.wwise.core.transport.create", {
    "object": "\\Events\\Default Work Unit\\Play_Music"
})
client.call("ak.wwise.core.transport.executeAction", {
    "transport": 1,
    "action": "play"
})

# 3. 等待一段时间收集数据
print("正在收集性能数据（15 秒）...")
time.sleep(15)

# 4. 获取当前捕获游标时间
cursor_result = client.call("ak.wwise.core.profiler.getCursorTime")
print(f"当前游标时间: {cursor_result.get('return', 'N/A')} ms")

# 5. 查询 CPU 使用率（参数格式请参考各 API 官方详情页）
try:
    cpu_result = client.call("ak.wwise.core.profiler.getCpuUsage")
    print(f"CPU 使用率数据: {json.dumps(cpu_result, indent=2)}")
except Exception as e:
    print(f"CPU 查询失败: {e}")

# 6. 查询活跃 Voice
try:
    voices_result = client.call("ak.wwise.core.profiler.getVoices")
    voices = voices_result.get("return", [])
    print(f"活跃 Voice 数量: {len(voices)}")
except Exception as e:
    print(f"Voice 查询失败: {e}")

# 7. 查询总线数据
try:
    busses_result = client.call("ak.wwise.core.profiler.getBusses")
    print(f"总线数据: {json.dumps(busses_result, indent=2)[:500]}...")
except Exception as e:
    print(f"总线查询失败: {e}")

# 8. 获取性能监视器计数器
try:
    perf_result = client.call("ak.wwise.core.profiler.getPerformanceMonitor")
    print(f"性能监视器: {json.dumps(perf_result, indent=2)[:500]}...")
except Exception as e:
    print(f"性能监视器查询失败: {e}")

# 9. 停止捕获
client.call("ak.wwise.core.profiler.stopCapture")
print("捕获已停止")

# 10. 停止 Transport
client.call("ak.wwise.core.transport.executeAction", {
    "transport": 1,
    "action": "stop"
})

client.disconnect()
```

> ⚠️ **注意**: `getCpuUsage`、`getVoices`、`getBusses` 等查询 API 的精确参数格式（官网未在 startCapture 页面提供），请参考各 API 的独立详情页获取完整参数 Schema。

### 示例 2：实时 CPU 监控循环

```python
from waapi import WaapiClient
import time

client = WaapiClient()

# 开始捕获
result = client.call("ak.wwise.core.profiler.startCapture")
print(f"捕获开始，游标: {result.get('return', 'N/A')} ms")

cpu_readings = []
start_time = time.time()
duration = 30  # 监控 30 秒

print(f"正在监控 CPU（{duration} 秒）...")
while time.time() - start_time < duration:
    try:
        cpu_result = client.call("ak.wwise.core.profiler.getCpuUsage")
        cpu_readings.append({
            "timestamp": time.time(),
            "data": cpu_result
        })
        cursor = client.call("ak.wwise.core.profiler.getCursorTime")
        print(f"[{time.strftime('%H:%M:%S')}] "
              f"游标: {cursor.get('return', 'N/A')} ms")
    except Exception as e:
        print(f"查询失败: {e}")
    
    time.sleep(1)

# 停止捕获
client.call("ak.wwise.core.profiler.stopCapture")
print(f"监控完成，采集 {len(cpu_readings)} 个数据点")

# 保存捕获文件
client.call("ak.wwise.core.profiler.saveCapture", {
    "filePath": "C:\\ProfilerCaptures\\cpu_monitor.wprof"
})
print("捕获文件已保存")

client.disconnect()
```

### 示例 3：性能测试自动化框架

```python
from waapi import WaapiClient
import time
import json

client = WaapiClient()

def run_performance_test(test_name, event_path, capture_duration=10):
    """
    对指定 Event 运行性能测试，返回各项指标快照
    """
    metrics = {}
    
    # 开始捕获
    client.call("ak.wwise.core.profiler.startCapture")
    
    # 创建 Transport 并播放
    transport_result = client.call("ak.wwise.core.transport.create", {
        "object": event_path
    })
    transport_id = transport_result.get("transport")
    
    client.call("ak.wwise.core.transport.executeAction", {
        "transport": transport_id,
        "action": "play"
    })
    
    # 等待稳定播放
    time.sleep(2)
    
    # 采集数据
    print(f"  [{test_name}] 采集中({capture_duration}s)...")
    time.sleep(capture_duration)
    
    # 获取各项指标快照
    for metric, api in [
        ("voices", "ak.wwise.core.profiler.getVoices"),
        ("busses", "ak.wwise.core.profiler.getBusses"),
        ("rtpcs", "ak.wwise.core.profiler.getRTPCs"),
        ("cpu", "ak.wwise.core.profiler.getCpuUsage"),
        ("loaded_media", "ak.wwise.core.profiler.getLoadedMedia"),
        ("streamed_media", "ak.wwise.core.profiler.getStreamedMedia"),
    ]:
        try:
            result = client.call(api)
            count = len(result.get("return", []))
            metrics[metric] = count
        except Exception as e:
            metrics[metric] = f"Error: {e}"
    
    # 停止
    client.call("ak.wwise.core.transport.executeAction", {
        "transport": transport_id,
        "action": "stop"
    })
    client.call("ak.wwise.core.profiler.stopCapture")
    
    return metrics


# 运行测试套件
test_cases = [
    ("Combat_Music", "\\Events\\Default Work Unit\\Play_Music_Combat"),
    ("Ambient_BG", "\\Events\\Default Work Unit\\Play_Music_Ambient"),
    ("SFX_Burst", "\\Events\\Default Work Unit\\Play_Explosion"),
]

print("=" * 60)
print("Wwise 性能回归测试报告")
print("=" * 60)

baseline = {}  # 可加载历史基线数据进行对比

for name, path in test_cases:
    result = run_performance_test(name, path, capture_duration=8)
    print(f"\n📊 {name}:")
    for k, v in result.items():
        baseline_val = baseline.get(f"{name}_{k}", "N/A")
        print(f"   {k}: {v} (基线: {baseline_val})")

client.disconnect()
```

## 常见陷阱和注意事项

1. **WAMP 协议推荐**：Profiler 数据查询建议使用 WAMP 协议（支持双向通信和 Pub/Sub）。HTTP POST 仅支持 RPC 调用。
2. **捕获开销**：Profiler 捕获会引入性能开销，仅在需要时开启。
3. **数据量控制**：长时间捕获产生大量数据。建议在自动化流程中控制捕获时长。
4. **时序依赖**：在 `startCapture` 之后、`stopCapture` 之前查询数据。停止捕获后数据可能不可用。
5. **保存路径**：`saveCapture` 使用 Wwise 可访问的绝对路径。
6. **API 参数**：各 `get*` 查询 API 可能有各自的参数要求（如 `time`、`gameObjectId` 等），具体请参考各 API 独立详情页（官网未在 startCapture 页面列出）。
7. **Performance Monitor 计数器**：性能监视器计数器列表见 [Wwise Authoring Performance Monitor Counter Identifiers](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_performance_counters.html)。

## 性能考量

- Profiler 仅在需要时开启，避免持续运行影响正常性能
- 自动化测试建议捕获时长 10-60 秒
- 使用 `enableProfilerData` 选择性启用特定数据类型，减少开销
- 捕获文件（.wprof）支持离线分析和对比
- 大型工程的 Voice 数据可能很庞大，注意内存占用
