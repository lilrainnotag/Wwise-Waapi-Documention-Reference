# 03 - 特殊返回选项（Special Return Options）

## 概述

除了内置访问器和 `@` 前缀属性外，Wwise WAAPI 还提供了一些**特殊返回选项**，它们具有独特的命名空间前缀（如 `sound:`、`music:`、`audioSource:`、`workunit:`、`soundbank:`）或返回结构化对象。

这些选项在 `return` 数组中与其他选项一样使用，不需要 `@` 前缀。

---

## audioPeaks 相关

> **注意**：`audioPeaks` 是一个独立的 API 函数集，不作为 `ak.wwise.core.object.get` 的 return 选项使用。

获取音频峰值数据应使用以下专用 API：

| API 函数 | 说明 |
|----------|------|
| `ak.wwise.core.audioSourcePeaks.getMinMaxPeaksInRegion` | 获取指定区域的音频峰值最小/最大值 |
| `ak.wwise.core.audioSourcePeaks.getMinMaxPeaksInTrimmedRegion` | 获取裁剪后区域的音频峰值最小/最大值 |

这些 API 直接作用于 Audio Source 对象，通过参数指定时间范围和通道等。

## 文件路径选项

### sound:originalWavFilePath

返回 Sound 或 Audio Source 对象关联的**原始 WAV 文件**的绝对路径。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["sound:originalWavFilePath"]
}
```

- **适用对象**：Sound、Audio Source
- **返回类型**：string
- **路径格式**：绝对路径（如 `C:\Project\Originals\SFX\explosion.wav`）
- **Mac 注意**：Mac 上使用 WAAPI 时需参考相关文档

### sound:convertedWemFilePath

返回 Sound 或 Audio Source 对象关联的**转换后 WEM 文件**的绝对路径。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["sound:convertedWemFilePath"],
  "platform": "Windows"
}
```

- **适用对象**：Sound、Audio Source
- **返回类型**：string
- **需要指定**：`platform` 参数（因为不同平台转换结果不同）
- **Mac 注意**：Mac 上使用 WAAPI 时需参考相关文档

### 其他文件路径选项

| 选项 | 说明 |
|------|------|
| `originalFilePath` | 原始文件的绝对路径 |
| `originalRelativeFilePath` | 原始文件相对于项目 Originals 文件夹的相对路径 |
| `convertedFilePath` | 转换后文件的绝对路径（需指定 platform） |

## Music 选项

### music:transitionRoot

返回 Music Transition Root 对象，该对象包含所有其他 Music Transition（递归）。

```json
{
  "waql": "\"\\Interactive Music Hierarchy\\Default Work Unit\\My Music\"",
  "return": ["music:transitionRoot", "music:transitionRoot.id"]
}
```

- **返回类型**：object（包含 `id` 字段）
- **适用对象**：Music 相关对象

### music:playlistRoot

返回 Music Playlist Root 对象，该对象包含所有其他 Music Playlist Item（递归）。

```json
{
  "waql": "\"\\Interactive Music Hierarchy\\Default Work Unit\\My Playlist\"",
  "return": ["music:playlistRoot", "music:playlistRoot.id"]
}
```

- **返回类型**：object（包含 `id` 字段）
- **适用对象**：仅适用于 Music Playlist Container

### 已弃用的别名

以下旧版本访问器已被弃用，建议使用 `music:` 前缀版本：

| 已弃用 | 建议使用 |
|--------|----------|
| `musicTransitionRoot` | `music:transitionRoot` |
| `musicPlaylistRoot` | `music:playlistRoot` |

## SoundBank 选项

### soundbank:bnkFilePath

返回生成的 SoundBank 文件（.bnk）的绝对路径。

```json
{
  "waql": "\"\\SoundBanks\\Default Work Unit\\MyBank\"",
  "return": ["soundbank:bnkFilePath"],
  "platform": "Windows"
}
```

- **适用对象**：仅对 SoundBank 对象有效
- **返回类型**：string
- **需要指定**：`platform` 参数
- **注意**：需要先生成 SoundBank 才能获取准确路径

## Audio Source 选项

### audioSource:playbackDuration

返回包含音频源播放时长信息的对象。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["audioSource:playbackDuration"]
}
```

返回结构：
```json
{
  "playbackDuration": {
    "min": 2.5,
    "max": 3.0,
    "type": "Normal"
  }
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `min` | number | 可能的最短播放时长（秒） |
| `max` | number | 可能的最长播放时长（秒） |
| `type` | string | 时长类型 |

- **适用对象**：所有包含 Audio Source 的对象（直接作为源或通过后代间接包含）

### audioSource:trimValues

返回 Audio Source 的裁剪时间范围。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["audioSource:trimValues"]
}
```

返回结构：
```json
{
  "trimValues": {
    "trimBegin": 0.5,
    "trimEnd": 3.2
  }
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `trimBegin` | number | 起始裁剪时间（秒） |
| `trimEnd` | number | 结束裁剪时间（秒） |

### audioSource:maxRadiusAttenuation

返回具有最大衰减半径的衰减对象信息。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["audioSource:maxRadiusAttenuation"]
}
```

返回结构：
```json
{
  "maxRadiusAttenuation": {
    "id": "{aabbcc00-...}",
    "radius": 100.0
  }
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `id` | string (GUID) | 最大半径衰减对象的 GUID |
| `radius` | number | 衰减半径 |

- **适用对象**：所有包含 Audio Source 的对象

### audioSource:maxDurationSource

返回时长最长的 Audio Source 对象。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["audioSource:maxDurationSource"]
}
```

返回结构：
```json
{
  "maxDurationSource": {
    "id": "{aabbcc00-...}",
    "trimmedDuration": 4.5
  }
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `id` | string (GUID) | 最长时长 Audio Source 的 GUID |
| `trimmedDuration` | number | 最长裁剪后源的时长（秒） |

### audioSource:language

返回与 Audio Source 关联的语言对象。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["audioSource:language"]
}
```

返回结构：
```json
{
  "language": {
    "id": "{aabbcc00-...}",
    "name": "English(US)"
  }
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `id` | string (GUID) | 语言对象的 GUID |
| `name` | string | 语言对象的名称 |

- **适用对象**：仅直接适用于 Audio Source 对象

### 已弃用的别名

| 已弃用 | 建议使用 |
|--------|----------|
| `playbackDuration` | `audioSource:playbackDuration` / `duration` |
| `maxDurationSource` | `audioSource:maxDurationSource` |
| `audioSourceTrimValues` | `audioSource:trimValues` |
| `maxRadiusAttenuation` | `audioSource:maxRadiusAttenuation` |
| `audioSourceLanguage` | `audioSource:language` |

## Work Unit 选项

### workunit:isDefault

返回 Work Unit 是否为默认 Work Unit。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\"",
  "return": ["workunit:isDefault"]
}
```

- **返回类型**：boolean
- `true` — 是默认 Work Unit
- `false` — 不是默认 Work Unit

### workunit:type

返回 Work Unit 的类型。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\"",
  "return": ["workunit:type"]
}
```

- **返回类型**：string
- 可能值：
  - `"folder"` — 物理文件夹（类型为 "WorkUnit"，但 workunitType 为 "folder"）
  - `"rootFile"` — 根 Work Unit 文件
  - `"nestedFile"` — 嵌套 Work Unit 文件

### workunit:isDirty

返回 Work Unit 或项目文件是否已修改但未保存。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\"",
  "return": ["workunit:isDirty"]
}
```

- **返回类型**：boolean
- `true` — 已修改未保存
- `false` — 未修改或已保存

## Mute / Solo / Inclusion 状态选项

这些选项用于查询对象在工程中的静音、独奏和包含状态。

### isExplicitMute

对象是否被**显式静音**。

```json
{
  "return": ["isExplicitMute"]
}
```

- **返回类型**：boolean
- 显式静音一个对象会**隐式地静音其所有后代对象**

### isExplicitSolo

对象是否被**显式独奏**。

```json
{
  "return": ["isExplicitSolo"]
}
```

- **返回类型**：boolean
- 独奏一个对象会使项目中**除该对象外的所有其他对象静音**

### isImplicitMute

对象是否被**隐式静音**（因某个祖先对象被显式静音导致）。

```json
{
  "return": ["isImplicitMute"]
}
```

- **返回类型**：boolean

### isImplicitSolo

对象是否被**隐式独奏**。

```json
{
  "return": ["isImplicitSolo"]
}
```

- **返回类型**：boolean

### isIncluded

对象是否被**包含**（Included）。

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["isIncluded"],
  "platform": "Windows"
}
```

- **返回类型**：boolean
- **需要指定**：`platform` 参数
- **重要**：此值会考虑对象**祖先**的 Inclusion 状态，即如果祖先被排除，即使该对象自身标记为包含，也会返回 `false`

### Mute/Solo 状态组合示例

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "id", "name",
    "isExplicitMute", "isImplicitMute",
    "isExplicitSolo", "isImplicitSolo",
    "isIncluded"
  ],
  "platform": "Windows"
}
```

## SoundBank 尺寸选项

以下选项返回对象在 SoundBank 中占用的空间信息。**注意：这些值需要在 SoundBank 生成后才准确。**

### totalSize

该对象及其所有子对象在 SoundBank 中占用的**总空间**（字节），不包含 `objectSize`。

```json
{
  "return": ["totalSize"]
}
```

- **返回类型**：integer（字节）

### mediaSize

该对象及其所有子对象的媒体文件**转换后总大小**（字节）。

```json
{
  "return": ["mediaSize"]
}
```

- **返回类型**：integer（字节）

### objectSize

该对象**元数据**在 SoundBank 中占用的空间（字节），不包含媒体文件。

```json
{
  "return": ["objectSize"]
}
```

- **返回类型**：integer（字节）

### structureSize

该对象及其所有子对象的**元数据**在 SoundBank 中占用的空间（字节），不包含媒体文件。

```json
{
  "return": ["structureSize"]
}
```

- **返回类型**：integer（字节）

### 尺寸查询示例

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["totalSize", "mediaSize", "objectSize", "structureSize"],
  "platform": "Windows"
}
```

## 其他特殊选项

### switchContainerChild:context

返回 Switch Container 子对象关联的**上下文对象**。

```json
{
  "waql": "select descendants where type = 'SwitchContainer'",
  "return": ["switchContainerChild:context"]
}
```

- **返回类型**：object（包含 `id` 字段）
- **说明**：该上下文对象包含与 Switch Container 子对象上下文相关的属性（如 "1st only" 复选框的状态）

### points

返回 Curve 对象的曲线点数据。**仅适用于 Curve 对象。**

```json
{
  "waql": "select objects where type = 'Curve'",
  "return": ["points"]
}
```

返回结构：
```json
{
  "points": [
    { "x": 0.0, "y": 0.0, "shape": "Linear" },
    { "x": 1.0, "y": 1.0, "shape": "SCurve" }
  ]
}
```

| 子字段 | 类型 | 说明 |
|--------|------|------|
| `x` | number | 曲线点的 X 坐标 |
| `y` | number | 曲线点的 Y 坐标 |
| `shape` | string | 曲线段形状。可能值：`Constant`、`Linear`、`Log3`、`Log2`、`Log1`、`InvertedSCurve`、`SCurve`、`Exp1`、`Exp2`、`Exp3` |

### stateProperties

返回与该对象关联的 State 属性名称数组。

```json
{
  "return": ["stateProperties"]
}
```

- **返回类型**：array of string

### stateGroups

返回与该对象关联的 State Group 对象数组。

```json
{
  "return": ["stateGroups"]
}
```

返回结构：
```json
{
  "stateGroups": [
    { "id": "{aabbcc00-...}", "name": "MyStateGroup" }
  ]
}
```

### blendTracks

Blend Container 的 Blend Track 相关数据。

- **类型**：array（官网未提供详细子字段说明）

## platform 和 language 选项参数

### platform 参数

`platform` 是 `ak.wwise.core.object.get` 的**可选参数**，用于指定获取哪个平台的数据。

| 属性 | 说明 |
|------|------|
| **参数名** | `platform` |
| **是否必需** | 否。不指定时使用**当前平台** |
| **接受值** | 平台名称（string）或平台 GUID（string，格式 `{aabbcc00-...}`） |

使用示例：

```json
// 使用平台名称
{
  "waql": "...",
  "return": ["@Volume", "sound:convertedWemFilePath"],
  "platform": "Windows"
}

// 使用平台 GUID
{
  "waql": "...",
  "return": ["@Volume", "sound:convertedWemFilePath"],
  "platform": "{E4F8A2B7-3C1D-4F5E-9A2B-8C7D6E5F4A3B}"
}
```

### language 参数

`language` 是 `ak.wwise.core.object.get` 的**可选参数**，用于指定获取哪个语言的数据。

| 属性 | 说明 |
|------|------|
| **参数名** | `language` |
| **是否必需** | 否 |
| **接受值** | 语言名称（string）或语言 GUID（string，格式 `{aabbcc00-...}`） |

使用示例：

```json
// 使用语言名称
{
  "waql": "...",
  "return": ["sound:convertedWemFilePath"],
  "language": "English(US)"
}

// 使用语言 GUID
{
  "waql": "...",
  "return": ["sound:convertedWemFilePath"],
  "language": "{B5D9C3F1-2A4E-4F6B-8C1D-9E7F5A3B2D4C}"
}
```

### 同时使用 platform 和 language

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "name",
    "@Volume",
    "sound:convertedWemFilePath",
    "isIncluded"
  ],
  "platform": "Windows",
  "language": "English(US)"
}
```
