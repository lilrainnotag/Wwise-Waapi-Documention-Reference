# 02 - 音频属性返回（Object Properties）

## 概述

除了内置访问器，Wwise WAAPI 还支持返回对象的**音频属性**（Properties）和**引用**（References）。这些以 `@` 或 `@@` 为前缀，后跟属性名称，例如 `@Volume`、`@Pitch`。

属性名称的具体列表取决于对象类型，完整列表参见 [Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wobjects_index.html)。

## @ 与 @@ 前缀的区别

这是返回选项中最关键的概念之一：

| 前缀 | 含义 | 示例 |
|------|------|------|
| `@` | 返回**该对象自身**的属性当前值（可能来自继承、RTPC、State 等） | `@Volume` — 返回该 Sound 对象的当前音量 |
| `@@` | 返回属性的 **override 源值**（即该属性在哪个对象上被显式设定了值） | `@@Volume` — 返回 override 该音量属性的源头值 |

### 实际场景说明

假设有一个 Sound 对象，其父级 Actor-Mixer 设置了 `Volume = -6`，而 Sound 对象自身没有覆盖 Volume：

- `@Volume` 返回 `-6`（从父级继承的值）
- `@@Volume` 返回父级 Actor-Mixer 上设置的值（override 源）

如果 Sound 对象自身覆盖了 Volume 为 `-3`：

- `@Volume` 返回 `-3`（该对象自身的值）
- `@@Volume` 返回 `-3`（override 源是该对象自身）

### 适用场景

`@@` 前缀常用于：
- 调试属性继承链
- 查找属性的实际 override 位置
- 在复杂层级中追踪属性来源

## 常用音频属性列表

以下是从 Wwise 2024.1.14 官方文档中提到的常用对象属性。实际可用的属性取决于对象类型，完整列表请查阅 Wwise Objects Reference 中对应对象类型的属性表。

### Sound / Actor-Mixer 对象常用属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `@Volume` | number (dB) | 音量，单位为分贝 |
| `@Pitch` | number (cents) | 音高，单位为音分 |
| `@Lowpass` | number | 低通滤波器截止频率 |
| `@Highpass` | number | 高通滤波器截止频率 |
| `@MakeUpGain` | number (dB) | 补偿增益 |
| `@OutputBusVolume` | number (dB) | 输出总线音量 |
| `@OutputBusLPF` | number | 输出总线低通滤波器 |
| `@OutputBusHPF` | number | 输出总线高通滤波器 |
| `@BusVolume` | number (dB) | 总线音量 |
| `@InitialDelay` | number (s) | 初始延迟 |

### Bus 对象常用属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `@BusVolume` | number (dB) | 总线音量 |
| `@BusConfig` | （官网未提供） | 总线配置 |
| `@HdrBusThreshold` | number (dB) | HDR 总线阈值 |
| `@HdrBusRatio` | number | HDR 总线压缩比 |
| `@HdrBusReleaseTime` | number (s) | HDR 总线释放时间 |

### RTPC 相关属性

| 属性 | 类型 | 说明 |
|------|------|------|
| `@RTPC` | array（对象列表） | 对象的 RTPC 列表。通过 `@RTPC` 返回 RTPC 对象的引用列表 |

### 引用类型属性

以下属性返回的是对其他 Wwise 对象的**引用**（reference），而非简单值：

| 属性 | 返回类型 | 说明 |
|------|----------|------|
| `@OutputBus` | object reference | 输出总线引用。可通过 `.name`、`.id` 等链式访问 |
| `@ Effects` | object list reference | 效果器列表引用。可通过 `.first`、`[0]` 等访问 |
| `@Attenuation` | object reference | 衰减对象引用 |
| `@Conversion` | object reference | 转换设置引用 |
| `@StateGroup` | object reference | State Group 引用（用于 Music 对象） |
| `@SwitchGroup` | object reference | Switch Group 引用 |
| `@GameParameter` | object reference | Game Parameter 引用 |
| `@TransitionRoot` | object reference | Music Transition Root 引用 |
| `@PlaylistRoot` | object reference | Music Playlist Root 引用 |
| `@ActiveSource` | object reference | 活跃音频源引用 |
| `@OriginalFile` | object reference | 原始音频文件引用 |
| `@ConvertedFile` | object reference | 转换后音频文件引用 |

## 引用类型属性的链式访问

引用类型属性返回的是对象引用，可以通过 `.` 继续访问该引用对象的属性：

```json
{
  "return": [
    "@OutputBus",
    "@OutputBus.name",
    "@OutputBus.id",
    "@OutputBus.type",
    "@OutputBus.@BusVolume"
  ]
}
```

### 效果器列表访问

对于 `@Effects` 等列表类型引用，支持以下访问方式：

```json
{
  "return": [
    "@Effects",
    "@Effects.first",         // 列表中第一个效果器
    "@Effects.first.id",      // 第一个效果器的 GUID
    "@Effects.first.name",    // 第一个效果器的名称
    "@Effects.first.effect.id", // 第一个效果器的效果插件 GUID
    "@Effects.count"          // 效果器数量
  ]
}
```

列表支持的方法（官网未提供完整列表，以下为 WAQL 中常见的列表操作）：
- `.first` — 获取第一个元素
- `.count` / `.count()` — 获取元素数量
- `[...]` 索引 — 按索引访问（语法取决于具体实现）

## 平台特定属性的返回

通过 `platform` 选项，可以获取特定平台的属性值：

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["@Volume", "@Pitch", "sound:convertedWemFilePath"],
  "platform": "Windows"
}
```

`platform` 参数接受：
- **平台名称**（string）：如 `"Windows"`、`"iOS"`、`"Android"`、`"PS5"` 等
- **平台 GUID**（string）：平台对象的 GUID，格式 `{aabbcc00-1122-3344-5566-77889900aabb}`

当未指定 `platform` 时，默认使用**当前平台**。

## language 选项

对于多语言项目，可以通过 `language` 选项获取特定语言的数据：

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": ["@Volume", "sound:convertedWemFilePath"],
  "language": "English(US)"
}
```

`language` 参数接受：
- **语言名称**（string）：如 `"English(US)"`、`"French(France)"` 等
- **语言 GUID**（string）：语言对象的 GUID

## 完整使用示例

### 获取 Sound 对象的音频属性

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "id",
    "name",
    "@Volume",
    "@Pitch",
    "@Lowpass",
    "@Highpass",
    "@MakeUpGain",
    "@OutputBusVolume",
    "@OutputBusLPF",
    "@OutputBusHPF",
    "@InitialDelay"
  ]
}
```

### 获取属性及 override 源

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "@Volume",
    "@@Volume",
    "@Pitch",
    "@@Pitch",
    "@Lowpass",
    "@@Lowpass"
  ]
}
```

### 获取输出总线信息（链式访问）

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "@OutputBus",
    "@OutputBus.name",
    "@OutputBus.id",
    "@OutputBus.@BusVolume"
  ]
}
```

### 获取效果器列表

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "@Effects",
    "@Effects.first.name",
    "@Effects.first.effect.name",
    "@Effects.first.effect.id"
  ]
}
```

### 获取 RTPC 列表

```json
{
  "waql": "\"\\Actor-Mixer Hierarchy\\Default Work Unit\\My Sound\"",
  "return": [
    "@RTPC",
    "@RTPC.first.id",
    "@RTPC.first.@GameParameter.name"
  ]
}
```

> **数据来源**：以上属性名称、前缀规则和链式访问语法均从 Audiokinetic 官方文档 (Wwise 2024.1.14) `ak.wwise.core.object.get` 的 Options Schema 中提取。具体对象类型支持的属性完整列表请参考 Wwise Objects Reference。
