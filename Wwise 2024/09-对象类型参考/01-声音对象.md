# 01-声音对象（Sound Objects）

> **来源**: [Audiokinetic 官方文档 - Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_object_reference.html)（注：可运行时通过 `ak.wwise.core.object.getTypes` 获取完整类型列表）

## 概述

声音对象是 Wwise 中最基础、最常用的对象类型，代表实际可播放的音频内容。声音对象位于 **Actor-Mixer Hierarchy** 中，是音频处理管线的起点。

## 类型列表

### Sound

声音是 Wwise 中最基本的音频播放单元。可以包含一个或多个音频文件源（AudioFileSource），支持随机/序列播放、RTPC 控制等。

- **ClassID**: 65552
- **WAAPI 类型名**: `Sound`
- **说明**: Wwise 中最基本的音频单元。支持三种类型：Sound SFX（音效）、Sound Voice（语音），子类型由 `IsVoice` 属性区分。一个 Sound 对象可包含多个 AudioFileSource，通过 `RandomOrSequence` 属性控制播放顺序。
- **所属层级**: Actor-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `IsVoice` | boolean | 是否为 Sound Voice（true = Sound Voice, false = Sound SFX） |
| `IsLoopingEnabled` | boolean | 是否启用循环 |
| `IsStreamingEnabled` | boolean | 是否启用流式播放 |
| `IsZeroLatency` | boolean | 是否启用零延迟 |
| `OutputBusVolume` | number | 输出总线音量 |
| `OverrideOutput` | boolean | 是否覆盖输出总线 |
| `OverridePositioning` | boolean | 是否覆盖定位设置 |
| `OverrideVirtualVoice` | boolean | 是否覆盖虚拟语音设置 |
| `OverrideConversion` | boolean | 是否覆盖转换设置 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |
| `Conversion` | Conversion | 转换设置 |
| `Attenuation` | Attenuation | 衰减设置 |
| `UserAuxSend0` | AuxBus | 用户辅助发送 0 |
| `UserAuxSend1` | AuxBus | 用户辅助发送 1 |
| `UserAuxSend2` | AuxBus | 用户辅助发送 2 |
| `UserAuxSend3` | AuxBus | 用户辅助发送 3 |
| `EarlyReflectionsAuxSend` | AuxBus | 早期反射辅助发送 |
| `Rtpc` | RTPC | 关联的 RTPC 对象（反向引用） |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | AudioFileSource | 包含的音频文件源列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `States` | State | 状态属性覆盖列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |
| `Metadata` | Metadata | 元数据列表 |

### AudioFileSource

音频文件源，引用磁盘上的实际 WAV 音频文件。每个 Sound 可以包含多个 AudioFileSource，支持随机/序列播放。

- **ClassID**: 16
- **WAAPI 类型名**: `AudioFileSource`
- **说明**: 音频文件源对象，是 Sound 的子对象，直接关联到导入的 WAV/PCM 音频文件。支持通过 `RandomOrSequence` 属性在多个 AudioFileSource 之间切换播放。
- **所属层级**: Actor-Mixer Hierarchy（作为 Sound 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `VolumeOffset` | number (dB) | 音量偏移 |
| `TrimBegin` | number | 裁剪起始位置 (s) |
| `TrimEnd` | number | 裁剪结束位置 (s) |
| `LoopBegin` | number | 循环起始位置 (s) |
| `LoopEnd` | number | 循环结束位置 (s) |
| `FadeInDuration` | number | 淡入时长 (s) |
| `FadeOutDuration` | number | 淡出时长 (s) |
| `CrossfadeDuration` | number | 交叉淡变时长 (s) |
| `OverrideWavLoop` | boolean | 是否覆盖 WAV 循环点 |
| `ChannelConfigOverride` | number | 声道配置覆盖 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `Conversion` | Conversion | 转换设置 |

---

### SourcePlugin

源插件，通过 Wwise 的插件系统生成音频（如 Wwise Synth One、Tone Generator 等），而非依赖预录制的音频文件。

- **ClassID**: 1048592
- **WAAPI 类型名**: `SourcePlugin`
- **说明**: 源插件对象，通过 Wwise 插件系统实时生成或处理音频信号。常用源插件包括 Wwise Synth One、Tone Generator、SoundSeed Grain 等。创建时需要通过 `@PluginID` 属性指定具体插件类型。
- **所属层级**: Actor-Mixer Hierarchy（作为 Sound 的子对象）

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Color` | number | 颜色索引 [0, 26] |
| `OverrideColor` | boolean | 是否覆盖颜色 |
| `RTPC` | list | 关联的 RTPC 曲线列表 |

> **注意**：具体插件的参数（如 Wwise Synth One 的合成参数）通过各插件的专属属性名设置，不在基础 SourcePlugin 属性表中。创建 SourcePlugin 时通过 `@PluginID` 指定插件类型。

**常用源插件**:

| 名称 | PluginID | ClassID | 说明 |
|------|----------|---------|------|
| Wwise Silence | 101 | 6619138 | 静音源，不产生任何音频输出 |
| Wwise Tone Generator | 102 | 6684674 | 生成纯音/正弦波 |
| Wwise Synth One | 148 | 9699330 | Wwise 内置合成器 |
| SoundSeed Air Wind | 119 | 7798786 | 风声音效生成器 |
| SoundSeed Air Woosh | 120 | 7864322 | 呼啸声音效生成器 |
| SoundSeed Grain | 183 | 11993090 | 粒子合成音效生成器 |
| Impacter | 184 | 12058626 | 碰撞音效生成器 |

### MotionSource

运动/振动源，用于生成控制器振动效果（如游戏手柄的触觉反馈）。

- **ClassID**: 26804226（PluginID: 409）
- **WAAPI 类型名**: 通过 SourcePlugin 类型的对象表示
- **说明**: 运动源对象，用于生成游戏控制器（如 DualSense、Xbox Controller 等）的振动/触觉反馈数据。是 SourcePlugin 的一种特殊类型。

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Channel1`~`Channel4` | number | 通道 1-4 的振动强度 |
| `LeftTrigger` | number | 左扳机振动强度 |
| `RightTrigger` | number | 右扳机振动强度 |
| `ChannelConfig` | number | 声道配置 |
| `DriverA`~`DriverH` | number | 驱动信号 A-H 分配 |
| `High1` / `High2` | number | 高频振动强度 |
| `Low1` / `Low2` | number | 低频振动强度 |

---

### MidiFileSource

MIDI 文件源，引用磁盘上的 MIDI 文件。

- **ClassID**: 5242896
- **WAAPI 类型名**: `MidiFileSource`
- **说明**: MIDI 文件源对象，关联到磁盘上的 MIDI 文件，可用于驱动 MIDI 合成器或音乐生成插件。

**常用属性**:

> SDK 2024.1 明确标注 MidiFileSource **没有 WAAPI 属性**。MIDI 文件信息通过文件导入流程管理。

## WAAPI 操作示例

### 创建 Sound 对象

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{AABBCC00-1122-3344-5566-77889900AABB}",
        "type": "Sound",
        "name": "MySound",
        "@Volume": -6.0,
        "@IsLoopingEnabled": false
    }
}
```

### 创建包含 AudioFileSource 的 Sound

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Actor-Mixer Hierarchy\\Default Work Unit\\",
        "type": "Sound",
        "name": "Explosion",
        "children": [
            {
                "type": "AudioFileSource",
                "name": "Explosion_01"
            }
        ]
    }
}
```

### 创建 SourcePlugin 对象（Tone Generator）

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "{SOUND_GUID}",
        "type": "SourcePlugin",
        "name": "ToneGen",
        "@PluginID": 102
    }
}
```

### 查询所有 Sound 对象

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"search": ["\\Actor-Mixer Hierarchy"]},
        "transform": [
            {"select": ["descendants"]},
            {"where": ["type:isIn", ["Sound"]]}
        ]
    }
}
```

### 获取 Sound 对象的播放时长

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"id": ["{SOUND_GUID}"]},
        "options": [{"return": ["Volume", "IsLoopingEnabled", "name", "type"]}]
    }
}
```

## 导入音频文件

声音对象的音频数据通过 `ak.wwise.core.audio.import` 导入：

```json
{
    "method": "ak.wwise.core.audio.import",
    "params": {
        "importOperation": "createNew",
        "default": {
            "importLanguage": "SFX"
        },
        "imports": [
            {
                "audioFile": "C:\\Audio\\explosion.wav",
                "objectPath": "\\Actor-Mixer Hierarchy\\Default Work Unit\\<Sound>Explosion"
            }
        ]
    }
}
```
