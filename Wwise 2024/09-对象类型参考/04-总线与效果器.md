# 04-总线与效果器（Bus & Effect Objects）

> **来源**: [Audiokinetic 官方文档 - Wwise Objects Reference](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=wwise_object_reference.html)

## 概述

总线和效果器对象位于 **Master-Mixer Hierarchy** 中，构成了 Wwise 的音频路由和混音管线。总线建立了音频信号的层级路由结构，效果器挂载在总线上对信号进行处理。

## 类型列表

### Bus

主总线，是音频路由层级中的核心节点。

- **ClassID**: 1376272
- **WAAPI 类型名**: `Bus`
- **说明**: 总线是 Wwise 音频路由管线的核心，所有声音对象最终都会路由到某个总线上。总线以层级结构组织（Master Audio Bus → 子 Bus），每层总线可以有自己的音量、效果器链、定位设置等。Master Audio Bus 是总线层级的根节点。
- **所属层级**: Master-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 总线音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `MakeUpGain` | number | 补偿增益 |
| `BusVolume` | number | 总线音量（引擎侧） |
| `HdrEnable` | boolean | 是否启用 HDR |
| `MaxDuckVolume` | number (dB) | 最大闪避音量 |
| `RecoveryTime` | number | 闪避恢复时间 (s) |
| `UsedForBackgroundMusic` | boolean | 是否用于背景音乐（触发自动闪避） |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线（指向父总线） |
| `Conversion` | Conversion | 转换设置 |
| `Attenuation` | Attenuation | 衰减设置（仅 Voice Bus） |
| `BusEffect0` | EffectSlot | 总线效果器 0 |
| `BusEffect1` | EffectSlot | 总线效果器 1 |
| `BusEffect2` | EffectSlot | 总线效果器 2 |
| `BusEffect3` | EffectSlot | 总线效果器 3 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | Bus / AuxBus / AudioDevice | 子总线/辅助总线/设备列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |
| `States` | State | 状态属性覆盖列表 |
| `Metadata` | Metadata | 元数据列表 |

### AuxBus

辅助总线（Auxiliary Bus），用于接收来自其他声音对象的发送（Send）信号。

- **ClassID**: 3997712
- **WAAPI 类型名**: `AuxBus`
- **说明**: 辅助总线用于从声音对象接收发送信号（User Aux Send / Early Reflection Aux Send），对发送信号进行独立处理。常用于创建全局混响、延迟等效果，多个声音可以 Send 到同一个 AuxBus 共享效果处理。
- **所属层级**: Master-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Volume` | number (dB) | 音量 |
| `Pitch` | number (cents) | 音高 |
| `Lowpass` | number | 低通滤波 |
| `Highpass` | number | 高通滤波 |
| `BusVolume` | number | 总线音量 |
| `BusChannelConfig` | number | 总线声道配置 |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `OutputBus` | Bus | 输出目标总线 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `children` | Bus / AuxBus | 子对象列表 |
| `Effects` | EffectSlot | 效果器插槽列表 |
| `RTPC` | RTPC | 关联的 RTPC 曲线列表 |

---

### AudioDevice

音频输出设备，代表一个物理音频输出端点。

- **ClassID**: 4653072
- **WAAPI 类型名**: `AudioDevice`
- **说明**: 音频设备代表物理音频输出端点（如扬声器、耳机等）。Master Audio Bus 通过 AudioDevice 输出到实际的音频硬件。多个 AudioDevice 可以共存用于不同输出配置。
- **所属层级**: Master-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `BypassEffect` | boolean | 是否旁通所有效果 |
| `Color` | number | 颜色索引 [0, 26] |
| `OverrideColor` | boolean | 是否覆盖颜色 |
| `Effects` | list | 效果器插槽列表 |
| `Inclusion` | boolean | 是否包含在 SoundBank 中 |
| `RTPC` | list | 关联的 RTPC 曲线列表 |

---

### Effect

效果器实例，代表一个应用于总线或声音对象的效果处理。

- **ClassID**: 1114128
- **WAAPI 类型名**: `Effect`
- **说明**: 效果器实例是通过 EffectSlot 挂载在 Bus 或 Sound 对象上的音频处理单元。每个 Effect 对应一个具体的 Wwise 效果器插件（如 Compressor、Delay、Reverb 等）。通过 `PluginID` 属性指定插件类型。
- **所属层级**: Master-Mixer Hierarchy / Actor-Mixer Hierarchy

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Color` | number | 颜色索引 [0, 26] |
| `Inclusion` | boolean | 是否包含在 SoundBank 中 |
| `OverrideColor` | boolean | 是否覆盖颜色 |
| `RTPC` | list | 关联的 RTPC 曲线列表 |

> **注意**：`PluginID` 在创建时通过 `@PluginID` 指定，不在 WAAPI 属性表中。具体效果器的参数（如 `EffectGain`）通过各 EffectPlugin 专属属性名设置。`Bypass` 属于 EffectSlot 而非 Effect。

### EffectSlot

效果器插槽，是挂载在总线或声音对象上的效果器容器。

- **ClassID**: 5505040
- **WAAPI 类型名**: `EffectSlot`
- **说明**: 效果器插槽是 Effect 的容器，定义效果器在总线或声音对象上的插入位置和旁通状态。一个总线/Object 可以有多个 EffectSlot（如 Effects 列表中的 0~3 号插槽）。
- **所属层级**: 任何层级的 Effect 链

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `Bypass` | boolean | 是否旁通此效果器插槽 |
| `Render` | boolean | 是否渲染 |
| `IsGlobal` | boolean | 是否为全局效果器（只读） |

**常用引用**:

| 引用 | 目标类型 | 说明 |
|------|----------|------|
| `Effect` | Effect | 关联的效果器实例 |

---

### Attenuation

衰减对象，控制声音的空间衰减行为。

- **ClassID**: 2686992
- **WAAPI 类型名**: `Attenuation`
- **说明**: 衰减对象定义声音在 3D 空间中的衰减行为，包括距离衰减曲线、扩散（Spread）、聚焦（Focus）等参数。衰减对象可以被多个声音对象共享（通过 `Attenuation` 引用）。
- **所属层级**: 独立对象，通过引用关联

**常用属性**:

| 属性 | 类型 | 说明 |
|------|------|------|
| `ConeUse` | boolean | 是否启用声锥衰减 |
| `ConeInnerAngle` | number | 声锥内角 |
| `ConeOuterAngle` | number | 声锥外角 |
| `ConeAttenuation` | number | 声锥衰减量 |
| `ConeHighPassFilterValue` | number | 声锥高通滤波值 |
| `ConeLowPassFilterValue` | number | 声锥低通滤波值 |
| `RadiusMax` | number | 最大衰减距离 |
| `HeightSpreadEnable` | boolean | 是否启用高度扩散 |
| `Color` | number | 颜色索引 [0, 26] |
| `OverrideColor` | boolean | 是否覆盖颜色 |
| `RTPC` | list | 关联的 RTPC 曲线列表 |

**常用列表**:

| 列表 | 元素类型 | 说明 |
|------|----------|------|
| `Curves` | Curve | 衰减曲线列表 |

## 总线层级示例

```
Master Audio Bus（Bus, ClassID: 1376272）
├── AudioDevice（ClassID: 4653072）
├── SFX Bus（Bus）
│   ├── Weapons Bus（Bus）
│   ├── Environment Bus（Bus）
│   └── Dialogue Bus（Bus）
├── Music Bus（Bus）
└── Reverb AuxBus（AuxBus, ClassID: 3997712）
    └── EffectSlot（ClassID: 5505040）
        └── Effect（ClassID: 1114128, Wwise RoomVerb）
```

## WAAPI 操作示例

### 创建 Bus

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Master-Mixer Hierarchy\\Default Work Unit\\",
        "type": "Bus",
        "name": "SFX_Bus",
        "@Volume": 0
    }
}
```

### 创建 AuxBus 并添加效果器

```json
{
    "method": "ak.wwise.core.object.create",
    "params": {
        "parent": "\\Master-Mixer Hierarchy\\Default Work Unit\\",
        "type": "AuxBus",
        "name": "GlobalReverb",
        "children": [
            {
                "type": "Effect",
                "name": "RoomVerb",
                "@PluginID": 118
            }
        ]
    }
}
```

### 设置 Sound 对象的 OutputBus 和 AuxSend

```json
{
    "method": "ak.wwise.core.object.setReference",
    "params": {
        "object": "{SOUND_GUID}",
        "reference": "OutputBus",
        "value": "{BUS_GUID}"
    }
}
```

```json
{
    "method": "ak.wwise.core.object.setReference",
    "params": {
        "object": "{SOUND_GUID}",
        "reference": "UserAuxSend0",
        "value": "{AUX_BUS_GUID}"
    }
}
```

### 设置 Effect 的 Bypass 状态

```json
{
    "method": "ak.wwise.core.object.setProperty",
    "params": {
        "object": "{EFFECT_SLOT_GUID}",
        "property": "Bypass",
        "value": true
    }
}
```

### 查询 Master-Mixer Hierarchy 结构

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"search": ["\\Master-Mixer Hierarchy"]},
        "transform": [
            {"select": ["descendants"]},
            {"where": ["type:isIn", ["Bus", "AuxBus", "AudioDevice"]]}
        ],
        "options": [{"return": ["id", "name", "type", "Volume"]}]
    }
}
```

### 获取总线上的效果器列表

```json
{
    "method": "ak.wwise.core.object.get",
    "params": {
        "from": {"id": ["{BUS_GUID}"]},
        "options": [{"return": ["id", "name", "Effects.name", "Effects.effect.name", "Effects.effect.PluginID"]}]
    }
}
```
