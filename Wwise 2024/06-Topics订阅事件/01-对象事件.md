# 对象事件

## 订阅机制

`ak.wwise.core.object.*` 系列 Topic 用于监听 Wwise 工程中对象（Object）的增删改等变化。所有对象事件 Topic 都支持 `return` 选项来指定返回哪些对象字段，还支持 `platform` 选项来指定平台。

通用的 Options：

| 名称 | 类型 | 说明 |
|------|------|------|
| return | array | 要返回的数据字段列表。支持内置访问器（id, name, type, path, parent 等）和属性访问器 |
| platform | string | 平台的 GUID，格式为 `{aabbcc00-1122-3344-5566-77889900aabb}` |

订阅示例（Python waapi-client）：

```python
from waapi import WaapiClient

client = WaapiClient()

def on_object_created(channel, **kwargs):
    obj = kwargs.get("object", {})
    print(f"对象已创建: {obj.get('name')} (ID: {obj.get('id')})")

sub_id = client.subscribe(
    "ak.wwise.core.object.created",
    options={"return": ["id", "name", "type", "path"]},
    callback=on_object_created
)
```

## 事件列表

### ak.wwise.core.object.created

- **触发时机**：当 Wwise 工程中创建了一个新对象时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 新创建的对象。使用 return 选项指定需要返回的属性 |
| object.id | string | 对象的 GUID，格式为 `{aabbcc00-1122-3344-5566-77889900aabb}` |
| object.name | string | 对象的名称 |
| object.type | string | 对象的类型。参见 Wwise Objects Reference |
| object.path | string | 对象从工程根目录的路径，如 `\Actor-Mixer Hierarchy\Default Work Unit\Sound1` |
| object.parent | object | 对象在层级中的父对象 |
| object.owner | object | 对象的拥有者（适用于自定义效果、自定义衰减等） |

- **WAMP 订阅示例**：

```json
// 订阅
[5, "ak.wwise.core.object.created"]

// 发布内容
{
    "object": {
        "id": "{aabbcc00-1122-3344-5566-77889900aabb}",
        "name": "New Sound SFX",
        "type": "Sound",
        "path": "\\Actor-Mixer Hierarchy\\Default Work Unit\\New Sound SFX"
    }
}
```

- **注意事项**：对象创建可能来自 UI 操作、API 调用或导入操作。该 Topic 不区分创建来源。

---

### ak.wwise.core.object.preDeleted

- **触发时机**：在对象被删除**之前**发送。可在此时获取被删对象的信息以做备份或其他处理
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 即将被删除的对象。使用 return 选项指定需要返回的属性 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |
| object.type | string | 对象的类型 |
| object.path | string | 对象从工程根目录的路径 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{aabbcc00-1122-3344-5566-77889900aabb}",
        "name": "Sound SFX",
        "type": "Sound",
        "path": "\\Actor-Mixer Hierarchy\\Default Work Unit\\Sound SFX"
    }
}
```

- **注意事项**：与 `postDeleted` 配对使用。`preDeleted` 发送时对象仍然存在，可以通过 API 访问其属性；`postDeleted` 发送时对象已被移除。

---

### ak.wwise.core.object.postDeleted

- **触发时机**：在对象被删除**之后**发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 已被删除的对象的信息。使用 return 选项指定需要返回的属性 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |
| object.type | string | 对象的类型 |
| object.path | string | 对象从工程根目录的路径 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{aabbcc00-1122-3344-5566-77889900aabb}",
        "name": "Sound SFX",
        "type": "Sound",
        "path": "\\Actor-Mixer Hierarchy\\Default Work Unit\\Sound SFX"
    }
}
```

- **注意事项**：发送时对象已从工程中移除，无法再通过 `ak.wwise.core.object.get` 等 API 获取其完整属性。建议在 `preDeleted` 阶段获取所需信息。

---

### ak.wwise.core.object.childAdded

- **触发时机**：当一个对象作为子对象被添加到另一个对象时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| parent * | object | 父对象 |
| child * | object | 新添加的子对象 |
| child.id | string | 子对象的 GUID |
| child.name | string | 子对象的名称 |
| child.type | string | 子对象的类型 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "parent": {
        "id": "{parent-guid}",
        "name": "My Container"
    },
    "child": {
        "id": "{child-guid}",
        "name": "New Child Sound",
        "type": "Sound"
    }
}
```

- **注意事项**：子对象添加可能来自 UI 拖拽、API 调用（如 `ak.wwise.core.object.create` 指定 parent）或导入操作。

---

### ak.wwise.core.object.childRemoved

- **触发时机**：当一个对象从另一个对象的子列表中移除时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| parent * | object | 父对象 |
| child * | object | 被移除的子对象 |
| child.id | string | 子对象的 GUID |
| child.name | string | 子对象的名称 |
| child.type | string | 子对象的类型 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "parent": {
        "id": "{parent-guid}",
        "name": "My Container"
    },
    "child": {
        "id": "{child-guid}",
        "name": "Removed Child",
        "type": "Sound"
    }
}
```

- **注意事项**：`childRemoved` 不等同于 `preDeleted`/`postDeleted`。子对象被移除层级关系后可能仍然存在于工程中（移动到其他位置），不一定被删除。

---

### ak.wwise.core.object.nameChanged

- **触发时机**：当对象被重命名时发送。发布重命名后的对象信息
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 被重命名的对象（新名称已生效） |
| oldName * | string | 对象之前的名称 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的新名称 |
| object.type | string | 对象的类型 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{object-guid}",
        "name": "NewName",
        "type": "Sound"
    },
    "oldName": "OldName"
}
```

- **注意事项**：同时返回旧名称和新名称，方便追踪重命名历史。相关 API：`ak.wwise.core.object.setName`。

---

### ak.wwise.core.object.notesChanged

- **触发时机**：当对象的 Notes 属性发生变化时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | Notes 发生变化的对象 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |
| object.notes | string | 对象更新后的 Notes 内容 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{object-guid}",
        "name": "Sound SFX",
        "notes": "Updated notes content"
    }
}
```

- **注意事项**：Notes 变更通常来自 Wwise UI 中的 Notes 面板编辑。

---

### ak.wwise.core.object.propertyChanged

- **触发时机**：当被监听的对象的指定属性发生变化时发送。必须在订阅时指定 `object` 和 `property`
- **Options（必填）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | string | 要监听的对象。可以是 GUID、名称（格式：`type:name`）或工程路径 |
| property * | string | 要监听的属性名称。参见 Wwise Objects Reference 了解各对象可用的属性 |
| return | array | 要返回的数据字段列表 |

- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 被监听的对象 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |
| property 值 | (对应类型) | 属性变化后的新值（通过 return 选项指定） |

- **WAMP 订阅示例**：

```python
from waapi import WaapiClient

client = WaapiClient()

# 监听对象 {some-guid} 的 Volume 属性变化
sub_id = client.subscribe(
    "ak.wwise.core.object.propertyChanged",
    options={
        "object": "{some-guid}",
        "property": "Volume",
        "return": ["id", "name", "@Volume"]
    },
    callback=lambda channel, **kwargs: print(f"Volume changed: {kwargs}")
)
```

- **注意事项**：
  - `object` 和 `property` 都是**必填**参数，这与大多数其他 Topic 不同
  - 每次订阅只能监听**一个对象的一个属性**，需要监听多个属性或多对象需分别订阅
  - 使用 `@propertyName` 语法在 return 中获取属性值

### ak.wwise.core.object.referenceChanged

- **触发时机**：当对象的引用（Reference）发生变化时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 引用发生变化的对象 |
| reference * | string | 发生变化的引用名称 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |
| object.type | string | 对象的类型 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{object-guid}",
        "name": "My Sound",
        "type": "Sound"
    },
    "reference": "OutputBus"
}
```

- **注意事项**：引用包括但不限于 OutputBus、Conversion、Attenuation、Effect 等。通过 return 表达式可以获取引用的目标对象信息。

---

### ak.wwise.core.object.curveChanged

- **触发时机**：当一条或多条曲线（Curve）发生变化时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 曲线所属的对象 |
| curve * | string | 发生变化的曲线标识 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{object-guid}",
        "name": "My Container",
        "type": "ActorMixer"
    },
    "curve": "Volume"
}
```

- **注意事项**：曲线变化可能来自 RTPC 编辑。如果同时有多条曲线变化，可能收到多次通知。

---

### ak.wwise.core.object.attenuationCurveChanged

- **触发时机**：当衰减曲线（Attenuation Curve）发生变化时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 衰减曲线所属的对象 |
| curve * | string | 发生变化的衰减曲线标识 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{object-guid}",
        "name": "Sound SFX",
        "type": "Sound"
    },
    "curve": "Attenuation"
}
```

- **注意事项**：这是 `curveChanged` 的特定子类，专门针对衰减曲线的变化。适用于监听声音的距离衰减设置变更。

---

### ak.wwise.core.object.attenuationCurveLinkChanged

- **触发时机**：当衰减曲线的链接/取消链接（Link/Unlink）状态发生变化时发送
- **发布内容（返回值）**：

| 名称 | 类型 | 说明 |
|------|------|------|
| object * | object | 衰减曲线所属的对象 |
| curve * | string | 链接状态发生变化的衰减曲线标识 |
| object.id | string | 对象的 GUID |
| object.name | string | 对象的名称 |

- **WAMP 订阅示例**：

```json
// 发布内容
{
    "object": {
        "id": "{object-guid}",
        "name": "Sound SFX",
        "type": "Sound"
    },
    "curve": "Attenuation"
}
```

- **注意事项**：衰减曲线可以链接（Link）使多个平台共享同一曲线，或取消链接（Unlink）为不同平台独立设置。此 Topic 监听链接状态的变化。
