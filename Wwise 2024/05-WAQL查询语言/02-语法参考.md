# 02-语法参考

## 完整语法结构

WAQL 查询有以下几种形式（来源：官方 WAQL Reference）：

| 语法形式 | 说明 |
|----------|------|
| `$ SOURCE` | 仅指定源 |
| `$ SOURCE TRANSFORM` | 源 + 一个变换 |
| `$ SOURCE TRANSFORM, TRANSFORM, ...` | 源 + 多个变换（逗号分隔） |
| `$ TRANSFORM` | 省略源，隐式以整个项目为源 |

- **SOURCE**：对象生成器，输出一个对象序列
- **TRANSFORM**：序列变换，接收输入序列并输出另一个序列

> **注意：** 当不指定源时，项目中的所有对象将隐式作为源。

---

## from 子句（Sources）

`from` 关键字指定查询的起始源，初始化对象序列。所有查询都有源，但当 `from` 省略时，隐式选择项目中的所有对象。

### from object — 按对象指定

```
$ from object "\Actor-Mixer Hierarchy\Default Work Unit\Hello"
$ from object "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"
$ from object "Event:Play_Hello"
$ from object "Event:2952797154"
$ from object "Event:Play_Hello", "Bus:Master Audio Bus"
```

OBJECT_SPECIFIER 支持以下形式：

| 形式 | 说明 | 示例 |
|------|------|------|
| **Path** | 双引号包围的绝对路径，以反斜杠开头，包含顶层物理文件夹 | `"\Actor-Mixer Hierarchy\Default Work Unit\Hello"` |
| **GUID** | 双引号包围的 128 位 GUID，放在花括号中 | `"{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"` |
| **Qualified unique name** | 双引号包围的对象名称，前缀为对象类型。仅适用于有唯一名称的类型（Event、Bus、Effect、GameParameter 等） | `"Event:Play_Hello"` |
| **Qualified unique ID** | 双引号包围的对象 ID（32 位 short ID），前缀为对象类型 | `"Event:2952797154"` |

简化形式（省略 `from object`）：
```
$ "Event:Play_Hello", "Bus:Master Audio Bus"
$ "\Actor-Mixer Hierarchy"
```

### from type — 按类型指定

```
$ from type Event
$ from type sound
$ from type Sound
$ from type randomSequenceContainer, switchContainer, blendContainer
$ from type bus
```

生成指定类型的所有对象。可指定一个或多个对象类型。类型名**不区分大小写**。完整类型列表参考 Wwise Objects Reference。

### from query — 按查询编辑器中的查询

```
$ from query "\Queries\Factory Queries\Audio Source\Audio Source - Format = Vorbis"
$ from query "{4D1B2AA5-19D8-44D3-AAE5-94024469CE7C}"
```

执行 Query Editor 中定义的 Wwise Query 的结果作为源。

- QUERY_SPECIFIER 支持 Path（绝对路径）或 GUID（花括号包围的 128 位 GUID）
- **注意：** 此生成器需要分配等于其生成序列大小的内存

### from search — 按文本搜索

```
$ from search "gun"
$ from search "foot walk"
```

对**整个项目**执行文本搜索。TEXT 为双引号包围的字符串，每个单词匹配项目对象中的单词。

> **注意：** 结果与 Wwise 工具栏搜索相同。

### from project — 整个项目

```
$ from project
```

生成包含项目中**所有对象**的序列。

## where 子句

`where` 关键字过滤输入序列中的对象，拒绝不匹配指定表达式的对象。

### 基本语法

```
where BOOLEAN_EXPRESSION
```

BOOLEAN_EXPRESSION 是一个返回 `true` 或 `false` 的表达式。表达式在每个输入序列的对象上执行，拒绝返回 `false` 的对象。

### 比较运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `=` | 等于（字符串不区分大小写） | `where name = "Hello"` |
| `!=` | 不等于 | `where name != "Hello"` |
| `<` | 小于 | `where volume < 0` |
| `<=` | 小于等于 | `where volume <= 0` |
| `>` | 大于 | `where volume > -3` |
| `>=` | 大于等于 | — |

### 单词搜索运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `:` | 单词部分匹配（支持通配符 `*`） | `where name : "Hello"`、`where name : "Hel"`、`where name : "*ello"` |

### 正则表达式

```
$ where name = /Hello/
$ where name = /llo$/
$ where name = /[a-z][0-9]/
```

使用 `= /REGEX/` 语法进行正则表达式匹配。采用 **ECMAScript 正则表达式**。

### 逻辑运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `!` | 逻辑非 | `where !(name = "Hello")` |
| `and` | 逻辑与 | `where name = "Hello" and volume = 0` |
| `or` | 逻辑或 | `where name = "Hello" or name = "Hi"` |
| `()` | 分组 | `where (volume = -3 or volume = 0) and (name = "Hello" or name = "Hi")` |

### where 子句示例

```
$ from type Sound where @Volume < 0
$ from type Sound where -1 = @Volume
$ from type Sound where @OutputBus = "Bus:Master Audio Bus"
$ from type Sound where @UserAuxSend0 = "AuxBus:Hangar_Env"
$ from type Event select children where @Target.path : "hello"
$ from type RandomSequenceContainer where childrenCount > 2 and childrenCount <= 4
$ from type Sound where notes : "All"
$ from type Sound where notes : "*audiokinetic*"
$ from type Sound where @UserAuxSend0 != null
```

## select 子句

`select` 关键字将输入序列中的每个对象投影为新形式。

```
select OBJECT_EXPRESSION
```

OBJECT_EXPRESSION 返回零到多个对象。

### select 示例

```
$ from object "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}" select parent
$ from object "Bus:Master Audio Bus" select children
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants, this where @Volume < 0
$ from object "\Actor-Mixer Hierarchy\Default Work Unit\Hello" select @OutputBus
$ from object "{CBCD492C-982D-4EE4-AE75-0019CA6577EF}" select parent.@Attenuation
```

## 其他变换（Transforms）

### skip — 跳过

跳过输入序列中指定数量的对象，返回剩余对象。

```
$ from type Sound skip 10
```

### take — 获取

返回输入序列开头指定数量的连续对象。

```
$ from type Sound take 10
```

### orderby — 排序

按升序排序输入序列中的对象。添加 `reverse` 进行降序排序。

```
$ from type Sound orderby name
$ from type Sound orderby name reverse
$ from type Bus orderby @BusVolume
$ from type Action orderby @Target.name
```

> **注意：** `orderby` 需要分配等于输入序列大小的内存。

### distinct — 去重

仅返回输入序列中的不同对象，重复对象条目将被缩减为一个。

```
$ from object "\Actor-Mixer Hierarchy" select descendants select @OutputBus distinct
```

> **注意：**
> - `distinct` 会改变序列的顺序，因此建议将 `orderby` 放在 `distinct` 之后
> - `distinct` 需要分配等于输入序列大小的内存

## 字符串引号规则

- **字符串值**必须用**双引号** `"..."` 包围
- 对象路径使用反斜杠 `\` 作为分隔符：`"\Actor-Mixer Hierarchy\Default Work Unit"`
- 正则表达式使用 `/.../` 包围：`where name = /Hello/`

## return 表达式（高级）

`return` 关键字用于控制从 `ak.wwise.core.object.get` 返回的数据格式。支持以下高级运算符：

### 组合运算符 `{}`

返回一个新的 JSON 对象，由枚举的表达式组成：

```
$ from type sound
return: ["path", "OutputBus.{name, shortid}"]

$ from type audiofilesource where markers.any()
return: ["path", "Markers.{time, label}"]

$ from type event
return: ["name", "children.target.{path, type}"]
```

> **注意：** 此运算符只能在 return 表达式中使用。

### 连接运算符 `[]`

返回一个新列表，是枚举列表或对象的连接：

```
$ from type randomsequencecontainer
return: ["[this, ancestors].name"]
```

### 别名关键字 `as`

重命名表达式，成为结果中的键名：

```
$ from type sound
return : ["outputbus.name as bus", "duration.max as duration"]

$ from type event
return : ["name as event", "children.target.[this, descendants].where(type=\"Sound\").originalRelativeFilePath as originals"]
```

> **注意：** `as` 只能在 return 表达式中使用。

## List Functions（列表函数）

对列表中的所有项执行条件逻辑或选择特定元素。可用于对象列表和 WAQL 提供的其他列表（如 `children`、`descendants`、`ancestors`、`referencesTo`）。

| 函数 | 说明 | 示例 |
|------|------|------|
| `count` | 返回列表中匹配条件的项数 | `where children.count() > 3`、`where effects.count(effect.pluginname:"eq") > 0` |
| `any` | 如有任何项匹配则返回 true | `where rtpc.any()`、`where children.any(type = "Sound")` |
| `all` | 如所有项都匹配则返回 true | `where children.all(type = "Sound")` |
| `first` | 返回第一个匹配的项 | `where effects.first(effect.pluginname:"EQ") != null` |
| `last` | 返回最后一个匹配的项 | `where effects.last(effect.pluginname:"EQ") != null` |
| `take` | 获取指定数量的项，返回新列表 | `select children.take(2)` |
| `skip` | 跳过指定数量的项，返回剩余的新列表 | `select effects.skip(1)` |
| `at` | 返回列表中指定索引的项 | `select effects.at(0)` |
| `where` | 返回匹配条件的新列表 | `select effects.where(effect.pluginname:"EQ")` |
