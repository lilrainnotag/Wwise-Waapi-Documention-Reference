# 01 - 项目查询模式

> **数据来源**: Audiokinetic 官方文档 — [Querying the Wwise Project](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=waapi_query.html)

## 场景描述

在自动化 Wwise 工程管理时，最常见的需求就是查询工程中的对象——获取对象属性、遍历层级结构、按条件筛选对象等。WAAPI 通过 `ak.wwise.core.object.get` 函数提供了完整的查询系统，支持两种查询方式：

| 查询方式 | 说明 | 推荐度 |
|---------|------|-------|
| **WAQL** | Wwise Authoring Query Language，一行文本查询 | ✅ 官方推荐 |
| **JSON** | 使用 `from` + `transform` 的 JSON 结构 | ❌ 不推荐 |

> **官方建议**: "We recommend using WAQL instead of the JSON query format. WAQL provides greater functionality and coverage, has better error handling and is easier to use."

---

## 核心 API 调用链

```
1. 连接 WAAPI → WaapiClient()
2. 构造 WAQL 查询字符串
3. 调用 ak.wwise.core.object.get(args, options=options)
4. 处理返回的结果数组
5. 断开连接 → client.disconnect()
```

**关键参数**：

- **args**：包含 `waql` 字段的 WAQL 查询字符串
- **options**：包含 `return`（返回字段列表）、`platform`（平台）、`language`（语言）

---

## 查询系统架构

### WAQL 查询语句结构

WAQL 查询遵循以下结构：

```
$ <from> <transform>* <options>?
```

- `$` — 查询起始符
- `<from>` — 查询起点（路径、GUID、类型等）
- `<transform>*` — 可选的转换链（select、where、distinct）
- `<options>?` — 可选的返回字段

### From 选项（查询起点）

| 选项 | 说明 | 示例 |
|------|------|------|
| `id:` | 通过 GUID 查找 | (在 JSON 模式中使用) |
| `name:` | 通过类型限定名查找 | `type:name` 格式 |
| `search:` | 文本搜索（名称和注释） | (在 JSON 模式中使用) |
| `path:` | 通过绝对路径查找 | `\Actor-Mixer Hierarchy\Default Work Unit\MySound` |
| `ofType:` | 按类型获取所有对象 | (在 JSON 模式中使用) |
| 直接使用路径 | 直接在 `$` 后跟路径 | `$ "\Actor-Mixer Hierarchy\Default Work Unit\MySound"` |
| 直接使用 GUID | 直接在 `$` 后跟 GUID | `$ "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"` |

### Transform 选项（转换链）

| 转换 | 说明 |
|------|------|
| `select parent` | 选取父对象 |
| `select children` | 选取直接子对象 |
| `select descendants` | 选取所有后代（递归） |
| `select ancestors` | 选取所有祖先（递归） |
| `select referencesTo` | 选取引用该对象的所有对象 |
| `where name = /regex/` | 按正则表达式过滤名称 |
| `where name:contains "text"` | 按文本搜索过滤名称（不区分大小写） |
| `where type:isIn "Type1", "Type2"` | 按类型过滤 |
| `where category:isIn "Category"` | 按类别过滤 |
| `distinct` | 去重 |

> **提示**: 可以在 Wwise Authoring 工具栏或 List View 搜索框中使用 `$` 前缀直接测试 WAQL 查询，非常便于验证语法和结果。

## 完整 Python 示例

### 示例 1：通过路径和 GUID 获取对象属性

> 来源：官方 Query 页面示例

```python
from waapi import WaapiClient
import pprint

# Connect (default URL)
client = WaapiClient()

# Return two objects
args = {
    'waql': '$ "\\Audio Devices\\Default Work Unit\\System", "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}"'
}

options = {
    'return': ['id', 'name', 'Volume']
}

result = client.call("ak.wwise.core.object.get", args, options=options)
pprint.pprint(result)

# Disconnect
client.disconnect()
```

**说明**：此示例通过路径和 GUID 查询两个对象，返回它们的 ID、名称和 Volume 属性。

---

### 示例 2：遍历层级并用正则过滤

> 来源：官方 Query 页面示例

```python
from waapi import WaapiClient
import pprint

# Connect (default URL)
client = WaapiClient()

# Return all objects under the actor-mixer hierarchy with a name that starts with "My"
args = {
    'waql': '$ "\\Actor-Mixer Hierarchy" select descendants where name = /^My/'
}

options = {
    'return': ['name', 'id']
}

result = client.call("ak.wwise.core.object.get", args, options=options)
pprint.pprint(result)

# Disconnect
client.disconnect()
```

**说明**：此示例从 Actor-Mixer Hierarchy 根节点开始，递归选取所有后代，然后通过正则表达式 `/^My/` 过滤名称以 "My" 开头的对象。

## Return 选项详解

### 属性值前缀

| 写法 | 含义 |
|------|------|
| `'PropertyName'` | 获取被 override 系统解析后的值（推荐） |
| `'@@PropertyName'` | 同上，显式使用 @@ 前缀 |
| `'@PropertyName'` | 获取直接在对象上设置的值（忽略 override） |

> 官方建议：不使用前缀，因为默认行为等同于 `@@` 前缀，会返回 override 解析后的实际使用值。

### 引用链查询

当表达式解析为有效引用时，可以通过 `.` 继续查询引用对象的属性：

```python
'return': [
    'OutputBus.name',               # 输出总线的名称
    'parent.name',                  # 父对象名称
    'parent.parent.type',           # 祖父对象类型
    'OutputBus.Volume',             # 输出总线的音量
    'OutputBus.Attenuation.name',   # 输出总线衰减的名称
    'Attenuation.path',             # 衰减的路径
    'Effects.first.effect.id',      # 第一个效果器的 ID
]
```

### 属性访问器

某些属性具有特殊功能（如随机化），可通过函数式访问器查询：

```python
# 查询 Volume 随机化器的 Max 属性
'return': ['randomizer("Volume").@Max']
```

当前支持的访问器列表：
- `randomizer` — 随机化修改器

> 更多访问器请参考 [ak.wwise.core.object.get](https://www.audiokinetic.com/library/2024.1.14_9084/?source=SDK&id=ak_wwise_core_object_get.html) 详情页。

### 其他 Options

| 选项 | 说明 |
|------|------|
| `return` | 返回值列表，默认 `['id', 'name']` |
| `platform` | 平台 ID (GUID) 或名称，用于获取平台特定值 |
| `language` | 语言 ID (GUID) 或名称，用于获取语言特定数据 |

## 常见实战模式

### 模式 1：按类型获取所有对象

```python
from waapi import WaapiClient

client = WaapiClient()

# 获取所有 Event 对象
args = {
    'waql': '$ from type "Event"'  # 注意：此语法可能需要配合 select 使用
}
options = {
    'return': ['id', 'name', 'type', 'path']
}

result = client.call("ak.wwise.core.object.get", args, options=options)
for obj in result.get('return', []):
    print(f"Event: {obj['name']} ({obj['id']})")

client.disconnect()
```

### 模式 2：获取指定 SoundBank 的包含对象

```python
from waapi import WaapiClient

client = WaapiClient()

# 通过 SoundBank 路径查询其包含的对象
args = {
    'waql': '$ "\\SoundBanks\\Default Work Unit\\MyBank" select descendants'
}
options = {
    'return': ['id', 'name', 'type', 'path']
}

result = client.call("ak.wwise.core.object.get", args, options=options)
print(f"MyBank 包含 {len(result.get('return', []))} 个对象")

client.disconnect()
```

### 模式 3：查询对象的引用关系

```python
from waapi import WaapiClient

client = WaapiClient()

# 查询引用了指定 Event 的所有对象
# 先用路径找到 Event
args = {
    'waql': '$ "\\Events\\Default Work Unit\\Play_MySound" select referencesTo'
}
options = {
    'return': ['id', 'name', 'type']
}

result = client.call("ak.wwise.core.object.get", args, options=options)
print("引用该 Event 的对象：")
for obj in result.get('return', []):
    print(f"  - {obj['type']}: {obj['name']}")

client.disconnect()
```

## 常见陷阱和注意事项

1. **路径转义**：WAQL 字符串中的反斜杠 `\` 需要转义为 `\\`。例如 `\\Actor-Mixer Hierarchy\\Default Work Unit`
2. **路径必须以类别名开头**：绝对路径必须以物理文件夹名称（类别名）开头
3. **不兼容的返回字段会被忽略**：如果 return 中的某个字段对查询结果对象不兼容，该字段不会出现在返回结果中（不会报错）
4. **WAQL vs JSON**：官方明确推荐 WAQL。JSON 查询不应在新项目中使用
5. **GUID 格式**：使用 `{xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx}` 格式，在 WAQL 中需要加双引号
6. **属性名大小写无关**：`Volume`、`volume`、`VOLUME` 等效

---

## 性能考量

- `select descendants` 在大型工程中可能返回大量对象，建议结合 `where` 过滤条件限制结果集
- 使用 `return` 精确指定需要的字段，避免返回不必要的属性数据
- 对于已知 GUID 的对象，直接通过 GUID 查询比遍历层级更高效
- 在 Wwise 中先用 `$` 前缀测试 WAQL 查询，验证语法和结果集大小
