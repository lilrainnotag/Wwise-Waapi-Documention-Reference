# 04-变换操作

## Transform 概述

Transform（变换）是 WAQL 查询的核心机制。每个查询由**源（Source）**和一系列**变换（Transform）**组成，每个变换接收前一部分的输出序列并生成新的序列。

### 基本概念

- **源（Source）**：由 `from` 关键字定义，初始化对象序列
- **变换（Transform）**：由特定关键字定义（`where`、`select`、`skip`、`take`、`orderby`、`distinct`），接收输入序列并输出新序列
- **输入序列（Input Sequence）**：前一个源或变换生成的对象序列
- 每个部分将输出传递给下一个部分

---

## Transform 的链式处理

### 单个 Transform

```
$ SOURCE TRANSFORM
```

示例：
```
$ from type Sound where @Volume < 0
```

### 多个 Transform（逗号分隔）

```
$ SOURCE TRANSFORM, TRANSFORM, ...
```

示例：
```
$ from type Sound where @Volume < 0, select parent
```

每个 Transform 依次处理：先 `where` 过滤，结果传递给 `select parent`。

### 省略 Source

```
$ TRANSFORM
```

此时整个项目作为隐式源：
```
$ where volume < 0
```

## 各 Transform 详解

### where — 过滤变换

过滤输入序列中不匹配指定表达式的对象。

```
$ from type Sound where @Volume < 0
$ from type Sound where @OutputBus = "Bus:Master Audio Bus"
$ from type Sound where childrenCount > 2 and childrenCount <= 4
```

**在 `where` 中使用的表达式类型：**
- 比较运算：`=`、`!=`、`<`、`<=`、`>`、`>=`
- 单词搜索：`:`
- 正则表达式：`= /REGEX/`
- 逻辑运算：`!`、`and`、`or`、`()`

### select — 选择变换

将输入序列中的每个对象投影为新形式。

```
$ from object "{1514A4D8-1DA6-412A-A17E-75CA0C2149F3}" select parent
$ from object "Bus:Master Audio Bus" select children
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants, this where @Volume < 0
$ from type Event select children select target select this, descendants where type = "sound"
```

**多个 select 的链式组合：**

```
$ from type event                   -- 所有 Event
select children                     -- Event 的 Action
select target                       -- Action 的 Target
select this, descendants            -- Target 及其所有后代
where type = "sound"                -- 仅保留 Sound 类型
```

### skip — 跳过变换

跳过指定数量的对象，返回剩余对象。

```
$ from type Sound skip 10
```

跳过前 10 个 Sound，返回第 11 个及之后的 Sound。

### take — 获取变换

返回开头指定数量的连续对象。

```
$ from type Sound take 10
```

仅返回前 10 个 Sound。

### orderby — 排序变换

按升序排序后返回。添加 `reverse` 降序排序。

```
$ from type Sound orderby name
$ from type Sound orderby name reverse
$ from type Bus orderby @BusVolume
$ from type Action orderby @Target.name
```

> **重要：** `orderby` 需要分配**等于输入序列大小**的内存来执行排序。

**排序值表达式的类型：**
- 字符串值（如 `name`）
- 数值（如 `@BusVolume`）
- 布尔值

### distinct — 去重变换

仅返回不同的对象，重复条目缩减为一个。

```
$ from object "\Actor-Mixer Hierarchy" select descendants select @OutputBus distinct
```

> **注意：**
> - `distinct` 会改变序列的**顺序**，建议将 `orderby` 放在 `distinct` **之后**
> - `distinct` 需要分配**等于输入序列大小**的内存

## Transform 链的典型模式

### 模式 1：过滤 + 投影

```
from → where → select
```

```
$ from type RandomSequenceContainer where childrenCount > 2 select children
```

1. 获取所有 RandomSequenceContainer
2. 过滤出 childrenCount > 2 的
3. 获取它们的子对象

### 模式 2：多级选择

```
from → select → select → select
```

```
$ from type event select children select target select this, descendants where type = "sound"
```

### 模式 3：选择 + 过滤

```
select → where
```

```
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants where @Volume < 0
```

1. 获取 Default Work Unit
2. 选择其所有后代
3. 过滤出 Volume < 0 的

### 模式 4：去重 + 排序

```
select → distinct → orderby
```

```
$ from object "\Actor-Mixer Hierarchy" select descendants select @OutputBus distinct orderby name
```

`orderby` 放在 `distinct` 之后确保正确的排序结果。

### 模式 5：跳过/限制

```
from → skip → take
```

```
$ from type Sound skip 10 take 5
```

跳过前 10 个，然后取接下来的 5 个（即获取第 11-15 个 Sound）。

---

## where 在 Transform 链中的位置

`where` 可以出现在 Transform 链中的**任意位置**：

**在 select 之前（过滤源对象）：**
```
$ from type Sound where volume < 0 select parent
```

**在 select 之后（过滤选择结果）：**
```
$ from object "\Actor-Mixer Hierarchy\Default Work Unit" select descendants where @Volume < 0
```

**在多个 select 之间：**
```
$ from type event select children where @ActionType = 1 select target
```

---

## 性能注意事项

1. **`from type` 优于 `where type =`**：`from type sound` 比 `where type = "Sound"` 更高效，因为前者限制迭代范围
2. **尽早使用 `where` 过滤**：在 Transform 链早期过滤可以减少后续 Transform 处理的对象数量
3. **`orderby` 和 `distinct` 消耗内存**：它们需要分配等于输入序列大小的内存
4. **`take`/`skip` 可以限制结果数量**：在不需要完整结果时使用这两个变换
